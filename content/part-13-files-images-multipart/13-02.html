กฎสำคัญ: dart:io File ใช้ได้กับ mobile/desktop แต่ import นี้ทำให้ Flutter Web compile ไม่ผ่านได้ แม้ branch ที่เรียกจะถูกครอบด้วย kIsWeb ก็ตาม

1. XFile เป็น boundary ที่ดีกว่า

image_picker คืน XFile ซึ่งอ่านชื่อ, path, length และ bytes ได้ข้าม platform ให้ UI และ repository รับ XFile หรือ type ของเราเอง แล้วค่อยแปลงเป็น multipart ใน data source

2. ปัญหาในโค้ดจริง

// wmsapp ปัจจุบัน
required File imageFile;
File(picked.path);
MultipartFile.fromPath('file', imageFile.path);

เหมาะกับ Android/iOS ที่แอปนี้ใช้งาน แต่หากจะรองรับ Web ต้องไม่ให้ shared file import dart:io และไม่ควรสมมติว่า browser มี filesystem path ที่ server/client อ่านตรงกันได้

3. Portable value object

class UploadAsset {
  final String name;
  final int length;
  final Future<List<int>> Function() readBytes;
  const UploadAsset(this.name, this.length, this.readBytes);
}

final asset = UploadAsset(
  picked.name,
  await picked.length(),
  picked.readAsBytes,
);

4. Bytes กับ stream

readAsBytes() สะดวกและ web-safe แต่โหลดทั้งไฟล์เข้าหน่วยความจำ ไฟล์ที่จำกัดไว้ไม่กี่ MB ใช้ได้ ส่วนไฟล์ใหญ่ควรเปิด stream และสร้าง multipart จาก stream เพื่อไม่ให้เกิด memory spike

5. kIsWeb ใช้เมื่อไร

if (kIsWeb) {
  return Image.memory(await picked.readAsBytes());
}
return Image.file(File(picked.path));

ตัวอย่างนี้ยังต้องอยู่ในไฟล์ที่ไม่ถูก compile สำหรับ web หรือแยกด้วย conditional import เพราะ parser ยังเห็น dart:io วิธีง่ายที่สุดคือใช้ Image.memory/Image.network ที่ portable หรือสร้าง adapter แยก platform

6. Conditional import

import 'preview_stub.dart'
  if (dart.library.io) 'preview_io.dart'
  if (dart.library.html) 'preview_web.dart';

ให้แต่ละ implementation รู้เรื่อง platform ของตน ส่วน screen เรียก interface เดียว ทำให้ test ด้วย fake ได้และไม่กระจาย kIsWeb ทั่ว codebase

7. อย่าเก็บ path เป็นข้อมูลถาวร

path จาก picker อาจเป็น temporary file และหายหลังระบบล้าง cache หากต้อง retry ภายหลังให้ copy เข้า app documents/cache ที่มี lifecycle ชัดเจน หรือเก็บ bytes ที่เข้ารหัส พร้อม metadata และ cleanup policy

8. แบบฝึกหัด

เปลี่ยน signature ของ uploadPartImage จาก File เป็น XFile หรือ UploadAsset แล้วอธิบายว่าจะใช้ fromPath, fromBytes หรือ stream ในแต่ละ platform

แนวคำตอบ

mobile ใช้ fromPath เพื่อ stream จาก disk, web ใช้ bytes/stream จาก picker และทั้งคู่ต้องตรวจ length ก่อนสร้าง request
