Subscribeตาม owner lifetime: StatefulWidgetลงทะเบียน handler referenceใน initState เมื่อ dependencyคงที่ หรือย้าย subscriptionไป route-scoped Storeเพื่อให้ UIไม่ parse/merge eventเอง

1. Widget pattern

late final RealtimeSubscription _subscription;

@override
void initState() {
  super.initState();
  _subscription = realtime.subscribe(_onEvent);
  unawaited(realtime.ensureConnected());
  unawaited(store.refresh());
}

2. Stable callback identity

method tear-off _onEvent เป็น referenceที่ใช้ยกเลิกได้ หลีกเลี่ยง anonymous closureคนละ instanceใน add/remove

3. Dependency changes

ถ้า realtime serviceมาจาก widget/providerและเปลี่ยนได้ ใช้ didUpdateWidget unsubscribeตัวเก่าแล้ว subscribeตัวใหม่ ไม่ addซ้ำทุก build/didChangeDependencies

4. Initial snapshot race

register eventก่อน HTTP loadอาจรับ eventระหว่าง snapshot วิธีปลอดภัยคือใช้ version/sequence: load snapshot versionแล้ว applyเฉพาะ eventใหม่หรือ refreshอีกครั้งหลัง connection synchronized

5. Handler responsibility

handlerตรวจ relevanceแล้วส่ง intentไป Store เช่น store.onRealtimeEvent(event) ไม่เปิด dialog/navigationหรือ setStateหลาย fieldจาก raw map

6. ของจริง

Putaway/Sorting screensใน wmsapp add listenersใน initState, connectและโหลด HTTP snapshot เป็น patternที่ดีแต่ต้องวาง reconciliation/versionเพิ่มเมื่อ production event orderingสำคัญ
