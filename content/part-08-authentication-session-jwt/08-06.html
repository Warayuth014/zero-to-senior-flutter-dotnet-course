Bootstrap gate: ก่อน request แรกต้องโหลด connection profile และ auth session ให้เสร็จ มิฉะนั้น request อาจไป server default โดยไม่มี token แล้วเกิด 401 ที่ดูเหมือน logout

1. Startup states

sealed class BootstrapState {}
class Booting extends BootstrapState {}
class NeedsLogin extends BootstrapState {}
class Ready extends BootstrapState { Ready(this.session); final AuthSession session; }
class BootFailed extends BootstrapState { BootFailed(this.message); final String message; }

2. Ordered initialization

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await connectionProfiles.load();
  await auth.restore();
  runApp(App(bootstrap: bootstrap));
}

3. Splash ไม่ใช่ delay

Splash แสดงตาม Future/state จริง ไม่ใช้ fixed timer เพราะเครื่องเร็วเสียเวลา เครื่องช้ายัง race และ error ไม่มีทาง retry

4. First request invariant

ApiClient ต้องมี base URL ที่ active และ token ที่ restore แล้วก่อน Store เริ่ม polling/load ใน initState ควรสร้าง authenticated shell หลัง gate ready เท่านั้น

5. Parallel ที่ปลอดภัย

theme/language อาจโหลดคู่กันได้ แต่ auth restore ต้องรอ connection profile ถ้า session bind กับ server และ feature data ต้องรอ auth; วาด dependency graphก่อนใช้ Future.wait

6. ของจริง

wms_absolute_mobile/main.dart เรียก WidgetsFlutterBinding.ensureInitialized() และรอ language/connection profile ก่อน runApp; Part นี้เพิ่ม session restore เข้า sequence เดียวกัน

7. แบบฝึกหัด

ภาษาโหลดไม่ได้แต่ token/server ถูกต้อง ควร block app ทั้งหมดหรือไม่?

แนวคำตอบ

ใช้ default locale และ log warning ได้ ส่วน connection/auth corruption ต้องเข้าสถานะ recoverable ที่ให้เลือก server/login ไม่ปล่อย feature request วิ่งผิด config

8. Acceptance

ไม่มี flash หน้า login ก่อน restore, ไม่มี request ก่อน ready, error retry ได้, logout ระหว่าง boot ปลอดภัย และ test ควบคุมลำดับด้วย fake dependencies
