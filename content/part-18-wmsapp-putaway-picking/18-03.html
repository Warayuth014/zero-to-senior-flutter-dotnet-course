StationSheet คือ command form: StationCard แสดง normal/dispatching state ส่วน sheet รับ pallet, ตรวจ station policy และสร้าง confirm command ที่สมบูรณ์

1. StationCard lifecycle

AnimationController เริ่ม repeat เมื่อ isDispatching และ didUpdateWidget start/stop/reset เมื่อสถานะเปลี่ยน ก่อน dispose controller เสมอ จึงไม่ทิ้ง ticker หลังออกหน้า

2. Normal vs dispatching

normal content แสดง station, pallet/destination และ affordance; dispatching content เปลี่ยนสีเป็น danger พร้อมลูกศร animated และข้อความ AMR ตาม receive/send role ภาพเคลื่อนไหวเป็น presentation ไม่ใช่ timer ของงานจริง

3. Sheet state

state หลักคือ pallet controller, PutawayPalletInfo?, loading scan/confirm, selected destination และ wrapping flag ส่วน effective destination ให้ fixedDestination ของ station ชนะค่าที่ผู้ใช้เลือก

4. Station policies

allowedType จำกัดชนิด pallet, fixedDestination ล็อกปลายทาง และ pwRole เปลี่ยนความหมายหน้าจอ receive/send กติกาเหล่านี้ต้อง validate ซ้ำใน .NET เพราะ client ถูกแก้ request ได้

5. Scan transition

empty → loadingPallet → palletLoaded
                    ↘ error/typeMismatch

request ส่ง palletId และ stationId ให้ backend ตรวจ location/availability ก่อน UI นำ response มาเลือก suggestedDestination

6. Confirm transition

dialog อธิบาย destination และ wrapping จากนั้น confirmPutaway ส่ง operatorId เมื่อสำเร็จ pop sheet แล้วให้ parent refresh ห้ามถือว่าปิด sheet เท่ากับ AMR ขนเสร็จ เพราะ dispatch/arrival เป็นสถานะถัดไป

7. Async lifecycle bug

ในโค้ดจริงบางจุดเรียก setState หลัง await ก่อนตรวจ mounted เช่นปิด loading ใน scan/confirm หาก sheet ถูกปิดระหว่าง request อาจเกิด setState after dispose ควรตรวจ mounted ก่อน setState ทุกครั้ง

8. Refactor

สร้าง sealed state Loading/Ready/Submitting/Error และ inject PutawayRepository; ให้ StationPolicy คำนวณ allowed destinations/wrapping แยกจาก widget แล้วเขียน test policy โดยไม่ต้อง pump bottom sheet
