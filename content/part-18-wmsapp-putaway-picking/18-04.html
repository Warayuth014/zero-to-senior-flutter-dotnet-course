Prework เป็นสองคอลัมน์แต่ใช้คนละ state source: receive stations แสดง pallet ที่เรียกมา/ตัดเสร็จ ส่วน send stations แสดง pallet ที่กำลังส่งกลับ ASRS

1. Six-station topology

PW-STN-1/3/5 เป็น PWRole.receive; PW-STN-2/4/6 เป็น send พร้อม fixedDestination: ASRS และทุกสถานีจำกัด allowedType: PW

2. Two status maps

_receiveStatus มาจาก prework-station-status ส่วน _stationStatus มาจาก station-status ทั่วไป การใช้ map แยกสะท้อน backend read model คนละชุด แต่ควรมี type แทน dynamic map

3. Parallel initial load

await Future.wait([
  _loadStationStatus(),
  _loadPreworkStationStatus(),
]);

ลดเวลาโหลดรวม แต่แต่ละ call กลืน error จึงอาจได้ครึ่งหน้าที่ดูเหมือนปกติ ควรแสดง freshness/error แยกต่อ column

4. Receive states

ไม่มี pallet แสดง empty; status IN_TRANSIT แสดงกำลังมาและปิดการเปิด sheet; state อื่นแสดง cut complete, cutItems และปุ่ม return empty pallet

5. Send states

send station ใช้ StationSheet เดิมเพื่อ scan PW pallet และ confirm ไป ASRS ปลายทางถูกล็อก จึงเลือก PREWORK/REPLENISH ไม่ได้ แต่ wrapping ยังเปิดได้เมื่อ fixed destination เป็น ASRS

6. Return empty pallet

preworkReturnPallet(palletId, stationId) เปลี่ยน pallet เป็น AVAILABLE หลัง confirm เมื่อสำเร็จ sheet ปิด แสดง snackbar และ parent เริ่ม animation การ return

7. Animation vs truth

ข้อความ AMR picking up/returning เปลี่ยนด้วย timer 2+2 วินาทีแล้ว refresh สถานะ Timer เป็น feedback เท่านั้น ไม่ควรกำหนดว่ากระบวนการจริงเสร็จ หาก event มาช้าหรือเร็ว UI ต้องยัง reconcile กับ server

8. Test matrix

ทดสอบ receive empty/in-transit/cut-complete, cutItems ว่าง/หลายรายการ, send busy, return reject/timeout/success, event ระหว่าง timer และ dispose ก่อน timer จบ โดย assert ว่า timer ถูก cancel และไม่ setState หลัง dispose
