ไฟล์หลัก: lib/core/app_language.dart — singleton ChangeNotifier ที่แยกค่าภาษา runtime ออกจาก persistence

1. State model

ภาษาเป็น enum English/Thai ไม่ใช่ free-form string จึงจำกัด state ที่เป็นไปได้ controller มี instance เดียว, default English และ key app_language สำหรับ preferences ส่วน getter code/locale ใช้สร้าง UI และ MaterialApp config

2. Load ก่อน runApp

load() อ่าน SharedPreferencesAsync แล้วแปลงค่าที่รู้จัก หาก plugin ไม่พร้อมใน test จะจับ StateError และใช้ default ต่อ การ await ก่อน runApp ป้องกัน first-frame language flash และทำให้ title/validator เริ่มด้วยภาษาเดียวกัน

3. Optimistic update

setLanguage(next)
→ update in-memory value
→ notifyListeners()
→ persist asynchronously
→ storage StateError: keep current session usable

UI เปลี่ยนทันทีแม้ disk ช้า หาก persist fail การเปิดแอปรอบหน้าอาจกลับค่าเดิม จึงควรมี diagnostic หรือสถานะ save failureถ้าการตั้งค่านี้สำคัญ

4. Rebuild propagation

MaterialApp ฟัง controller ที่ root ขณะที่ LanguageButton เรียก toggle และ widgets ใช้ tr() ระหว่าง build ข้อความที่สร้างนอก build หรือ cache ใน constructorจะไม่เปลี่ยนเอง จึงควรเก็บ domain value แล้วแปลตอน render

5. สิ่งที่ไม่ควรแปล

status/enum จาก backend, barcode, part code และ identifiers ต้องคงค่าต้นฉบับเพื่อส่งกลับ API การแปลควรอยู่ presentation mapping เช่น connectionStatusLabel ไม่เปลี่ยน serialized value มิฉะนั้นภาษา UI อาจทำให้ contract เสีย

6. ข้อจำกัดของ tr(en, th)

ฟังก์ชันสอง string ใช้ง่ายและเหมาะกับแอปเล็ก แต่ตรวจ missing key/plural/placeholders ยาก และกระจายข้อความทั่ว codebase เมื่อโตควรย้ายไป ARB/gen-l10n หรือ typed catalog โดยรักษา domain-to-label mapping เดิมไว้

7. Concurrency และ testability

การ toggle เร็วหลายครั้งทำ writes ตามลำดับ future ที่เรียก แต่ storage completionอาจไม่ใช่ intent ล่าสุดหาก adapter เปลี่ยนเป็น async ที่ช้าต่างกัน แนวทาง robust คือ serialize write หรือ version intent และ inject storage แทนจับ plugin errorใน production class โดยตรง

8. Test checklist

ทดสอบ default, restore en/th, unknown persisted value, notify ครั้งเดียวเมื่อค่าต่าง, ไม่ notify เมื่อค่าเดิม, persistence failureยังเปลี่ยน UI session, MaterialApp locale rebuild และ domain valueไม่ถูกแปลปะปนกับ label
