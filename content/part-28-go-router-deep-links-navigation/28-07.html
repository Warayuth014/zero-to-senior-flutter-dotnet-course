Query parameter: เหมาะ optional view state เช่น filter/search/sort/sourceที่เปลี่ยนแล้ว resourceหลักยังเดิมและควร share/bookmarkได้

1. Lab filter

/tasks?status=waiting ทำให้เปิดรายการที่ filterแล้วได้ทันที FilterChipใช้ goNamedแก้ queryแทน local stateลับ

2. Parse

อ่าน state.uri.queryParameters แล้ว validate enum/range/default Unknown valueควร fallbackหรือแสดง invalid-linkอย่างตั้งใจ

3. Encoding

ใช้ Uri/queryParametersเพื่อ encode space, Thaiและreserved characters ไม่ต่อ ?q=$text เอง

4. Canonical defaults

ถ้า status=allเท่ากับไม่มี query ให้ canonical URLตัด defaultออก ลด duplicate URLsและทำ shareง่าย

5. Multiple values

ใช้ queryParametersAllเมื่อ filterหนึ่ง keyมีหลายค่าและกำหนด ordering/canonical formก่อนสร้าง cache key

6. Sensitive data

ห้ามใส่ token/password/PIIใน queryเพราะปรากฏใน history, logs, screenshotsและreferrer ใช้ secure session/one-time codeตาม protocol

7. Update history

searchทุก keystrokeอาจใช้ replace/debounceไม่ให้ browser backต้องย้อนตัวอักษรทีละตัว ส่วน filter explicitอาจใช้ goเพิ่ม historyได้

8. Test

Routing testเปิด /tasks?status=waiting แล้วเห็น TASK-001แต่ไม่เห็น working task เป็นหลักฐานว่า URLและ UI stateตรงกัน
