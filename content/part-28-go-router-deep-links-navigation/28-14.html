Back semantics: browser back, Android back, iOS gesture, branch stackและ unsaved workต้องมี behaviorสอดคล้อง ไม่ใช้ dialogดักทุก popโดยไม่เข้าใจ page-backed routes

1. canPop

ตรวจ navigator/router stackก่อนแสดง custom back ปุ่ม rootควรออก/ส่ง backgroundตาม platformไม่วนไปหน้า arbitrary

2. PopScope

ใช้สำหรับ formมี unsaved changesพร้อม canPop/callbackรุ่นปัจจุบัน แต่ page-backed routeเปลี่ยนจาก deep linkอาจถอด pageless routesด้วย ต้องทดสอบ package behavior

3. Confirm discard

แยก navigation intentจากการตัดสินใจบันทึก draft ห้าม call popซ้ำจน loopและรองรับ system gestureที่เริ่มก่อน callbackบาง platform

4. Browser back

ถ้า filterใช้ goทุก keystroke historyจะรก เลือก replace/debounceตาม UXและทดสอบ forwardด้วย

5. Branch back

เมื่อ task detailอยู่ branch backควรกลับ task listก่อนออก app สลับ branchแล้วกลับมาต้อง preserve stackตาม StatefulShellRoute contract

6. Pageless cleanup

dialogบน pageอาจหายเมื่อ incoming URLแทน page-backed stack นี่ถูกต้องได้แต่ side effects/listenersต้องไม่ค้าง

7. Scanner cancel

backจาก scannerคืน nullและ detailยังอยู่ ไม่ควร logout/กลับ homeเพราะ scannerอยู่ root navigator

8. Test matrix

เขียนตาราง platform×location×operation×expected URL/visible page/data loss แล้วทดสอบ critical cellsจริง
