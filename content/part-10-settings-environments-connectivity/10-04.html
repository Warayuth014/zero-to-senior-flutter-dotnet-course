1. Model

2. Stable ID

ใช้ UUID/created IDเป็น identity ไม่ใช้ nameหรือ URL เพราะแก้ชื่อ/hostได้ Active selectionอ้าง IDและ duplicate-nameเป็น validation/UXคนละเรื่อง

3. Environment metadata

development/staging/productionช่วยสี/label/default protocolแต่ไม่ควรเปลี่ยน URLแบบแอบแฝงและไม่ใช้แทน verified server realm

4. copyWith

edit draftด้วย immutable copyและรักษา ID/createdAt แยก save-as-newที่ออก IDใหม่จาก save-editsชัดเจน ป้องกันแก้ objectใน listโดยตรง

5. JSON boundary

fromJson(Object?) ตรวจ required fields, port range, enum fallbackและ normalize legacy host ห้าม throwจน controller loadทั้งรายการล้มเพราะ profileเสียหนึ่งตัว

6. Equality

เปรียบเทียบ normalized semantic fieldsสำหรับ dirty/duplicate endpointแต่ identityใช้ ID ไม่ให้ slashต่างกันถือเป็น serverคนละตัวโดยบังเอิญ

7. แบบฝึกหัด

8. Invariants
