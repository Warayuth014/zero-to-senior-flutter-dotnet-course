Settings sheet ใช้ draft แยก saved state: พิมพ์/ทดสอบไม่เปลี่ยน active configจนกด Save/Use และปิด sheetต้อง guardข้อมูลที่ยังไม่บันทึก

1. Draft lifecycle

เปิด profile → copyลง controllers/draft → edit/validate/test draft → saveผ่าน controller → update baseline hash → close การ cancelทิ้ง draftโดยไม่ mutate profileใน list

2. Dirty detection

ProfileDraft get draft => ProfileDraft.fromControllers(...);
bool get isDirty => draft.normalized != savedBaseline.normalized;

เปรียบเทียบ normalized semantic valuesไม่ใช่ textดิบเพื่อ slash/spaceไม่ทำ dirtyปลอม

3. PopScope guard

Back, tapนอก modal, drag-downและ close buttonต้องผ่าน confirmเดียวกัน: Discard / Keep editing / Saveหาก valid ห้าม guardเฉพาะ AppBar back

4. Async safety

disable Test/Saveซ้ำระหว่าง probe/write, ตรวจ mountedหลัง awaitและใช้ draft generationไม่ให้ผล testเก่าของ URL Aแสดงบน draft B

5. Separate actions

Testไม่ save, Saveไม่จำเป็นต้อง activate, Save & Useมี realm/session confirmation และ Save As Newออก IDใหม่ ป้ายปุ่มต้องสื่อผลชัด

6. Accessibility/PDA

keyboard type numericสำหรับ port, touch targetsใหญ่, errorใกล้ field, copy resolved URL, show environment color+textและอย่าพึ่งสีอย่างเดียว
