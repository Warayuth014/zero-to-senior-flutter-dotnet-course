Modal bottom sheet เหมาะ selection/form/contextual actionsที่ต้องพื้นที่มากกว่า dialogและยังเห็นบริบทด้านหลัง ต้องจัด keyboard, safe area, scroll และ typed resultให้ครบ

1. Typed sheet

final location = await showModalBottomSheet<Location>(
  context: context,
  isScrollControlled: true,
  useSafeArea: true,
  builder: (ctx) => LocationPicker(
    onSelected: (value) => Navigator.pop(ctx, value),
  ),
);

2. Keyboard

isScrollControlledให้ sheetขยายและรับ viewInsets; contentควร scrollและ padding bottomตาม keyboardเมื่อ Scaffoldไม่จัดให้ จำกัด maxHeightสำหรับ landscape/PDA

3. DraggableScrollableSheet

เหมาะ listยาวที่ลากขนาดได้และต้องส่ง scrollControllerให้ listเพื่อ gestureทำงานร่วมกัน ไม่จำเป็นกับ action sheetสั้น

4. Dirty guard

ครอบ contentด้วย PopScopeและให้ close/drag/backผ่าน discard policyเดียว Absolute settings sheetทำเช่นนี้เพื่อป้องกันค่าที่แก้หาย

5. ตัวอย่างจริง

wmsappใช้ sheetsเลือก part/lot/image sourceและ workflow detail; Absoluteใช้ route-level connection settings form แสดงว่า sheetเป็น routeที่มี state/resultได้เต็ม

6. Root navigator

ใน nested shellกำหนด useRootNavigatorเมื่อ sheetต้องครอบ bottom navทั้งหมด มิฉะนั้นใช้ nearest navigatorเพื่ออยู่ใน feature stack ทดสอบ pop context

7. แบบฝึกหัด

Picker 500 locationsควร Column childrenทั้งหมดไหม?

เฉลย

ใช้ bounded/draggable sheet + ListView.builder, search state, typed Location result และ empty/loading/error ไม่ใช้ SingleChildScrollViewสร้าง 500 rows

8. จุดพลาด

อย่าเรียก Navigator.pop(pageContext)จาก sheetโดยไม่แน่ใจ navigator ใช้ builder contextและคืน result; หลัง awaitตรวจ page mounted
