Lab: ประกอบ Login → authenticated Shell → Workflow → Logout โดยกำหนด route stack, dependency/store lifetime, back policy, modal resultsและ session cleanupให้ทดสอบได้

1. Acceptance criteria

  • loginสำเร็จแทน Loginด้วย Shell
  • shellสร้าง/dispose session storeครั้งเดียว
  • bottom navigationใช้ destination sourceเดียว
  • workflowคืน Saved/Paused/Cancelledแบบ typed
  • PopScopeป้องกัน draft/commitสูญหาย
  • settings sheetมี dirty guard
  • logoutล้าง session/timers/stackทั้งหมด

2. Composition

App(auth, repositories)
└─ LoginScreen(auth)
   └─ pushReplacement WarehouseShell
      ├─ WarehouseStore(repositories, session)
      ├─ Home / Tasks / Picking destination
      ├─ SettingsSheet(connection)
      └─ Workflow routes → typed results

3. Auth transition

Future<void> login() async {
  if (submitting) return;
  final session = await auth.login(user, password);
  if (!mounted) return;
  Navigator.pushReplacement(
    context,
    MaterialPageRoute(builder: (_) => WarehouseShell(session: session)),
  );
}

4. Workflow result

final result = await Navigator.push<WorkflowResult>(
  context,
  MaterialPageRoute(builder: (_) => ReceiveFlow(store: store)),
);
if (!context.mounted) return;
switch (result) {
  case Saved(): await store.refreshReceiving();
  case Paused(): await store.refreshTasks();
  case Cancelled() || null: break;
}

5. Back/modal policy

Initial workflow popได้; draftถาม discard/pause; submitting lockหรือย้าย operationเข้า store; confirm dialogคืน bool; selection sheetคืน model; ทุก modalปิดด้วย builder contextและคืน focus

6. Logout

final confirmed = await confirmLogout(context);
if (!confirmed) return;
await auth.logout();
if (!context.mounted) return;
Navigator.of(context, rootNavigator: true).pushAndRemoveUntil(
  MaterialPageRoute(builder: (_) => LoginScreen(auth: auth)),
  (_) => false,
);

Shell dispose store/timerเมื่อ routeถูกล้าง

7. Tests

ใช้ fake auth/repositories + NavigatorObserver ทดสอบ failed loginไม่ navigate, success replacement, workflow result refreshถูก command, dirty backไม่ pop, double logoutหนึ่ง transition, logoutแล้ว Backไม่เข้า shell และ store disposeยกเลิก polling
