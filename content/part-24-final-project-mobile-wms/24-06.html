เป้าหมาย session: loginกับ .NET, แนบ JWTทุก protected call, handle expiration/401และล้าง stateตอน logout โดยไม่สอน Identity internalsซ้ำคอร์ส backend

1. Login contract

POST /api/Authenticate/login
{ "Username": employeeId, "Password": password }
→ { "token": "...", "expiration": "...Z" }

productionควรคืน user/roles/refresh policyจาก serverหรืออ่าน verified JWT claimsอย่างปลอดภัย

2. AuthRepository

repository map wire responseเป็น AuthSession, ตั้ง tokenใน session providerและคืน typed failures Widgetไม่ parse JWTหรือเขียน preferencesเอง Password controllerถูก clear/disposeและไม่ logค่า

3. Session state machine

checking → anonymous → authenticating → authenticated
                         ↘ rejected/error
authenticated → expired/revoked → anonymous

cold startต้องมี splash/checking ไม่ flash protected homeก่อนรู้ session

4. Persistence choice

เริ่ม memory-onlyเพื่อ threat surfaceต่ำ หาก requirementต้อง remember loginใช้ secure storageบน Androidและ document web behavior Token expiry/revocationยังต้องตรวจ server; encryption at restไม่ทำให้ stolen live tokenปลอดภัย

5. Authorization

roles/permissionsช่วยซ่อนเมนูและอธิบาย UI แต่ .NETต้อง enforceทุก endpoint Client-supplied usernameใน commandเป็น audit hintไม่ได้เป็น identity; backendอ่าน authenticated claims

6. Logout transaction

cancel timers/SignalR, invalidate async generations, clear token, feature storesและsensitive cache แล้ว navigate login การ clear SharedPreferencesทั้งหมดอาจลบ connection/languageจึงแยก namespaces

7. Concurrent 401

หลาย requestsอาจได้ 401พร้อมกัน Session coordinatorต้อง single-flight logout/refreshและไม่เปิด dialogซ้ำ Commandที่กำลังรอห้าม commit stateหลัง session generationเปลี่ยน

8. Acceptance tests

valid/invalid login, malformed token response, double submit, expiration, concurrent 401, logoutระหว่าง request, app restartและ role denied พร้อม integration testว่า protected .NET endpointปฏิเสธ requestไม่มี token
