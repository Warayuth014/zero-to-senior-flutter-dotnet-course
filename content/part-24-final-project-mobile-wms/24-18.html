Production readiness review: Final Projectถือว่าเสร็จเมื่อทีมอื่นรับช่วงและ operateได้ ไม่ใช่เมื่อผู้เขียน demo happy pathสำเร็จหนึ่งครั้ง

1. Functional trace

reviewทุก acceptance scenarioจาก user intent→widget→store→repository→HTTP/SignalR→.NET→state/audit ตรวจ identity/quantity/statusและ source of truth ไม่อ่านเฉพาะ screenshots

2. Architecture gate

dependenciesมองเห็น, feature storesมี boundary, local stateไม่ global, raw JSONหยุดที่ adapter, resources dispose, no God Store/service locatorใหม่และ ADRอธิบาย trade-offs/migration

3. Reliability gate

timeout/retry/idempotency/reconciliationชัด, stale responseกันได้, polling/realtime lifecycleถูก, commandsมี per-operation busyและ userไม่ติด dead-endหลัง partial failure

4. Security gate

real auth/authorization, secure token policy, HTTPS, server-switch logout, secret/log redaction, upload validation, logout cleanupและ dependency vulnerability reviewผ่าน

5. UX/operations gate

PDA/deviceจริงผ่าน scanner/focus/keyboard/glove/text scale/localization/background shift Connection/stale indicatorsชัดและ supportดู version/correlation/serverได้โดยไม่เห็น secret

6. Test/release gate

CI green, critical failure/race cases, .NET integration, signed artifact install/upgrade, checksum/symbols/rollbackและ pilot planครบ Known flaky testหรือ manual-only critical flowเป็น release riskที่ต้องยอมรับเป็นลายลักษณ์อักษร

7. Runbook

Start/stop & health
Environment/profile setup
Login/session recovery
Common errors + correlation lookup
Rollback/reinstall
Data/audit escalation
Owners and contacts

8. Graduation rubric

ผู้เรียนอธิบายและแก้ flowใหม่ได้โดยไม่ copy patternผิดบริบท, reviewerรัน/ทดสอบ/releaseจากเอกสารได้ และทุกช่องว่าง productionถูกระบุ owner/risk—not ซ่อนใต้คำว่า “ไว้ทำทีหลัง”
