จบบทนี้แล้วจะทำได้: เขียนฟังก์ชันที่รับค่าและคืนค่า เลือกใช้ parameter แบบตำแหน่งหรือแบบมีชื่อได้ถูกที่ และเข้าใจว่า “ส่งฟังก์ชัน” ต่างจาก “เรียกฟังก์ชัน” อย่างไร

1. ปัญหาที่บทนี้แก้

จนถึงตอนนี้โค้ดของเราเป็นคำสั่งเรียงกันยาว ๆ ใน main() ซึ่งใช้ได้กับโปรแกรม 10 บรรทัด แต่พออยากทำงานเดิมซ้ำในหลายที่ เราจะเริ่มคัดลอกโค้ด และเมื่อกฎเปลี่ยนก็ต้องไล่แก้ทุกจุด

ฟังก์ชันคือวิธีตั้งชื่อให้ “ชุดของงาน” หนึ่งชุด เพื่อให้เรียกใช้ซ้ำได้ และแก้ที่เดียวมีผลทุกที่ นี่ยังเป็นบทที่สำคัญเป็นพิเศษ เพราะ Flutter ทั้งเฟรมเวิร์กสร้างจากการส่งฟังก์ชันไปมา

3. Mental model: เครื่องจักรที่มีช่องใส่และช่องออก

ให้คิดว่าฟังก์ชันคือเครื่องจักรในสายพาน

  • ช่องใส่ คือ parameter — ระบุว่าเครื่องนี้ต้องการวัตถุดิบอะไรบ้าง
  • ช่องออก คือ return type — ระบุว่าเครื่องนี้ผลิตอะไรออกมา
  • ข้างในเครื่อง คือรายละเอียดที่คนเรียกใช้ไม่จำเป็นต้องรู้

อ่านบรรทัดแรกของฟังก์ชันแล้วต้องตอบได้สามข้อ: รับอะไร, คืนอะไร, ชื่อบอกว่าทำอะไร ถ้าตอบไม่ได้ แปลว่าฟังก์ชันนั้นตั้งชื่อไม่ดีหรือทำงานหลายอย่างเกินไป

ประโยคเดียวที่ต้องจำ: ฟังก์ชันที่ดีทำ “เรื่องเดียว” และชื่อของมันบอกได้ว่าเรื่องนั้นคืออะไร

  required String code,
  required String location,
  int quantity = 1,
  String? note,
}) {
  final suffix = note == null ? '' : ' ($note)';
  return 'หยิบ $code จำนวน $quantity จาก $location$suffix';
}

ทำไม Flutter ถึงใช้ named parameter แทบทุกที่: เพราะ widget หนึ่งตัวมีค่าให้ตั้งสิบกว่าค่า ถ้าใช้ตำแหน่งล้วน ๆ จะไม่มีใครจำได้ว่าตัวที่เจ็ดคืออะไร — พอเห็น padding:, onPressed:, child: ในบทหลัง ๆ ให้รู้ว่านั่นคือรูปแบบเดียวกับที่เรียนวันนี้

กฎของ required: parameter แบบมีชื่อจะไม่บังคับส่งโดยปริยาย ดังนั้นแต่ละตัวต้องเข้าเงื่อนไขข้อใดข้อหนึ่งใน 3 ข้อนี้ — ใส่ required, มีค่าเริ่มต้น, หรือเป็นชนิดที่ว่างได้ (String?)

7. ฟังก์ชันเป็น “ค่า” ได้

นี่คือแนวคิดที่ทำให้ Flutter ทำงานได้ และเป็นจุดที่คนใหม่งงมากที่สุด ใน Dart ฟังก์ชันเก็บใส่ตัวแปรได้เหมือนตัวเลขหรือข้อความ

void report(String message) => print('  [report] $message');

final printer = report;   // เก็บ "ตัวฟังก์ชัน" ไว้ในตัวแปร
printer('ส่งฟังก์ชันไปทำงานทีหลัง');   // ค่อยเรียกทีหลัง
จุดที่พลาดกันมากที่สุดทั้งคอร์ส: report คือ ตัวฟังก์ชัน ส่วน report('hi') คือ การเรียกทันทีแล้วได้ผลลัพธ์ — ต่างกันแค่วงเล็บ แต่ความหมายคนละเรื่อง เมื่อถึงบทปุ่มใน Flutter การใส่วงเล็บผิดที่จะทำให้ปุ่มทำงานเองตั้งแต่หน้าจอเปิด แทนที่จะรอให้ผู้ใช้กด

8. Closure: ฟังก์ชันที่จำสิ่งรอบตัวได้

int Function(int) makeAdder(int amount) {
  return (int value) => value + amount;   // จำค่า amount เอาไว้
}

final addTax = makeAdder(7);
print(addTax(100));   // 107
print(addTax(250));   // 257

ฟังก์ชันที่คืนออกมา “จำ” ค่า amount ไว้ได้ แม้ makeAdder จะทำงานจบไปแล้ว พฤติกรรมนี้เรียกว่า closure และเป็นเหตุผลว่าทำไมปุ่มแต่ละปุ่มในรายการถึงรู้ว่าตัวเองต้องเปิดงานใบไหน

ชนิด int Function(int) อ่านว่า “ฟังก์ชันที่รับ int หนึ่งตัวแล้วคืน int” — อ่านจากขวาไปซ้าย: คืน int, ชื่อชนิดคือ Function, รับ int

10. แบบฝึกหัด

เขียนฟังก์ชัน validateQuantity ที่

  1. รับข้อความจำนวนที่ผู้ใช้พิมพ์ (อาจว่างหรือไม่ใช่ตัวเลข)
  2. รับจำนวนสูงสุดแบบไม่บังคับ ผ่าน named parameter
  3. คืน String? — เป็นข้อความบอกเหตุผลเมื่อผิด และเป็น null เมื่อผ่าน

แล้วเรียกใช้กับค่า '5', '0', 'abc' และ '99' โดยกำหนดค่าสูงสุดเป็น 10

ดูแนวคำตอบและเหตุผล
String? validateQuantity(String? raw, {int? max}) {
  final value = int.tryParse(raw?.trim() ?? '');
  if (value == null) return 'กรุณากรอกตัวเลข';
  if (value <= 0) return 'จำนวนต้องมากกว่า 0';
  if (max != null && value > max) return 'เกินจำนวนคงเหลือ ($max)';
  return null;   // null = ผ่าน
}

void main() {
  for (final input in ['5', '0', 'abc', '99']) {
    final error = validateQuantity(input, max: 10);
    print('$input -> ${error ?? 'ผ่าน'}');
  }
}

ทำไมคืน String? แทน bool: เพราะผู้ใช้ต้องรู้ว่า “ผิดตรงไหน” ไม่ใช่แค่ “ผิด” และรูปแบบนี้ตรงกับสิ่งที่ฟอร์มของ Flutter ต้องการพอดี (จะเจอใน Part 3) การออกแบบให้ null แปลว่าผ่านอาจดูแปลกตอนแรก แต่ทำให้เขียน if (error != null) ได้ตรงไปตรงมา

ลองต่อ: เก็บฟังก์ชันนี้ไว้ในตัวแปรชนิด String? Function(String?) แล้วส่งเข้าไปในฟังก์ชันอื่น — นั่นคือ callback ซึ่งจะเรียนเต็ม ๆ ใน D1.11

11. สรุปท้ายบท

  • ฟังก์ชันคือการตั้งชื่อให้ชุดของงาน เพื่อเรียกซ้ำและแก้ที่เดียว
  • บรรทัดแรกของฟังก์ชันต้องบอกได้ว่า รับอะไร คืนอะไร ทำอะไร
  • parameter มี 3 แบบ: ตำแหน่ง, ตำแหน่งไม่บังคับ, และมีชื่อ — Flutter ใช้แบบมีชื่อเป็นหลัก
  • ฟังก์ชันเป็นค่าได้: f คือตัวฟังก์ชัน ส่วน f() คือการเรียก
  • closure ทำให้ฟังก์ชันจำค่ารอบตัวไว้ได้
