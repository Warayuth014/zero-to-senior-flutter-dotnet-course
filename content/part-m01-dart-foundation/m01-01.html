1. Dart คืออะไร

Dart คือภาษาโปรแกรมที่เราใช้เขียน Flutter โปรแกรม Dart อ่านคำสั่งจากบนลงล่าง โดยเริ่มทำงานที่ฟังก์ชันชื่อ main เสมอ ส่วน Flutter คือชุดเครื่องมือที่นำภาษา Dart ไปสร้างหน้าจอและแอปหลาย platform

คำจำแบบง่ายตัวอย่าง
Dartภาษาที่เราเขียนตัวแปร, function, class
Flutterเครื่องมือสร้างแอปด้วย DartText, Button, Screen
.NET APIระบบหลังบ้านที่แอปคุยด้วยภายหลังlogin, อ่าน/บันทึกสินค้า

2. โปรแกรมที่เล็กที่สุด

void main() {
  print('สวัสดี Dart');
}

void บอกว่า function นี้ไม่ส่งค่ากลับ, main() คือจุดเริ่ม, วงเล็บปีกกา { } ครอบชุดคำสั่ง และเครื่องหมาย ; ปิดหนึ่งคำสั่ง ภาษา Dart แยกตัวพิมพ์เล็ก–ใหญ่ จึงต้องเขียน main และ print ให้ตรง

เปิด PowerShell ที่โฟลเดอร์คอร์ส แล้วรัน:

ถ้าเห็นชื่อคลัง จำนวนสินค้า และสถานะ แปลว่า Dart SDK ทำงานแล้ว หากไม่พบคำสั่ง dart ให้ย้อนกลับไปตรวจ PATH และ flutter doctor ใน Part 0

4. ตัวแปรคือกล่องที่มีชื่อ

final warehouseName = 'Bangkok DC';
var itemCount = 3;

itemCount = itemCount + 1;
print('$warehouseName มีสินค้า $itemCount รายการ');

final เหมาะกับค่าที่กำหนดครั้งเดียว ส่วน var ให้ Dart อนุมานชนิดและเปลี่ยนค่าได้ การเขียน $ชื่อ ในข้อความเรียกว่า string interpolation

อย่าสับสน: var ไม่ได้แปลว่าไม่มี type หลังอนุมานเป็น int แล้ว ตัวแปรนี้จะรับข้อความไม่ได้

5. Comment มีไว้บอกเหตุผล

// เพิ่มสินค้าที่เพิ่งสแกนสำเร็จ
itemCount = itemCount + 1;

/* comment หลายบรรทัด
   ใช้เมื่อจำเป็นจริง ๆ */

Comment ไม่ถูกรัน ควรอธิบายว่า “ทำไม” มากกว่าทวนว่าโค้ด “ทำอะไร” และอย่าเก็บโค้ดเก่าทั้งก้อนไว้ใน comment เพราะ Git เก็บประวัติให้เราแล้ว

6. ลองผิดอย่างมีหลักฐาน

  1. ลบ ; หลัง print แล้วรัน ดูบรรทัด error แรก
  2. แก้กลับและรันจนผ่าน
  3. เปลี่ยนชื่อคลังและจำนวนเริ่มต้น
  4. เพิ่มข้อความอีกหนึ่งบรรทัด เช่น พร้อมเริ่มเรียน Flutter

เป้าหมายไม่ใช่จำ error แต่ฝึกวงจร แก้หนึ่งจุด → รัน → อ่านผล ซึ่งจะใช้ตลอดคอร์ส

7. แบบฝึกหัด

เพิ่มตัวแปร scannedBy แล้วแสดงผลเป็น “Bangkok DC มีสินค้า 4 รายการ — ตรวจโดย Somchai” โดยใช้ตัวแปรทุกค่า ห้ามพิมพ์ผลลัพธ์สำเร็จรูปทั้งประโยค

ดูแนวคำตอบหลังจากลองเอง
final warehouseName = 'Bangkok DC';
final scannedBy = 'Somchai';
var itemCount = 3;
itemCount = itemCount + 1;

print('$warehouseName มีสินค้า $itemCount รายการ — ตรวจโดย $scannedBy');

8. สรุปก่อนบทถัดไป

  • ทุกโปรแกรม Dart เริ่มที่ main()
  • print ช่วยดูผลลัพธ์และพิสูจน์ความเข้าใจ
  • final ใช้กับค่าที่ไม่เปลี่ยน; var ใช้กับค่าที่เปลี่ยนได้
  • Dart มี type แม้เราให้ภาษาอนุมาน
  • แก้โค้ดทีละเรื่องและอ่าน error แรกก่อนเสมอ
