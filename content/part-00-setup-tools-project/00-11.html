Git ควรเก็บ source/config ที่สร้างผลลัพธ์ซ้ำได้ ไม่เก็บ cache/build output/secret การ ignore มากเกินก็อันตรายพอ ๆ กับน้อยเกิน เพราะอาจซ่อน platform config ที่จำเป็น

1. สิ่งที่ควร commit

  • lib/, test/, assets ที่อ้างใน pubspec
  • pubspec.yaml และ lockfile สำหรับ app
  • analysis_options.yaml
  • platform runner/build/manifest ที่ target ใช้
  • version manager/CI/scripts/docs ที่ทำ build ซ้ำได้

2. สิ่งที่ไม่ควร commit

  • .dart_tool/, build/, coverage output
  • IDE user state เช่น .idea/ ตาม policy
  • APK/AAB/debug artifacts โดยไม่มี release artifact policy
  • keystore, signing passwords, API tokens, private certificates
  • local server address/user-specific config หากไม่ใช่ safe example

สองแอป ignore Flutter cache, build, coverage และ Android output folders ตาม template

3. Secret ไม่ใช่แค่ไฟล์ .env

ตรวจ source, JSON, Gradle properties, shell scripts, CI logs, screenshots และ git history Token ที่เคย commit แล้วลบจากไฟล์ยังอยู่ใน history ต้อง revoke/rotate ก่อนพิจารณาล้าง history

4. ตรวจ ignore ด้วยหลักฐาน

git status --short
git check-ignore -v build/app/outputs/flutter-apk/app-debug.apk
git ls-files .dart_tool build
git diff --cached --check

git check-ignore บอก rule ต้นทาง ส่วน git ls-files ช่วยจับไฟล์ที่ถูก track ไปแล้ว—เพิ่ม .gitignore ภายหลังไม่ untrack อัตโนมัติ

5. อย่าทำลาย user changes

ก่อน clean/generated migration ดู git status และ diff ทุกครั้ง Dirty worktree อาจเป็นงานคนอื่นหรือ experiment ที่ยังไม่ commit ห้าม reset/checkout ทิ้งเพื่อให้คำสั่งผ่าน

6. Commit ที่ review ได้

  • feature code + tests + config ที่เกี่ยวข้อง
  • dependency upgrade แยกจาก business feature เมื่อทำได้
  • generated diff ต้องมี source/config ที่อธิบายว่ามาจากไหน
  • message บอก outcome ไม่ใช้ “update files”

7. แบบฝึกหัด

พบ android/key.properties, pubspec.lock, build/, android/app/src/main/AndroidManifest.xml ตัดสิน commit/ignore และเหตุผล

เฉลย
  • key.properties ที่มี signing secret: ignore/ใช้ secret store
  • lockfile ของ app: commit
  • build: ignore
  • manifest: commit เพราะเป็น source config ของ Android permissions/application

8. จุดพลาด

อย่า ignore ทั้ง android/ หรือ ios/ เพราะคิดว่า Flutter generate ได้ทั้งหมด โปรเจกต์จริงมี permission, signing hooks, intent filters และ native customization ที่เป็น source
