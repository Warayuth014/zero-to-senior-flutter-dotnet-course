คำสั่ง flutter run ต้องเลือก target ที่ชัด เพราะ localhost, permissions, plugins และ rendering behavior ต่างกันระหว่าง Android emulator, เครื่องจริง, Web และ Windows

1. ค้นหาและเลือก device

flutter devices
flutter emulators
flutter emulators --launch <emulator-id>
flutter run -d <device-id>

ถ้ามีหลาย device แล้วไม่ใส่ -d CLI จะถามหรือเลือกไม่ตรงที่คิด ใน script/README ให้ใช้ stable device selector เช่น windows, chrome หรือ id ที่ทีมกำหนด

2. Android emulator

ใน emulator localhost คือ Android VM ไม่ใช่ Windows host โดย emulator มาตรฐานใช้ 10.0.2.2 เข้าหา host API ต้องตรวจด้วยว่า backend listen interface/port และ firewall อนุญาต

flutter run -d emulator-5554 \
  --dart-define=WMS_API_BASE_URL=http://10.0.2.2:6191

3. Android เครื่องจริง/PDA

เครื่องจริงต้องใช้ IP ของเครื่อง backend ที่เข้าถึงได้ในเครือข่าย เช่น 192.168.x.x ไม่ใช้ 10.0.2.2 ตรวจ Wi-Fi/VPN/firewall/HTTPS certificate และ Android cleartext policy แยกจาก Dart code

adb devices
flutter run -d 127.0.0.1:16384  # ใช้ id ที่ flutter devices แสดงจริง

4. Web

flutter run -d chrome

Web ไม่มี dart:io File/Platform แบบ mobile และ browser บังคับ CORS ถ้า API ใช้งานผ่าน Postman แต่ Web ไม่ได้ ให้ตรวจ CORS/origin ไม่ใช่เพิ่ม catch ใน Flutter

5. Windows desktop

flutter run -d windows

Windows app บนเครื่องเดียวกับ API ใช้ localhost ได้และ debug เร็ว แต่ไม่พิสูจน์ Android permissions, touch/scanner behavior หรือ network จาก PDA จึงใช้เป็น feedback loop ไม่ใช่ acceptance target แทนเครื่องจริง

6. Target matrix ของ WMS

Targetใช้ทดสอบยังไม่พิสูจน์
Windowslogic/UI/API บน hostAndroid manifest/hardware
Chromeresponsive/CORS/web safetydart:io/native plugin
EmulatorAndroid build/lifecyclescanner/สัญญาณจริง
PDA จริงend-to-end/ergonomics/networkควรเป็น acceptance target

7. แบบฝึกหัด

API รันที่ Windows port 6191: ระบุ base URL สำหรับ Windows app, Android emulator และ PDA IP 192.168.1.40

เฉลย
  • Windows: http://localhost:6191
  • Android emulator มาตรฐาน: http://10.0.2.2:6191
  • PDA: http://192.168.1.40:6191 โดย backend/firewall ต้องรับจาก LAN

8. จุดพลาด

“แอปเปิดได้” ไม่เท่ากับ “target พร้อม production” ต้องทดสอบ API address, permission, scanner input, app lifecycle และ poor network บนอุปกรณ์จริง
