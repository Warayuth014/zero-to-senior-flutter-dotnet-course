3. Lab B: wms_absolute_mobile

cd C:\Users\User\Desktop\wms_absolute_mobile

จุดอ่าน: main() await language/connection ก่อน runApp → สร้าง AuthRepository(ApiClient) → LoginScreen ต้องตอบได้ว่าเหตุใด connection load ต้องเสร็จก่อน request แรก

4. ทดสอบบน Android/PDA

flutter devices
flutter run -d <android-device-id> \
  --dart-define=WMS_API_BASE_URL=http://<server-ip>:6191

ใช้ config mechanism ที่โปรเจกต์รองรับจริง wmsapp มี settings/base discovery ส่วน absolute มี connection profiles และ optional dart-define override อย่า hardcode IP ลง source เพื่อให้ lab ผ่าน
