ระดับ: BeginnerMini Project แรกผลลัพธ์: Warehouse Counter
ประกอบสิ่งที่เรียน: รันแอป แก้ UI ใช้ Hot Reload, Analyzer, Debuggerและ Git โดยยังไม่ต้องเข้าใจ syntaxทุกบรรทัด Dart Foundationจะย้อนมาอธิบายทีละส่วน

1. หน้าจอที่ต้องการ

แสดงชื่อ “Warehouse Counter”, จำนวนสินค้าที่นับได้ และปุ่มเพิ่ม/ล้าง เป้าหมายคือเห็น input → ค่าเปลี่ยน → UIเปลี่ยน

2. รัน Lab ที่เตรียมไว้

Set-Location .\labs\flutter_wms_companion
flutter run -t lib/beginner_main.dart

หากมีหลาย deviceให้เติม -d <device-id>

3. ทดลองตาม Scenario

  1. กด “เพิ่มสินค้า” สามครั้ง ต้องเห็น 3
  2. กด “ล้างจำนวน” ต้องกลับ 0
  3. แก้ชื่อคลังใน codeแล้ว Hot Reload
  4. วาง breakpointตอนเพิ่มและดูค่า count

4. อ่าน Code แค่สามจุด

int count = 0;                     // ค่าปัจจุบัน
setState(() => count++);           // เปลี่ยนค่า
Text('$count รายการ');             // แสดงค่า

ยังไม่ต้องจำ class/override/build เราจะอธิบาย variableและ functionใน Dart Foundation แล้วกลับมาอ่าน codeนี้ใหม่

5. Quality Check

dart format lib test
flutter analyze --no-pub
flutter test --no-pub

Labมี widget testตรวจการเพิ่มและล้างจำนวน ทำให้การแก้ครั้งต่อไปมี safety net

6. แบบฝึกหัด

เพิ่มปุ่ม “เพิ่ม 5” โดยเลียนแบบปุ่มเพิ่มหนึ่ง แล้วเพิ่ม testว่าจาก 0กลายเป็น 5

แนวคำตอบ
onPressed: () => setState(() => count += 5)

ใน testให้ tapปุ่มแล้ว pump ก่อนตรวจข้อความ 5 รายการ

7. Definition of Done

  • รันบน deviceของตัวเองได้
  • เพิ่มและล้างจำนวนได้
  • format/analyze/testผ่าน
  • commitเฉพาะไฟล์ที่ตั้งใจแก้
  • อธิบายได้ว่า inputใดทำให้ตัวเลขเปลี่ยน

8. สรุปและบทถัดไป

คุณมี Flutter appแรกที่รันและทดสอบได้แล้ว ต่อไป Dart Foundationจะสอนว่า int, function, classและ asyncคืออะไรจากตัวอย่างเล็ก ก่อนกลับมาสร้าง UIที่ซับซ้อนขึ้น
