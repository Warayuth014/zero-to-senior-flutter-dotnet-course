ระดับ: เริ่มจากศูนย์ระบบ: Windowsผลลัพธ์: เรียก flutter ได้จาก Terminal
เป้าหมาย: ติดตั้ง Flutter SDK ไว้ในตำแหน่งที่ดูแลง่าย และยืนยันว่า Windows เรียกคำสั่ง flutter จาก Terminal ได้

1. สิ่งที่กำลังติดตั้ง

Flutter SDK เป็นโฟลเดอร์เครื่องมือ ไม่ใช่แอปที่กด Next อย่างเดียว ภายในมีคำสั่ง flutter, Dart SDK และไฟล์ที่ใช้ build หลาย platform

เราจะทำสามขั้น: ดาวน์โหลด → แตกไฟล์ → เพิ่มโฟลเดอร์ bin เข้า PATH

2. เตรียมพื้นที่

สร้างโฟลเดอร์ path สั้นที่ผู้ใช้เขียนได้ เช่น C:\dev แล้วแตก Flutter เป็น C:\dev\flutter

หลีกเลี่ยง: Program Files, โฟลเดอร์ที่ต้องใช้ Administrator, OneDrive ที่ sync ตลอดเวลา และ path ที่ซ้อนยาวมาก เพราะอาจทำให้ permission หรือ build tools มีปัญหา

3. ดาวน์โหลด Stable Channel

  1. เปิดหน้า Install ของ Flutter
  2. เลือก Windows และดาวน์โหลด Stable SDK
  3. ตรวจว่าไฟล์ดาวน์โหลดจบสมบูรณ์
  4. แตกไฟล์ลง C:\dev

หลังแตกแล้วไฟล์ C:\dev\flutter\bin\flutter.bat ต้องมีอยู่จริง หากได้ path ซ้อน flutter\flutter\bin ให้ตรวจตำแหน่งแตกไฟล์ใหม่

4. PATH คืออะไร

PATH คือรายชื่อโฟลเดอร์ที่ Terminal ใช้ค้นหา command เมื่อเราพิมพ์ flutter Windows จะไล่หาไฟล์ flutter ในแต่ละโฟลเดอร์

เพิ่มรายการนี้ใน User PATH:
C:\dev\flutter\bin

ใช้ User PATH ได้โดยไม่ต้องแก้ System PATH สำหรับผู้ใช้คนอื่นทั้งเครื่อง

5. เปิด Terminal ใหม่แล้วตรวจ

flutter --version
dart --version
where.exe flutter
where.exe dart

where.exe บอกตำแหน่งไฟล์ที่ถูกเรียก ทั้ง Flutter และ Dart ควรมาจาก SDK ชุดเดียวกันใต้ C:\dev\flutter

6. ติดตั้ง Editor

VS Code

เบา เริ่มง่าย ติดตั้ง Flutter extension ซึ่งจะติดตั้ง Dart extension ตามมา

Android Studio

ใช้จัดการ Android SDK/Emulator ได้สะดวก และเขียน Flutter ได้เช่นกัน

เลือก editor ที่ถนัดได้ แต่ Android Studio ยังมีประโยชน์สำหรับ Android toolchain แม้เขียน code ใน VS Code

7. Flutter กับ Dart เวอร์ชันต้องคู่กัน

Flutter SDK รวม Dart version ที่ผ่านการทดสอบร่วมกันแล้ว จึงไม่ควรดาวน์โหลด Dart แยกแล้วบังคับให้ Flutter ใช้คนละชุด

Flutter SDK
└── Dart SDK เวอร์ชันที่ release นั้นกำหนด

8. ปัญหาที่พบบ่อย

อาการสาเหตุที่น่าจะเป็นตรวจอย่างไร
flutter ไม่ใช่ commandPATH ยังไม่ถูกหรือ Terminal เก่าเปิด Terminal ใหม่และดู User PATH
where พบหลาย pathเคยติดตั้งหลาย SDKเก็บ path ที่ต้องใช้และลบรายการเก่า
Permission deniedSDK อยู่โฟลเดอร์ protectedย้ายไป path ที่ผู้ใช้เขียนได้

ผ่านเมื่อใด

10. สรุปจำเร็ว

ติดตั้ง SDK สำเร็จยังไม่แปลว่า build Android ได้ บทนี้ยืนยันเฉพาะ command ระดับเครื่อง บทถัดไปจะใช้ flutter doctor ตรวจ toolchain แต่ละ target
