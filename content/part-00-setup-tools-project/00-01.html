Baseline ของคอร์สบนเครื่องนี้: Flutter 3.41.7 stable, Dart 3.11.5, DevTools 2.54.2 บน Windows โดย Android/Windows/Web toolchains ผ่าน flutter doctor ทั้งหมด เวอร์ชันในอนาคตอาจเปลี่ยน แต่หลักการอ่านผลเหมือนเดิม

1. SDK ที่ต้องมีจริง

Flutter SDK รวม framework, engine artifacts, command-line tools และ Dart SDK ที่เข้ากันมาแล้ว จึงไม่ควรติดตั้ง Dart คนละเวอร์ชันแล้วบังคับ Flutter ใช้มั่ว ๆ สำหรับ Windows ให้โฟลเดอร์ SDK อยู่ path สั้นและเขียนได้ เช่น C:\dev\flutter แล้วเพิ่ม C:\dev\flutter\bin เข้า PATH

flutter --version
dart --version
where.exe flutter
where.exe dart

สองคำสั่งสุดท้ายช่วยจับปัญหา PATH มี Flutter หลายชุดหรือ shell ใช้ SDK คนละตัวกับ IDE

2. อ่าน flutter doctor เป็นระบบ

flutter doctor -v
หมวดจำเป็นเมื่อหลักฐานที่ต้องดู
Flutterทุก targetchannel, path, framework/Dart version
Android toolchainAPK/device/PDASDK, build-tools, Java, licenses
ChromeWebbrowser executable
Visual StudioWindows desktopDesktop C++ workload และ Windows SDK

เครื่องหมายเตือนใน target ที่ไม่ใช้ เช่น Xcode บน Windows ไม่ได้แปลว่า Android build พัง ให้แก้ตาม target ของโปรเจกต์

3. Android prerequisites

  1. ติดตั้ง Android Studio/SDK Platform/Build-tools
  2. ให้ Flutter เห็น JDK ที่เข้ากับ Android Gradle Plugin
  3. รัน flutter doctor --android-licenses
  4. เปิด USB debugging หรือสร้าง emulator
  5. ยืนยันด้วย adb devices และ flutter devices

สถานะ unauthorized ต้องอนุมัติบนโทรศัพท์ ไม่ใช่แก้ Dart code

4. แยกปัญหา environment จาก project

ถ้า flutter doctor พัง แปลว่าเครื่องมือระดับเครื่องยังไม่พร้อม ถ้า doctor ผ่านแต่ flutter pub get พัง ให้ดู SDK constraint/dependency ถ้า pub ผ่านแต่ build พัง ให้ดู platform project/Gradle/manifest ส่วน app เปิดได้แต่ API ต่อไม่ได้คือ runtime configuration/network

5. หลักฐานจากเครื่องและโปรเจกต์จริง

  • Flutter SDK อยู่ C:\dev\flutter
  • Android SDK อยู่ใต้ LocalAppData และใช้ JDK จาก Android Studio
  • มี physical/virtual Android, Windows, Chrome และ Edge เป็น device target
  • ทั้ง wmsapp และ wms_absolute_mobile มี platform folders หลายชุด แต่ production target หลักคือ mobile/PDA

6. แบบฝึกหัด

รัน 4 คำสั่ง: flutter --version, where flutter, flutter doctor -v, flutter devices แล้วบันทึก SDK path, Dart version, target ที่พร้อม และ warning ที่ไม่เกี่ยวกับ target

เกณฑ์ตรวจคำตอบ

ต้องแยกได้ว่า SDK/toolchain/device เป็นสามชั้น ไม่สรุปเพียง “doctor เขียว” และต้องระบุ device id ที่จะใช้กับ flutter run -d ได้

7. Troubleshooting เร็ว

  • ติดตั้งแล้ว command ไม่เจอ: เปิด terminal/IDE ใหม่เพราะ PATH ยังไม่ refresh
  • IDE กับ terminal คนละ version: ตั้ง Flutter SDK path ใน IDE ให้ตรง where flutter
  • Android license ไม่ผ่าน: ตรวจ Java/SDK path ก่อนรับ license
  • device ไม่ขึ้น: ตรวจ cable/USB mode/ADB authorization ไม่แก้ Flutter project

8. Exit check
