1. Decode

final decoded = jsonDecode(body);
if (decoded is! Map<String, dynamic>) throw ContractException('root');

2. Cast

as assertไม่ convert; num as doubleอาจพัง

3. Pattern

ใช้ switch/type promotionตรวจ Object?ก่อนอ่าน

4. Boundary

ApiClientคืน decoded rawได้เฉพาะ repository parser ไม่ส่ง dynamicถึง widget

5. Error

แยก malformed JSON, wrong shapeและdomain validation

6. Logging

log path/type/status ไม่ dump token/PIIทั้ง body

7. แบบฝึกหัด

json['qty'] as int เมื่อ 5.0?
