fromJson คือ untrusted boundary; toJson คือ request contract ทั้งสองควร testและไม่ assumeชนิด runtime

1. Parse

factory TaskDto.fromJson(Map<String, dynamic> j) => TaskDto(
  id: requireString(j, 'id'),
  qty: readDouble(j['qty']),
);

2. Serialize

Map<String, Object?> toJson() => {'taskId': id, 'qty': qty};

3. Direction

Response DTOกับ request DTOอาจคนละ shape อย่าฝืนใช้ classเดียว

4. Unknown keys

โดยทั่วไป ignoreเพื่อ forward compatibility แต่ log schema violationสำคัญ

5. Required keys

throw typed FormatException/ContractExceptionพร้อม path ไม่ใช้ !

6. Generated code

json_serializableลด boilerplateแต่ custom converter/invariantยังต้องออกแบบ

7. แบบฝึกหัด

Serverเพิ่ม fieldใหม่ควรพังไหม?

เฉลย

ไม่ควรหาก clientไม่ใช้; missing/ชนิดผิดของ required fieldจึง failชัด

8. จุดพลาด

อย่า castตรง j['qty'] as double; JSON integerอาจเป็น int
