Nested JSONต้องตรวจ containerก่อน map และรายงาน pathของ childที่เสีย ไม่ cast list/mapลึกแบบ blind

1. Object

final raw = json['destination'];
final dto = raw is Map<String, dynamic> ? DestinationDto.fromJson(raw) : null;

2. List

final items = requireList(json, 'items')
  .mapIndexed((i, e) => TaskDto.fromJson(requireMap(e, 'items[$i]'))).toList();

3. Null elements

เลือก rejectหรือ skipพร้อม telemetry ห้าม skipเงียบใน stock transaction

4. Empty list

เป็น success emptyไม่ใช่ loading/error

5. Deep model

แยก DTOย่อยและ mapper ไม่เขียน factoryหนึ่งอันร้อยบรรทัด

6. Performance

ข้อมูลมหาศาลพิจารณา isolate/paginationหลัง profile

7. แบบฝึกหัด

itemsเป็น objectแทน array?

เฉลย

โยน contract errorที่ items ไม่พยายาม iterate map valuesโดยเดา

8. จุดพลาด
