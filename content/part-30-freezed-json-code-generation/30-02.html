แยก runtime จาก dev dependencies: annotationsถูกอ้างจาก sourceตอน runtime compile ส่วน generatorsทำงานเฉพาะช่วงพัฒนา/build

1. Runtime

freezed_annotation และ json_annotation อยู่ dependencies เพราะ annotated source/generated API import ทั้งสอง package

2. Dev

freezed, json_serializable และ build_runner อยู่ dev_dependencies เพราะใช้สร้าง source ไม่ต้องรวมเป็น app feature

3. Install

flutter pub add freezed_annotation json_annotation
flutter pub add --dev freezed json_serializable build_runner

4. เวอร์ชัน lab

lockfileนี้ resolve Freezed 3.2.5, annotations 3.1.0, json_serializable 6.14.1 และ json_annotation 4.12.0 บน Dart 3.11

5. Compatible graph

generatorหลายตัวแชร์ analyzer/build/source_gen อย่าบังคับ versionรายตัวโดยไม่ดู solver เพราะ Drift/Freezed/JSONต้องอยู่ pipelineเดียวกัน

6. Stable policy

ใช้ stableที่ solverรองรับ อ่าน changelogและ migration guideก่อน major upgrade ไม่ตาม prereleaseเพียงเพราะเลขใหม่กว่า

7. Lockfile

applicationควร commit pubspec.lock เพื่อให้เครื่องทีมและ CI resolve graphเดียวกัน แล้วใช้ dependency bot/update PRแยก

8. Checkpoint

รัน flutter pub deps และอธิบายว่า annotation, builder และ build orchestratorแต่ละตัวทำหน้าที่ใด
