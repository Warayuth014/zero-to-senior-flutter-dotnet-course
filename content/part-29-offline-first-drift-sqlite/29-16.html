1. Run API

dotnet run --project .\labs\dotnet\WmsMobileApi
  --urls http://0.0.0.0:5080

2. Run app

flutter run --project-directory .\labs\flutter_wms_companion
  -t lib/offline_main.dart
  --dart-define=WMS_API_BASE_URL=http://localhost:5080
