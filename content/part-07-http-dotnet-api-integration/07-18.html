Lab ปิด Part 7: สร้าง Flutter client ที่เรียก Minimal .NET endpoint จริง พร้อม typed DTO, grid query, ProblemDetails, timeout, health probe, tests และ log redaction

1. Acceptance criteria

  • GET tasks รองรับ search/page/pageSize และคืน items/totalCount
  • POST complete รับ typed request + idempotency key
  • 400/404/409 คืน ProblemDetails + stable code
  • Flutter แยก network/API/contract error
  • health ตรวจ service marker
  • unit/integration tests ครบ happy + failure

2. .NET contracts

record TaskDto(string TaskId, string Status, decimal Quantity);
record CompleteTaskRequest(decimal Quantity);
record GridPage<T>(IReadOnlyList<T> Items, int TotalCount);

app.MapGet("/api/WMS/tasks", (string? search, int page = 1,
  int pageSize = 20) => Results.Ok(/* GridPage */));

3. Command endpoint

app.MapPost("/api/WMS/tasks/{id}/complete",
  (string id, CompleteTaskRequest body, HttpRequest http) => {
    var key = http.Headers["Idempotency-Key"].ToString();
    if (string.IsNullOrWhiteSpace(key))
      return Results.Problem(statusCode: 400,
        title: "Missing idempotency key");
    return Results.Ok(new { taskId = id, status = "COMPLETED" });
  });

4. Flutter API

class TasksApi {

  Future<GridPage<TaskDto>> fetch({String search = ''}) async {

5. Test table

  • query อักขระพิเศษและ pagination
  • 200 grid, 204 และ malformed JSON
  • 400 validation, 409 duplicate และ 500
  • timeout/SocketException
  • retry GET เท่านั้น
  • idempotency key เดิมคืนผลเดิม
  • token ไม่อยู่ใน log
