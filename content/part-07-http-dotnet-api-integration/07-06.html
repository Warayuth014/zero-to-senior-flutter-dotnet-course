Dependency injection: รับ http.Client จากภายนอก ทำให้ production ใช้ client จริง แต่ test ควบคุม status/body/exception ได้โดยไม่เปิด server

1. Constructor injection

class ApiClient {
  ApiClient({http.Client? client})
      : _client = client ?? http.Client(),
        _ownsClient = client == null;
  final http.Client _client;
  final bool _ownsClient;
}

2. Ownership

ผู้สร้าง dependency เป็นผู้ dispose: ถ้า ApiClient สร้าง client เองจึง close เอง แต่ถ้ารับ shared client จาก composition root ต้องไม่ปิดแทนเจ้าของ

3. MockClient

final client = MockClient((request) async {
  expect(request.url.path, '/api/WMS/tasks');
  expect(request.headers['Authorization'], 'Bearer test-token');
  return http.Response('{"items":[],"totalCount":0}', 200);
});
final api = TasksApi(ApiClient(client: client));

4. ทดสอบ request ด้วย

อย่าตรวจแค่ model ที่คืนมา ให้ assert method, URL, encoded query, header และ JSON body ด้วย เพราะ bug integration จำนวนมากอยู่ฝั่ง request

5. ทดสอบ failure table

  • 200 valid/invalid JSON
  • 204 empty
  • 400 ProblemDetails
  • 401/403
  • 500 HTML proxy page
  • timeout และ ClientException

6. ไฟล์จริง

wms_absolute_mobile/lib/core/api_client.dart และ connection probe ของทั้งสองแอปรับ optional client อยู่แล้ว จึงเป็น seam สำหรับ test โดยไม่เปลี่ยน production behavior

7. แบบฝึกหัด

เขียน test ที่พิสูจน์ว่า barcode A&B 01 ถูก encode ใน query และ server decode กลับค่าเดิม

แนวคำตอบ

ตรวจ request.url.queryParameters['search'] ไม่ตรวจ raw URL string ซึ่งอ่าน percent encoding ยาก

8. หลักจำ

Inject ที่ I/O boundary, assert request + response mapping และไม่มี network จริงใน unit test
