Pure Dart test คือ feedback ที่เร็วที่สุด: ย้าย logic ออกจาก widget callback มาเป็น function/model/state machine แล้วทดสอบโดยไม่ต้อง pumpWidget

1. โครงสร้างพื้นฐาน

import 'package:flutter_test/flutter_test.dart';

void main() {
  group('normalizeBarcode', () {
    test('trims and uppercases warehouse code', () {
      expect(normalizeBarcode(' plt-001\n'), 'PLT-001');
    });
  });
}

2. Table-driven tests

for (final (raw, expected) in [
  ('P-001', 'P-001'),
  (' p-001 ', 'P-001'),
  ('', null),
]) {
  test('parse $raw', () => expect(parsePart(raw), expected));
}

เพิ่ม edge cases ได้โดยไม่ทำสำเนา setup และชื่อ case ชี้ค่าที่เสียทันที

3. State transition

final next = ReceivingState.initial().apply(
  const PartScanned('P-001'),
);
expect(next.step, ReceivingStep.serial);
expect(next.partCode, 'P-001');
expect(next.error, isNull);

ถ้า transition ต้องใช้ BuildContext แสดงว่า logic กับ UI ยังติดกันเกินไป

4. Exception และ validation

expect(
  () => Quantity.parse('-1'),
  throwsA(isA<ValidationException>()
      .having((e) => e.field, 'field', 'qty')),
);

assert type/ข้อมูลสำคัญ ไม่ล็อกข้อความทั้งประโยคจน localization ทำ test แตกโดยไม่เกี่ยว behavior

5. เวลาและ ID

final clock = FakeClock(DateTime.utc(2026, 8, 15, 9));
final ids = SequenceIds(['cmd-1']);
final command = factory.create(clock: clock, ids: ids);
expect(command.createdAt, DateTime.utc(2026, 8, 15, 9));

6. Value equality

DTO/state ควร immutable และเปรียบเทียบค่าชัดเจน ใช้ record, overridden equality หรือ matcher แยก field ห้าม assert ด้วย object identity เมื่อ business ต้องการ value equality

7. ไม่ทดสอบ private method

ทดสอบ public behavior ผ่าน input/output หาก private logic ซับซ้อนจนอยากเรียกตรง ๆ ให้ extract เป็น collaborator ที่มีความหมาย เช่น ScanValidator มากกว่าเปิด method เพื่อ test อย่างเดียว

8. แบบฝึกหัด

เขียน test ของ duplicate serial แบบ case-insensitive และ whitespace-safe

แนวคำตอบ

normalize serial ทั้งค่าที่รับใหม่และ collection เดิมก่อนเทียบ พร้อม case ของค่าใหม่, ซ้ำ, ช่องว่าง และ empty โดยไม่แตะ widget
