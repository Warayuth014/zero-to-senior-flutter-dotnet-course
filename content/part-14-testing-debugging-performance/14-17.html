Lab ปลาย Part: สร้าง safety net ของ receiving flow ตั้งแต่ JSON → repository → Store → widget/scanner/navigation โดยใช้ fake repositories แบบ wms_absolute_mobile และนำหลักไปวางรอบ wmsapp ก่อน refactor screen ใหญ่

1. Acceptance criteria

  1. โหลด open orders และ empty/error/retry
  2. scan part/serial/pallet ตาม step
  3. กัน duplicate และ double-submit
  4. Back ลด step, exit/resume ตาม policy
  5. timeout/stale response ไม่ทับ state ใหม่
  6. scanner อยู่ fixed บน PDA และ focus กลับหลัง error

2. Test seam ที่ต้องมี

class ReceivingStore extends ChangeNotifier {
  ReceivingStore({
    required ReceivingRepository repository,
    required Clock clock,
    required IdGenerator ids,
  });
}

screen รับ store/repository จาก composition root ไม่เรียก singleton HTTP ภายใน callback

3. Fake repository

final repo = FakeReceivingRepository(openOrders: [order]);
repo.receiveGate = Completer<void>();
final store = ReceivingStore(
  repository: repo,
  clock: FixedClock(now),
  ids: SequenceIds(['cmd-1']),
);
addTearDown(store.dispose);

4. Unit/contract layer

ทดสอบ normalization/duplicate/qty/state reducer แบบ pure Dart; fixture response จาก .NET ครอบคลุม null/unknown status/time; MockClient ตรวจ path/auth/body และ mapping 400/401/409/500/timeout โดยไม่เปิด network

5. Store race layer

final first = repo.queueFetch();
final second = repo.queueFetch();
store.search('A');
store.search('B');
second.complete(pageB);
first.complete(pageA);
await Future.wait([firstOperation, secondOperation]);
expect(store.query, 'B');
expect(store.items, pageB.items);

6. Widget flow

pump ที่ 390×560, enterText + receiveAction(done), assert loading/step/error/focus, scan ซ้ำขณะ receive pending และ confirm repository call หนึ่งครั้ง จากนั้น drag results แล้ว assert scanner y ไม่เปลี่ยนและไม่มี overflow

7. Navigation + lifecycle

ทดสอบ business Back, system back, bottom navigation reset, resume draft, dispose ก่อน response และ route result จาก pallet/dialog ปิด timer/subscription ทุกเส้นทางและไม่ใช้ pumpAndSettle ขณะมี polling ไม่สิ้นสุด

8. Definition of Done

analyze/test ผ่านซ้ำได้โดยไม่ network/sleep, ทุก critical failure มี test, suite อ่านเป็น receiving specification, profile trace บน PDA ไม่มี jank hotspot ใหม่ และ bug ที่พบทุกตัวเพิ่ม regression test ระดับต่ำที่สุดที่จับได้
