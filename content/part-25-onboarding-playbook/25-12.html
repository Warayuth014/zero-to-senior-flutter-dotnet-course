Glossary ใช้เพื่อคุยให้ตรงกัน: เก็บ canonical term/owner/boundary ไม่แปลคำจนความหมายทางเทคนิคหรือ WMSเปลี่ยน

1. Flutter runtime

Widget immutable configuration; Element mounted identity; State mutable lifecycle; BuildContextตำแหน่ง Element; RenderObject layout/paint ไม่เรียกทุกอย่างว่า “หน้า”

2. State/async

setState mark local subtree dirty; ChangeNotifier publish invalidation; generation latest-operation token; single-flightหนึ่ง requestพร้อมกัน; idempotencyทำซ้ำแล้วผล domainไม่ซ้ำ

3. Architecture

DTO wire shape; domain model business meaning/invariant; repository consumer-facing data boundary; store/controller feature state/commands; composition rootจุดประกอบ dependencies

4. HTTP/.NET

route/endpoint verb+path handler; model binding request→DTO; ProblemDetailsstructured error; JWTsigned claims token; 401not authenticated; 403authenticatedแต่ไม่มีสิทธิ์; 409state conflict

5. Realtime

SignalR Hubconnection/event boundary; reconnectสร้าง connectionใหม่; reconciliationโหลด authoritative snapshotหลัง uncertainty; pollingqueryตามเวลา; eventไม่เท่ากับ source of truthเสมอ

6. WMS entities

Inbound/Receivingรับเข้า; Putawayย้ายเข้าที่เก็บ; Retrieve/Pickingหยิบออก; Relocateย้ายตำแหน่ง; Pallet/Containerหน่วยถือสินค้า; Location/Destinationphysical/logical endpoint

7. Operations

Dispatchมอบ taskให้ carrier; AGV/Forkliftautomatic/manual carrier; Cycle Countตรวจยอด; Stagedอยู่จุดพักก่อน transition; ESS/ASRSexternal automation authority; Auditหลักฐานใครทำอะไรเมื่อใด

8. Team glossary rule

เพิ่มคำพร้อม canonical code/server status, Thai/English label, ownerและตัวอย่าง ห้ามใช้ display labelเป็น API keyหรือเรียก “complete”เหมือนกันเมื่อแต่ละ flowมี authority/endpointต่างกัน
