AppLanguageController เป็น SSOT: ถือ enum/Locale, โหลดและ persist preference, notifyหนึ่งครั้งเมื่อเปลี่ยน และไม่แปล business dataเอง

1. Controller shape

enum AppLanguage { english, thai }
class AppLanguageController extends ChangeNotifier {
  AppLanguage _language = AppLanguage.english;
  Locale get locale => Locale(_language == AppLanguage.thai ? 'th' : 'en');
  bool get isThai => _language == AppLanguage.thai;
}

2. Load before UI

โหลดระหว่าง bootstrapเพื่อลด flashภาษา default หาก plugin unavailableใน testให้ fallback deterministicและยัง switch in-memoryได้

3. Set flow

ถ้าค่าเดิม return; update memory+notifyเพื่อ UIตอบสนองเร็ว แล้ว persistด้วย error policy หรือ persistก่อน notifyหาก productต้อง guaranteeข้าม restart—ระบุให้ชัด

4. No global strings in models

Domain/modelไม่เรียก singleton tr เพราะผลลัพธ์เปลี่ยนตาม global stateและ testยาก ให้ UI/localization mapperแปล typed enum

5. LanguageButton

ปุ่มต้องบอก actionหรือ current codeชัด, touch target, tooltip localizedและไม่ใช้ธงชาติแทนภาษาเสมอไป ของจริงแสดงไอคอนโลก + TH/EN

6. Persistence key

ใช้ namespaced/versioned keyเช่น app.v1.language และรองรับค่า unknownด้วย default ไม่ throwตอน startup

7. แบบฝึกหัด

เขียน preferencesล้มหลัง notifyควร revertภาษาไหม?

แนวคำตอบ

ขึ้นกับ contract; ของจริงคงภาษาปัจจุบันและเปิดใหม่กลับ default ควร log/แจ้งเฉพาะถ้าการ persistสำคัญ ไม่ crash UI

8. Controller tests

load th/en/unknown/failure, no notifyเมื่อค่าเดิม, notifyครั้งเดียว, persist valueถูกและ MaterialApp localeเปลี่ยนตาม
