เลือก icon systemตามงาน: Materialสำหรับมาตรฐาน platform, Font Awesome/MDIสำหรับ glyphเฉพาะ และ SVGสำหรับ brand/warehouse artที่ต้องคุมรูปทรง

1. Material icons

uses-material-design: true ทำให้ Icons.* พร้อมใช้และเข้ากับ IconTheme/semantic labels เหมาะ actionsทั่วไปเช่น back, settings, refresh

2. Icon packages

font_awesome_flutter หรือ material_design_icons_flutter เพิ่มตัวเลือกแต่เพิ่ม dependency/font footprintและชื่อ glyphอาจเปลี่ยนตาม version ให้รวม mappingใน design system

3. SVG

SvgPicture.asset(
  'assets/icons/wms/pallet.svg',
  width: 24, height: 24,
  colorFilter: ColorFilter.mode(
    Theme.of(context).colorScheme.primary, BlendMode.srcIn),
  semanticsLabel: tr('Pallet', 'พาเลท'),
);

4. Icon meaning

อย่าใช้ iconกำกวมโดยไม่มี label/tooltipโดยเฉพาะ PDA icon-only action และอย่าใช้สีอย่างเดียวบอก error/success

5. Alignment/optical size

glyphจากหลายชุดมี baseline/stroke/visual weightต่างกัน กำหนด container sizeและตรวจจริง ไม่คิดว่า size: 24 ดูเท่ากันทุก library

6. Licensing/tree shaking

ตรวจ licenseและ dynamic icon lookupอาจขัด tree shaking หากสร้าง IconData runtime ต้องพิจารณาขนาด/ข้อจำกัด release build

7. แบบฝึกหัด

brand logoควรทำเป็น Font Awesomeใกล้เคียงหรือ asset SVGจริง?

เฉลย

ใช้ approved SVG/assetจริงเพื่อ brand accuracy; package iconใช้สำหรับ functional icons

8. Accessibility

icon buttonมี tooltip/semantic label, touch target≥48, contrastพอ, disabled stateชัดและ screen readerไม่อ่าน decorative iconซ้ำกับ Text
