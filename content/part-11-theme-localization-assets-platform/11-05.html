flutter_localizations ให้ widgetระบบแปลได้: Material date picker, pagination labels, text directionและ built-in controlsต้องมี delegates—notแค่ข้อความของแอป

1. Dependency

dependencies:
  flutter_localizations:
    sdk: flutter
  intl: any

version intlต้องเข้ากับ Flutter SDK resolution ไม่ pinขัดกันโดยไม่ตรวจ

2. Delegates

localizationsDelegates: const [
  GlobalMaterialLocalizations.delegate,
  GlobalWidgetsLocalizations.delegate,
  GlobalCupertinoLocalizations.delegate,
],

3. supportedLocales

supportedLocales: const [Locale('en'), Locale('th')],

รายการนี้เป็น contractให้ frameworkเลือก localeและ fallback

4. What it does not do

ไม่แปลข้อความ businessของแอปอัตโนมัติ ต้องมี tr/ARB และ backend-owned product/location/statusควรกำหนดว่าจะ translateหรือแสดง verbatim

5. Locale resolution

ถ้า deviceใช้ localeไม่รองรับ MaterialAppเลือก fallbackตาม callback/default ควรกำหนด deterministicและเก็บ user preferenceแยกจาก system locale

6. Thai specifics

date picker/Material labelsเปลี่ยนตาม localeแต่ business date/timezoneยังต้อง formatด้วย intlและ contract UTC ไม่ถือว่า localizationแก้ timezoneให้

7. แบบฝึกหัด

เปลี่ยน app localeเป็น thแต่ปุ่ม Cancelใน date pickerยังอังกฤษควรตรวจอะไร?

เฉลย

flutter_localizations dependency, delegates, supportedLocalesและ localeที่ MaterialAppได้รับจริง

8. Smoke tests

Material widgetsไทย/อังกฤษ, unsupported locale fallback, localeเปลี่ยน runtimeและไม่มี missing delegate exception
