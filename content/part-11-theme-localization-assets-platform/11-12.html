Launcher iconเป็น platform build asset: ใช้ sourceภาพที่มี safe zone/contrastและ generateผ่าน config ไม่เปลี่ยนด้วย runtime Flutter theme

1. Config

dev_dependencies:
  flutter_launcher_icons: ^0.14.4

flutter_launcher_icons:
  android: true
  ios: true
  image_path: assets/icons/app_icon.png
  adaptive_icon_background: '#FFFFFF'
  adaptive_icon_foreground: assets/icons/app_icon_foreground.png

2. Generate

dart run flutter_launcher_icons

ตรวจ generated platform filesใน gitตาม workflowของ repoและ rebuild/installใหม่เพราะ launcher cacheไม่อัปเดตด้วย hot reload

3. Source quality

ใช้ square high-resolution master, ไม่มีตัวหนังสือเล็ก/ขอบชิด, alpha/backgroundตรง platform และดูได้ทั้ง light/dark launcher

4. Adaptive icon

Android maskเป็น circle/squircleรูปต่างกัน Foregroundต้องอยู่ safe zoneและ backgroundแยก layer ไม่เอา legacy full iconมาเป็น foregroundตรง ๆ

5. Flavors/environments

DEV/UAT/PRODควร icon/name/bannerต่างเพื่อลดเปิดผิดแอป อาจใช้ config/sourceแยกต่อ flavorและ CI generate deterministic

6. Branding governance

เก็บ approved master/licenseและไม่ stretch/recolor logoเอง ขนาด generatedไม่ใช่ design source

7. แบบฝึกหัด

เปลี่ยน icon configแล้ว emulatorยังรูปเก่าควรทำอะไร?

เฉลย

run generator, clean/rebuildและ uninstall/reinstallหรือ clear launcher cache ไม่แก้ Image.assetใน UI

8. Release checklist

Android adaptive/legacy, iOS sizesถ้ารองรับ, Windows/web assets, transparent edge, DEV/PROD distinctionและ store artworkแยกจาก launcher asset
