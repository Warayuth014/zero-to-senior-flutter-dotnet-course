Lab: อ่าน Dashboard widget tree ของ wms_absolute_mobile จาก runtime ownerลงถึง responsive tiles แล้วพิสูจน์ identity/rebuild/local stateด้วย Inspectorและ widget tests ไม่ใช่แค่วาดกล่องจากภาพ

1. Root-to-dashboard trace

main
└─ WmsApp (ListenableBuilder: language)
   └─ MaterialApp + app-wide SafeArea
      └─ LoginScreen
         └─ WarehouseShell (State + WarehouseStore owner)
            └─ Scaffold
               ├─ ListenableBuilder(store): body
               │  └─ AnimatedSwitcher
               │     └─ KeyedSubtree(ValueKey(store.screen))
               │        └─ HomeView
               └─ ListenableBuilder(store): bottom nav

2. HomeView tree

HomeView (Stateless, receives store)
└─ LayoutBuilder(page constraints)
   └─ Padding → Column
      ├─ DispatchTile(callback → store.nav)
      ├─ Expanded
      │  └─ LayoutBuilder(grid constraints)
      │     └─ GridView → Tile[] → HomeIcon/AutoSizeText
      └─ SummaryCard (Stateful: list/chart local mode)

Responsiveค่ามาจาก constraints; business counts/navigationมาจาก store; list/chartเป็น local presentation state นี่คือ ownerสามระดับที่ต้องแยก

3. Identity map

  • ValueKey(store.screen): screen identityสำหรับ AnimatedSwitcher
  • title/sub ValueKeys: identityของ responsive AutoSizeText
  • dashboard list/chart keys: AnimatedSwitcher state/animationและ test finder
  • GlobalKey Formอยู่ Loginไม่ใช่ Dashboard เพราะ operation validateอยู่ที่นั่น

4. Rebuild experiment

  1. เปิด Inspector/track rebuilds
  2. สลับภาษา: root MaterialApp/inherited localization subtreeเปลี่ยน
  3. store notify badge: shell listenersและ dependent body/nav build
  4. สลับ list/chart: SummaryCard setState subtreeเฉพาะ card
  5. resize Windows/PDA: LayoutBuildersคำนวณ compact/narrow/extentใหม่

บันทึกสิ่งที่สังเกตจริง ไม่สรุปจากทฤษฎีอย่างเดียว

6. Widget test assignment

testWidgets('dashboard switches list to chart', (tester) async {
  await tester.pumpWidget(buildDashboard(fakeStore));
  expect(find.byKey(const ValueKey('dashboard-list')), findsOneWidget);
  await tester.tap(find.byKey(const ValueKey('dashboard-mode-chart')));
  await tester.pumpAndSettle();
  expect(find.byKey(const ValueKey('dashboard-chart')), findsOneWidget);
});

เพิ่ม test badge/store notifyและ narrow constraintอีกอย่างละหนึ่งเคส โดยใช้ fakeไม่ต่อ network
