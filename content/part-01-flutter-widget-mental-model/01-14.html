InheritedWidget ส่งข้อมูลลง treeและบันทึกว่า Elementใด depend เมื่อค่าเปลี่ยน framework rebuildเฉพาะ dependents เป็นฐานของ Theme.of, MediaQuery, Localizations และ state packagesหลายตัว

1. Conceptual API

class SessionScope extends InheritedWidget {
  const SessionScope({super.key, required this.session, required super.child});
  final AuthSession session;

  static SessionScope of(BuildContext context) =>
      context.dependOnInheritedWidgetOfExactType<SessionScope>()!;

  @override
  bool updateShouldNotify(SessionScope old) => old.session != session;
}

2. of(context) ทำ dependency

เมื่อ childเรียก SessionScope.of(context) Elementนั้นถูกลงทะเบียน หาก scope widgetใหม่ตัดสิน notify child buildใหม่ ไม่ต้องส่ง sessionผ่าน constructorทุกระดับที่ไม่ใช้มัน

3. ตัวอย่าง built-inจริง

  • Theme.of(context): color/text/theme
  • MediaQuery.of(context): size/padding/viewInsets
  • Localizations: locale/resources
  • Navigator.of(context): หา stateของ ancestor navigator (กลไกภายในสัมพันธ์กับ tree)

wmsappอ่าน Themeในหลาย widgets; scan sheetsอ่าน MediaQueryของ contextเฉพาะตำแหน่ง

4. InheritedWidget เองไม่ได้ mutate

มันเป็น immutable configเหมือน widgetอื่น Mutable sourceมักอยู่ StatefulWidget/ChangeNotifier แล้วใช้ InheritedNotifier/Providerครอบ การออกแบบต้องแยก ownerจาก distribution mechanism

5. Granularity ของ updateShouldNotify

คืน trueทุกครั้งทำ dependentsกว้าง rebuild; เทียบไม่ครบทำ UI stale ถ้า stateใหญ่และ consumersใช้คนละ sliceให้แยก scopes/aspects/selectorsหรือ view models แทน God scopeหนึ่งก้อน

6. Constructor injection vs inherited

ส่ง constructorเมื่อ dependencyตรง/ใกล้และอยากเห็นชัด; inheritedเมื่อ descendantจำนวนมากข้าม intermediate widgetsและ lifetimeเป็น subtree policy เช่น theme/session อย่าใช้ inheritedเพียงลด parameterสองชั้นจน dependencyซ่อนหมด

แนวคำตอบ

ตอนนี้ constructor injectionใน absoluteชัดและจำนวนชั้นไม่มากจึงเหมาะ หากหลาย featureลึกต้องใช้ session/read-only authอาจสร้าง AuthScope/Providerที่ app/session root แต่ commandและlifetimeยังอยู่ AuthRepository พร้อม tests ไม่ให้ widgetsแก้ tokenตรง
