2. Pattern อ่าน method

Future<ApiResult<T>> action(...) async {
  final response = await _post('/domain/action', body);
  if (!response.success) return ApiResult.error(...);
  return ApiResult.success(T.fromJson(response.data!));
}

5. Typed vs dynamic

บาง methodคืน modelชัด เช่น UnloadSession/SortingDashboardData แต่ command responseหลายจุดยังเป็น Map<String,dynamic> ทำให้ key knowledgeไหลเข้า screenและ contract testsยากขึ้น

6. Error propagation

extensionsมักส่ง response.errorต่อแล้ว screensใช้ fallbackข้อความไทย ต้องตรวจว่า statusCodeถูกเก็บหรือหายเพราะสร้าง ApiResult.errorใหม่ หาก 404/409/401มี business meaningควร map typed failure

7. Part trade-off

ช่วยแบ่งไฟล์โดยยังใช้ private method แต่ทั้งหมดเป็น libraryเดียว, dependency directionไม่ถูกบังคับและ compile couplingสูง ทางเลือกคือ domain API classesที่รับ transport interface ทำให้ fake/ownershipแยกชัด
