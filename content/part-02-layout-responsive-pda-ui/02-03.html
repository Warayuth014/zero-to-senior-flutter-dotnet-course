Expanded, Flexible และ Spacer ใช้ได้เมื่อเป็นลูกโดยตรงของ Flex และแก้ปัญหา “แบ่งพื้นที่ที่ Flex มีอยู่” ไม่ใช่เครื่องมือกำหนดขนาดทั่วไป

1. Flex algorithm แบบใช้งานจริง

  1. วัด non-flex children ก่อน
  2. หักพื้นที่และ spacing ออกจาก main axis
  3. แบ่งพื้นที่ที่เหลือตามค่า flex
  4. วัด flex children ด้วยส่วนแบ่งนั้น
  5. จัดตำแหน่งผลลัพธ์

ดังนั้น overflow มักเกิดจาก non-flex children ใช้พื้นที่เกินก่อนถึงขั้นแบ่ง flex

2. Expanded คือ tight flex

Row(children: [
  Expanded(flex: 2, child: PickingPane()),
  const SizedBox(width: 8),
  Expanded(child: SummaryPane()),
])

พื้นที่ที่เหลือแบ่ง 2:1 และแต่ละ child ต้องใช้ส่วนแบ่งเต็ม เหมาะกับ columns/panes ที่ต้องเติมพื้นที่

3. Flexible คือเพดาน ไม่จำเป็นต้องเต็ม

Row(children: [
  const Icon(Icons.warehouse),
  const SizedBox(width: 8),
  Flexible(child: Text(label, maxLines: 2)),
])

ค่าเริ่มต้น FlexFit.loose ให้ child เล็กกว่าส่วนแบ่งได้ Absolute ใช้ Flexible กับ label ในปุ่ม PDA เพื่อให้ข้อความ wrap โดยไม่ผลัก icon/ขอบปุ่มออก

4. Spacer คือช่องว่างแบบ flex

Spacer() เทียบเท่า Expanded ที่มี SizedBox ว่าง ใช้ผลัก action ไปท้าย Row ได้ แต่ถ้ามี MainAxisAlignment.spaceBetween/spaceAround อยู่ Spacer จะกินพื้นที่ที่เหลือก่อน ทำให้ alignment นั้นแทบไม่มีผล

5. ParentDataWidget rule

Expanded/Flexible เขียน ParentData ให้ RenderFlex จึงต้องมีเส้นทางจากมันถึง Row/Column/Flex ที่มีแต่ Stateless/Stateful wrappers ห้ามมี Container/Padding render widget คั่น เช่น Padding(child: Expanded(...)) ผิด ให้สลับเป็น Expanded(child: Padding(...))

6. Expanded กับ scrollable

ใน Column ที่สูง bounded ให้ Expanded(ListView) ถูกต้อง แต่ใน Column ภายใน SingleChildScrollView main axis ไม่ bounded จึงเกิด “non-zero flex but incoming height constraints are unbounded” เลือกเอา scrollable ชั้นเดียว, ใช้ shrinkWrap เฉพาะรายการเล็ก หรือกำหนด bounded height ให้ช่วงนั้น

7. แบบฝึกหัด

แถว summary ต้องให้ label ใช้พื้นที่มากที่สุด, status กึ่งกลางไม่เกิน 100 และ value กว้างตามตัวเลข จะเขียนอย่างไร?

เฉลย
Row(children: [
  Expanded(child: Text(label, overflow: TextOverflow.ellipsis)),
  const SizedBox(width: 6),
  Flexible(child: ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 100),
    child: Text(status, textAlign: TextAlign.center),
  )),
  const SizedBox(width: 6),
  Text(value),
])

8. จุดพลาด

อย่าครอบทุก child ด้วย Expanded เพื่อหยุด overflow เพราะจะทำให้ความหมายของขนาดหาย เช่น icon/button ถูกบังคับกว้างเท่ากับข้อความ ให้เลือกเฉพาะ child ที่เป็นเจ้าของพื้นที่ยืดหยุ่นและกำหนด priority อย่างตั้งใจ
