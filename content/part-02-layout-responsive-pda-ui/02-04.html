Padding, Align, Center และ SizedBox เปลี่ยน constraints หรือการวางตำแหน่งคนละแบบ การอ่าน wrapper chain ทีละชั้นช่วยให้รู้ว่า spacing มาจากไหนและเหตุใด child จึงไม่เต็มพื้นที่

1. Padding หักพื้นที่ก่อนส่งให้ลูก

Padding(
  padding: const EdgeInsets.fromLTRB(12, 8, 12, 16),
  child: ScanPanel(),
)

ถ้า parent กว้าง 360 และ padding ซ้ายขวา 12 ลูกได้รับ maxWidth 336 จากนั้น Padding บวก inset กลับตอนรายงาน size การซ้อน Padding หลายชั้นจึงสะสมจริงและทำ PDA แคบเร็วกว่าที่คิด

2. Center คือ Align กลางแบบย่อ

เมื่อมี bounded area, Align/Center สามารถกินพื้นที่ที่ parent อนุญาตแล้ววาง child ตาม alignment; หากแกนหนึ่ง unbounded มันหดตาม child ในแกนนั้น ใช้ widthFactor/heightFactor เมื่อต้องการให้ขนาดเป็นเท่าของ child แต่ระวังผลกับ constraint chain

3. SizedBox มีสามบทบาท

  • กำหนด tight width/height: ช่อง icon 48×48
  • สร้าง gap ที่มีความหมายคงที่
  • SizedBox.expand ขอใช้ constraint สูงสุด

SizedBox.shrink ขอ 0 แต่ parent tight อาจยังบังคับใหญ่กว่า 0 ได้

4. ConstrainedBox และข้อจำกัดที่ซ้อนกัน

ConstrainedBox(
  constraints: const BoxConstraints(maxWidth: 560),
  child: LoginForm(),
)

ข้อจำกัดใหม่ถูก intersect กับของ parent ไม่ได้ override แบบ CSS ตัวอย่าง Login ของ Absolute ใช้ Center + ConstrainedBox ทำให้ฟอร์มไม่กว้างเกินบน tablet แต่ยังหดได้บน PDA

5. FractionallySizedBox, AspectRatio, FittedBox

ใช้ FractionallySizedBox เมื่อขนาดเป็นสัดส่วนของพื้นที่ parent, AspectRatio เมื่ออัตราส่วนมีความหมาย เช่นภาพ/กล้อง, FittedBox เมื่อย่อ/ขยาย child ที่มีขนาดของตัวเอง เช่นตัวเลขใหญ่ในช่องจำกัด อย่าใช้ FittedBox ครอบ form หรือข้อความยาวทั้งหน้าเพราะ touch target/text scale จะผิดความหมาย

6. Spacing tokens ใน PDA

รวมค่า radius, inset, control height และ gap ที่ใช้ซ้ำเป็น token เช่น PdaMetrics ทำให้ density สม่ำเสมอ แต่ breakpoint อาจเลือก token ชุด compact ได้ Absolute ใช้ inset 10/12 และ gap 8/10 ตาม maxHeight แทนลดทุกอย่างแบบสุ่ม

7. แบบฝึกหัด

ต้องการหน้าล็อกอินอยู่กลางจอ กว้างไม่เกิน 480 แต่เมื่อ keyboard ขึ้นต้องเลื่อนได้ จัด wrapper order อย่างไร?

แนวคำตอบ
SafeArea(
  child: LayoutBuilder(builder: (_, c) =>
    SingleChildScrollView(
      padding: const EdgeInsets.all(16),
      child: ConstrainedBox(
        constraints: BoxConstraints(minHeight: c.maxHeight - 32),
        child: Center(child: ConstrainedBox(
          constraints: const BoxConstraints(maxWidth: 480),
          child: LoginForm(),
        )),
      ),
    ),
  ),
)

8. จุดพลาด

เลข magic ที่คำนวณ screenHeight - appBar - statusBar - keyboard - 37 เปราะต่อ platform และ text scale ให้พึ่ง constraints, SafeArea, Scaffold resize และ viewInsets ตามหน้าที่ก่อนคำนวณเอง
