PDA ถูกใช้ด้วยนิ้วโป้ง, ถุงมือ, การเดิน และการสแกนต่อเนื่อง UI ต้องลดความแม่นยำที่ต้องใช้, ทำสถานะชัด และให้ workflow เดินด้วย hardware keyboard/scanner ได้ ไม่ใช่แค่ทำทุกอย่างเล็กเพื่อใส่จอ

1. Touch target ไม่เท่ากับ icon size

Icon อาจ 20–24 logical pixels แต่พื้นที่กดควรอย่างน้อยประมาณ 48×48 ตาม Material และใหญ่ขึ้นสำหรับถุงมือ Absolute PdaButton สูง 54 (compact 46) และเต็มความกว้าง ทำให้ action หลักกดได้แม้เคลื่อนที่

2. Primary action placement

วาง action ที่ใช้ซ้ำใกล้นิ้ว/ท้าย flow, ตรึงเมื่อจำเป็น และอย่าให้ keyboard/navigation bar บัง แยก destructive action ออกจาก confirm ทั้งตำแหน่ง สี และ dialog ลดการกดพลาดจากกล้ามเนื้อจำ

3. Scanner และ hardware keyboard

รักษา focus ที่ scan field, submit ด้วย Enter, debounce/lock ระหว่าง request, แสดงค่าที่อ่านล่าสุดและเสียง/สั่น/สีเป็น feedback หลายช่องทาง ปุ่ม manual fallback ต้องกดง่าย แต่ไม่แย่ง focus ทุก rebuild

4. Semantics และ traversal

Semantics(
  button: true,
  label: 'รับสินค้าเข้า',
  value: 'งานค้าง $count',
  child: WarehouseTile(/* ... */),
)

กำหนด label สำหรับ SVG/icon, รวม semantics ของ tile ไม่ให้ screen reader อ่านชิ้นตกแต่งซ้ำ และจัด focus traversal ตามลำดับงาน ทดสอบ TalkBack และ keyboard/tab จริง

5. Feedback และ error recovery

หลัง scan ต้องรู้ทันทีว่า accepted, duplicate หรือ error โดยไม่ต้องอ่านข้อความยาว ใช้เสียง/สั่นร่วมกับ banner ที่มีข้อความและ icon Error ต้องบอกวิธีแก้และรักษาค่าที่ผู้ใช้ต้องแก้ ไม่ล้าง form ทั้งหมด

6. Density แบบมีลำดับชั้น

ลด decorative gap ก่อนลด touch target/ตัวอักษร ซ่อนข้อมูล secondary ก่อนซ่อน key identifier ใช้ progressive disclosure สำหรับรายละเอียด Absolute เลือก compact inset/gap และ tile composition ตาม height แต่ยังรักษาปุ่ม/ข้อมูลหลัก

7. แบบฝึกหัด

หน้า Picking ต้อง scan 100 ครั้งต่อกะ ออกแบบ loop หลัง scan สำเร็จและผิดพลาด

แนวคำตอบ

สำเร็จ: lock request → feedback เสียง/สั่น/สี → update count/list → clear/เลือก field → คืน focus อัตโนมัติ; ผิดพลาด: feedbackต่างกัน → เก็บ code ให้ตรวจ/แก้ → message สั้นพร้อม action retry → ไม่เปลี่ยน task โดยไม่ตั้งใจ ปุ่มยืนยันสุดท้ายใหญ่และแยกจาก cancel

8. จุดพลาด

การทำ compact โดยลดปุ่มเหลือ 28px และ font 8px อาจ “ไม่ overflow” แต่ใช้จริงไม่ได้ วัด success ด้วยเวลา/ข้อผิดพลาดของผู้ปฏิบัติงาน, gloves, แสง, เสียง และ device จริง ไม่ใช่ screenshot สวยอย่างเดียว
