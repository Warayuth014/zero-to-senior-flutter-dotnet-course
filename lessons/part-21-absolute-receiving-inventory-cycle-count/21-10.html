ไฟล์หลัก: screens/inventory_view.dart เป็น async-state gate แล้วส่งข้อมูลให้ StockView ใน screens/ops_views.dart ทำ search/filter/render

1. Source of truth เดียวสอง consumers

WarehouseStore.pallets ใช้ทั้ง Inventory Controlและ outbound picker InventoryView ไม่ fetchเอง; shell/store trigger loadPallets เมื่อเปิด stock/withdrawหรือ home loadAll ทำให้สถานะไม่ขัดกันเพราะแต่ละหน้าถือ cacheของตัวเอง

2. Async UI สามสถานะ

  • loadingและ listว่าง → progressเต็มหน้า
  • errorและ listว่าง → message + Retry
  • มี cached list → render StockView แม้ refreshกำลังโหลดหรือรอบล่าสุด error

นี่คือ stale-while-refresh policyที่รักษาข้อมูลเดิมให้ใช้อ้างอิงได้ แต่ควรมี subtle refresh/error indicatorเพื่อไม่ทำให้ผู้ใช้คิดว่าข้อมูลสด

3. Search fields

StockView normalize queryเป็น lowercaseแล้วค้น pallet code, product code, product description, brandและ location โดยยังไม่ค้น productName ช่องรับ scannerกับ manual textเหมือนกันแต่ไม่มี onSubmitted action; การยิง barcodeจึงเป็น filterทันที ไม่ใช่เปิด detail

4. Status filters

filtersมี All, Stored, Movingและ At Destination โดย Movingรวม MOVING/ALLOCATED/WAIT_RETURN ขณะที่ PICKING, AWAIT_PUTAWAYและ EMPTYเห็นได้เฉพาะ All นี่เป็น presentation grouping ไม่ใช่ canonical status list ต้องระวัง statusใหม่หายจากหมวดที่ operatorคาด

5. Fixed scanner layout

scan/filter cardอยู่นอก Expanded ListView จึงคงตำแหน่งขณะรายการเลื่อน เหมาะกับ hardware scannerที่ต้องมี focus targetมองเห็นตลอด scanner_layout_test.dart วัด top coordinateก่อน/หลัง dragเพื่อยืนยัน behavior ไม่ใช่แค่เช็ค widgetมีอยู่

6. Row semantics

empty palletซ่อน product detailsและแสดง Empty, palletมี stockแสดง qty/unit, locationและ translated status สีเลือกจาก statusบางกลุ่มแล้ว fallback amber ต้องมี text labelคู่สีเสมอ และ sentinel location - ควรแสดงได้แต่ไม่ควรถือเป็นข้อมูล warehouseจริง

7. Performance

filterสร้าง listใหม่ทุก buildและ render rowsทั้งหมดใน Columnภายในการ์ดเดียว ไม่ใช้ lazy item builder แม้ outer ListView ดังนั้น 1,000 palletsอาจสร้าง widgetจำนวนมาก ทางเลือกคือ ListView.builder/slivers, debounce searchและ server pagination โดยต้องรักษา fixed header

8. Widget tests

ทดสอบ loading/error/retry/cache-on-error, queryทุก fieldรวม case/Thai, clear button, status groupingทุก canonical value, empty row, unknown status, fixed scanner, 390px/text scale และ listขนาดใหญ่ด้วย frame/build profiling
