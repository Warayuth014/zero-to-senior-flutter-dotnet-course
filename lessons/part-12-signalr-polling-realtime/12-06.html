1. Typed listener

typedef TaskEventListener = void Function(TaskRealtimeEvent event);

abstract interface class RealtimeSubscription {
  void cancel();
}

RealtimeSubscription subscribe(TaskEventListener listener);

2. Snapshot iteration

for (final listener in List<TaskEventListener>.of(_listeners)) {
  try { listener(event); } catch (error, stack) { report(error, stack); }
}

copyป้องกัน listener removeตัวเองระหว่าง iterationและ isolate errorราย listener

3. Duplicate registration

ใช้ Setเมื่อ callback identityเหมาะหรือ subscription IDป้องกัน addซ้ำจาก didChangeDependencies/rebuild พร้อม testว่า eventหนึ่งเรียกครั้งเดียว

4. Event-specific vs union

หลาย addXListener methodsชัดแต่ APIโต sealed union TaskRealtimeEvent + filter/streamทำ compositionง่าย เลือกตามจำนวน eventsและ consumer

5. Stream option

broadcast Streamให้ StreamSubscription.cancel() และ operatorsได้ แต่กำหนด sync/async, buffering/error/close lifecycleให้ชัด ไม่ใช้ streamเพียงเพราะคำว่า realtime

6. Backpressure

ถ้า eventถี่กว่า UIประมวลผลให้ coalesceตาม entity/version, debounce refreshหรือ batch ไม่ queue unboundedจน memoryโต

7. แบบฝึกหัด

listener A throw แล้ว Bควรได้รับ eventไหม?

เฉลย

ควร isolate Aด้วย try/catch/reportแล้วส่ง Bต่อ เว้นแต่ architectureกำหนด stream error semanticsต่างอย่าง explicit
