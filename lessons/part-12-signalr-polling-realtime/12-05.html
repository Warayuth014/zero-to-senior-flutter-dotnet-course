1. Raw handler

void onTaskChanged(List<Object?>? args) {
  if (args == null || args.length != 1) {
    reportContractError('TaskStatusChanged args'); return;
  }
  final raw = args.single;
  if (raw is! Map) { reportContractError('Expected map'); return; }
  final event = TaskStatusChangedDto.fromJson(
    Map<String, dynamic>.from(raw)).toDomain();
  events.add(event);
}

2. Typed event

ประกอบ eventId, entity ID, status enum, versionและ occurredAt ให้ validationชัด Unknown statusใช้ safe mappingหรือ trigger refresh ไม่ crash listener loop

3. Multiple arguments

SignalR eventอาจส่งหลาย argsแต่ object payloadเดียว versionง่ายกว่า หาก contractหลาย argsให้ parse index+type explicitและมี testsจาก .NET fixtureจริง

4. Casing/numbers/time

ใช้ convertersกลางจาก Part 6รองรับ camel/Pascal migration, int/doubleและ UTC timestamp ไม่สร้าง parse logicอีกชุดเฉพาะ realtime

5. Contract error isolation
