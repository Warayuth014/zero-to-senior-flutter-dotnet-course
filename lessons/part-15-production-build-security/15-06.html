ไม่มี client-side secret ที่ซ่อนได้จริง: APK/IPA และ --dart-define ถูกตรวจย้อนกลับได้ แอปเก็บได้เพียง credential/session ที่ server ออกให้ผู้ใช้ภายใต้ขอบเขตและอายุจำกัด

1. ห้ามฝังอะไร

DB password, API master key, signing private key, certificate private key และ service-account credential ต้องอยู่ server/secret manager ไม่อยู่ Dart, assets, Gradle, plist, Git history หรือ CI log

2. Public config ไม่ใช่ secret

API base URL, feature flag public และ environment name ใส่ flavor/--dart-define ได้ แต่ต้อง validate/allowlist ค่าและอย่าคิดว่าการ obfuscate ทำให้เป็นความลับ

3. Session storage

SharedPreferences เหมาะ settings non-sensitive เช่น theme/profile label ไม่เหมาะ long-lived bearer/refresh token ใช้ platform secure storage (Keychain/Keystore-backed) ตาม threat model และไม่เก็บ password

4. โค้ดจริง

wmsapp เก็บ userId/fullName/role ใน SharedPreferences และ clear ทั้ง store เมื่อ logout; ข้อมูลนี้ไม่ใช่หลักฐาน authorization Server ต้องตรวจ token/claims ทุก request และการ clear ทั้ง prefs อาจลบ settings ที่ไม่เกี่ยว ควร namespace/clearเฉพาะ session

5. Token lifecycle

access token อายุสั้น, refresh rotation/revocation ตาม backend, clear memory/storage เมื่อ logout/401 และไม่ส่ง token ผิด origin Background/screenshot/clipboard ต้องไม่เผย token

6. CI secrets

keystore password, service credentials และ signing materials มาจาก protected secret store เฉพาะ release job จำกัดสิทธิ์/branch, mask logs, rotate และ audit access ไม่เขียนลง generated fileที่ถูก upload เป็น artifact

7. Obfuscation

--obfuscate --split-debug-info เพิ่มต้นทุน reverse engineeringและต้องเก็บ symbols เพื่อถอด stack trace แต่ไม่แทน encryption/auth และไม่ปกป้องค่าที่แอปต้องอ่านได้ตอน runtime

8. Secret scan

สแกน source/history/artifacts สำหรับ token/private key/password, ตรวจ release logsและ crash reports, revoke ทันทีเมื่อพบ ไม่พอเพียงลบ commit ล่าสุดเพราะ secret ยังอยู่ใน history/cache
