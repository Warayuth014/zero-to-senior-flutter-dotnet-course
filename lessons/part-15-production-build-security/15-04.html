HTTP เปิดเผยทั้ง token และข้อมูล WMS บนเครือข่าย: wms_absolute_mobile ปัจจุบันตั้ง android:usesCleartextTraffic="true" ทั้งแอป เหมาะเป็นช่องทางชั่วคราวใน LAN ทดสอบ แต่ไม่ใช่ค่า production

1. Threat model

LAN ไม่ได้แปลว่าปลอดภัย ผู้ที่อยู่ network เดียวกันอาจดัก/แก้ request ได้ Bearer token, serial, inventory และ command จึงต้องใช้ HTTPS เพื่อ confidentiality และ integrity

2. Production default

<application
  android:usesCleartextTraffic="false"
  android:networkSecurityConfig="@xml/network_security_config" />

ให้ production fail closed เมื่อ endpoint เป็น http:// และ validate URL ก่อน save profile ไม่รอให้ request แรกล้ม

3. Scoped development exception

<network-security-config>
  <base-config cleartextTrafficPermitted="false" />
  <domain-config cleartextTrafficPermitted="true">
    <domain>10.0.2.2</domain>
  </domain-config>
</network-security-config>

วาง exception ใน debug flavor/source set และจำกัด host ไม่เปิด global ใน release

4. Config UI policy

production profile บังคับ HTTPS/allowlisted host; development profileอาจยอม HTTP พร้อม warning เด่น การให้ผู้ใช้เปลี่ยน protocol ได้ไม่ได้แปลว่า authorization/security policy ควรถูกข้าม

5. Mixed content และ media

API เป็น HTTPS แต่ image/SignalR URL เป็น HTTP ก็ยังรั่วและอาจถูก platform block ตรวจทุก scheme รวม redirect, WebSocket (wss) และ URL ที่ backend คืนกลับ

6. Proxy/TLS termination

อาจ terminate TLS ที่ reverse proxy แล้วคุย HTTP ใน private segment แต่ device → public/internal endpoint ต้องเป็น HTTPS และ proxy ส่ง forwarded headers อย่างไว้ใจเฉพาะ proxy ที่กำหนด

7. Tests

release build ต้องปฏิเสธ HTTP, ยอม HTTPS production, redirect ไป HTTP ถูกปฏิเสธ และ debug exceptionทำงานเฉพาะ host ที่ตั้งไว้ ตรวจบน Android version ต่ำ/สูงสุดที่รองรับ

8. Migration

ติด certificate/hostname ที่ถูกต้องบน backend → เพิ่ม HTTPS profile → test health/login/SignalR/image → migrate devices → ปิด HTTP listener/cleartext exception ไม่แก้ด้วย accept-all certificate
