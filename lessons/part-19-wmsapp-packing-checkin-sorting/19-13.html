Part image เป็น supervisor workflow: โหลด/search สินค้า, เลือกกล้องหรือ gallery, ลดขนาดภาพ แล้วส่ง multipart พร้อม partId ก่อน reload URL จาก server

1. Parts list

getAllParts() อ่าน /upload/parts เป็น dynamic maps แล้วเก็บ all/filtered lists Search match partId, itemDesc และ brand แบบ lowercase

2. Search state issue

_loadParts เรียก _filterParts() ภายใน setState และ filter เรียก setState อีกชั้น เป็น nested state mutationที่อ่านยาก ควรคำนวณ filtered listก่อนแล้ว setStateครั้งเดียว

3. Choose source

bottom sheet คืน ImageSource.camera/gallery; cancel หยุด flow หลัง pick ใช้ maxWidth/maxHeight 1024 และ quality 85 เพื่อลด upload แต่ยังต้องตรวจ byte size/MIME หลังได้ไฟล์

4. Multipart upload

POST /upload/part-image
multipart file + field partId

API รับ dart:io File จึงผูกกับ mobile/desktop และไม่รองรับ web โดยตรง

5. Server security

.NET ต้องตรวจสิทธิ์ supervisor, part exists, MIME/magic bytes, size/dimensions, decode/re-encode, filename/storage path และ malware policy ห้ามเชื่อ extension หรือ client compression

6. URL construction

getImageFullUrl ตัดทุกข้อความ /api ด้วย replaceAllแล้วต่อ relative path ซึ่งเสี่ยงเมื่อ URL/path มีคำนี้ที่อื่น ควรใช้ Uri resolve กับ configured origin/CDN URL

7. Refresh/cache

หลัง upload success โหลด parts ใหม่ แต่ image cache อาจยังแสดงรูปเก่าที่ URL เดิม ควรให้ serverคืน versioned URL/etag หรือ evict cache เฉพาะ assetนั้น

8. Upload tests

ทดสอบ cancel, permission denied, oversized/non-image/corrupt, network timeout, unauthorized, part deleted, cache refresh และ disposeระหว่าง picker/upload โดยห้าม setStateหลัง dispose
