ไฟล์หลัก: task_views.dart, outbound_views.dart, ops_views.dart และ pda_widgets.dart — compose domain flowsให้ใช้ได้จริงบน PDA

1. TasksView

แสดง manual taskที่ยังไม่ completedและเรียง ongoingเหนือ waiting พร้อม historyด้านล่าง Task cardนำเข้า TaskRunViewโดยไม่ duplicate execution logicไว้ใน list

2. DispatchView

แบ่ง pendingกับ in progressให้ operatorเห็นงานที่เลือก carrierได้ชัด ปุ่ม AGV/Forkliftเป็น command entry ส่วนสถานะหลังจากนั้นมาจาก store/server ไม่เก็บ local widget stateเป็นความจริง

3. WithdrawView

layoutตรึง scanner/selection/actionสำคัญไว้ ขณะที่ pallet results scrollภายใน เหมาะกับ viewportสั้นและ keyboard/scanner บทเรียนคือกำหนด scroll ownerให้ชัด ไม่ซ้อน unbounded listใน pageโดยบังปุ่มยืนยัน

4. PickingView

destination selector, C1/C2 incoming, C3 Store In, active pickและ historyอยู่หน้าเดียว แต่ operational areaคงขนาด ส่วน historyขยายแล้วเป็นผู้ทำให้ page scroll จึงรักษา actionสำคัญไม่กระโดดระหว่าง flow

5. Shared PDA primitives

PdaCard, PdaButton, ScanBox, QtyStepper, FlowStepsและ CollapsibleSectionรวม visual/interaction convention ลด driftและทำให้ widget testsเลือก behaviorซ้ำได้

6. Accessibility และ scanner UX

สี statusอย่างเดียวไม่พอ ต้องมีข้อความ/icon, touch targetใหญ่, focusกลับช่อง scan, submitจาก hardware Enterและ errorที่อ่านได้ ใน warehouseแสง/ถุงมือ/เสียงดังทำให้ desktop assumptionsใช้ไม่ได้

7. View-model boundary

Widgetควรเลือก/แสดง stateและส่ง intent ส่วน mapping API, invariantsและmutationอยู่ repository/store ปัจจุบัน God Storeเริ่มใหญ่ Senior refactorแยก task/dispatch/picking controllersโดยคง shared projectionsอย่างระวัง

8. Responsive test set

ทดสอบ viewport PDAหลายความสูง, text scale, keyboardเปิด, long Thai/English labels, empty/loading/error, listใหญ่, focusหลัง errorและ hardware Enter พร้อม goldenเพียงส่วน visualที่ไม่เปราะต่อ font/environment
