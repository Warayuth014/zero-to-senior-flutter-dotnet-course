1. Probe ใช้ URL draft

probeConnection(baseUrl) รับ URLโดยตรงและสร้าง clientแยกจาก ApiClient จึงทดสอบสิ่งที่ผู้ใช้กำลังกรอกก่อน save/activate ได้ ไม่ต้องเปลี่ยน global active serverเพื่อทดลอง และไม่แนบ Bearer tokenไป health endpoint

2. Health URI

{normalized baseUrl}/api/WMS/mobile_health

ก่อนยิงต้อง parse URIและตรวจ scheme/host การปล่อย invalid addressถึง network layerทำให้ errorคลุมเครือกว่า field validation แต่ probeยังต้องป้องกันตัวเองเพราะอาจถูกเรียกจากที่อื่น

3. ทำไม HTTP 200 ยัง failได้

Blazor/server fallback routeอาจคืน index.html พร้อม 200 เมื่อ base pathหรือ API routeผิด หาก probeตรวจเฉพาะ statusจะขึ้น dotเขียวหลอก โค้ดจึง decode JSON mapและต้องเห็น service == "WMS" กับ ok == true จึงถือว่าสำเร็จ

4. Result แบบ typed

ConnectionTestResult เก็บ ok, elapsedMs, message และ statusCode ทำให้ UIแสดงทั้ง outcomeกับ latencyโดยไม่ parse exception string ค่าที่คืนควรเป็น sanitized user message ส่วนรายละเอียด stack/host diagnosticsส่ง loggerแยกช่อง

5. Error taxonomy

  • 2xx แต่ payloadผิด: ชี้ไปที่ Base Path/route
  • non-2xx: serverถึงแต่ endpointปฏิเสธ/ผิด
  • timeout 8 วินาที: serverช้าหรือ route/networkไม่ตอบ
  • HandshakeException: HTTPS/certificate
  • SocketException: DNS/IP/port/network
  • ClientException: HTTP client/protocol

ข้อความต่างกันช่วย operatorแก้ปัญหาตรงจุด

6. Resource ownership

หาก callerไม่ inject client probeจะสร้างและปิด clientเองหลังจบ วิธีนี้ป้องกัน socket resourceรั่วในการกด Testหลายครั้ง เมื่อ injectเพื่อ testต้องกำหนดให้ชัดว่า probeไม่ปิด resourceของ caller หรือใช้ wrapperที่ encode ownershipใน API

7. Race และ cancellation

กด Testซ้ำหรือสลับ profileระหว่าง probeอาจทำให้ผลเก่ามาถึงทีหลัง settings/controllerต้องใช้ busy guard, generation token หรือ cancellable operation การ timeoutช่วยจำกัดเวลารอแต่ไม่รับประกันว่า stale completionจะไม่ commit UI state

8. Contract test สำคัญที่สุด

จำลอง response 200 JSONถูก, 200 HTMLจาก Blazor fallback, 200 JSON serviceผิด/ok false, 404/500, malformed JSON, timeout, TLS และ socket error ตรวจ URIรวม base path, elapsed/status และยืนยันว่า owned clientถูก closeโดยไม่ส่ง Authorization header
