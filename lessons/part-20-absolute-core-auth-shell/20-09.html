ไฟล์หลัก: lib/core/app_theme.dart, lib/features/warehouse/ui/pda_colors.dart และ lib/widgets/pda_status_bar.dart — design tokens สามระดับที่ไม่ควรใช้สลับหน้าที่กัน

1. Theme ระดับแอป

AppTheme ตั้ง Material 3, color scheme, typography, input/card/dialog/progress และ minimum button sizes ให้ login/settings/shared Material widgets มี baseline เดียวกัน การแก้ accessibility เช่น tap target หรือ text scale จึงทำที่ root ได้มากกว่าตามแก้ทุก screen

2. Operational tokens

PdaColors ตั้งชื่อสีตามความหมายในคลัง เช่น shell navy, electric blue, success/warning/error, muted surface และ borders ส่วน PdaMetrics มี screen padding, radius และ minTapTarget = 48 ชื่อเชิง semantic ทำให้เปลี่ยน palette ได้โดยไม่ต้องรู้ hex ในทุก widget

3. สองชั้นไม่ใช่ duplication

App theme ครอบ Material components ทั้งแอป ส่วน PDA tokens รองรับ dense operational screen และ status ที่ต้อง contrast ชัด หาก feature ใช้ Colors.green โดยตรงทุกจุด จะไม่รู้ว่า green หมายถึง connected, completed หรือ safe action และยากต่อ dark/high-contrast theme

4. Tap target กับ visual size

ปุ่มบน handheld อาจวาด icon 20px แต่พื้นที่แตะต้องอย่างน้อย 48px เพราะผู้ใช้สวมถุงมือหรือเดินทำงาน PdaMetrics.minTapTarget และ theme constraints แยก hit area จาก graphic size จึงไม่ต้องขยาย icon จน layoutแน่น

5. Status bar สองโลก

SystemChrome/AnnotatedRegion คุม Android/iOS system overlay ส่วน PdaStatusBar เป็น PreferredSizeWidget สูงคงที่ใน Scaffold แสดง app identity/PDA หากแก้เพียง AppBar color แต่ไม่ตั้ง overlay icon brightness ข้อความระบบอาจอ่านไม่ออก

6. Responsive shell

header ของ shell ใช้ LayoutBuilder ลดความสูงและซ่อน subtitle บน home เมื่อกว้างไม่เกิน 400px, จำกัดความกว้าง profile name และใช้ ellipsis หลักคือรักษา action สำคัญกับ title ก่อนรายละเอียด ไม่บีบทุกอย่างให้เล็กจนแตะไม่ได้

7. Semantic status ต้องไม่พึ่งสีอย่างเดียว

connection dot มีสีต่างตาม unknown/connecting/connected/disconnected แต่เมนูยังแสดง label ด้วย ช่วยทั้ง color-vision deficiency และการ debug screenshot อย่าทำ hard-coded green เพราะสถานะ network เป็น data จาก controller ไม่ใช่ decoration

8. Visual test

ตรวจ 390×844 ที่ text scale 1.0/1.3, ไทย/อังกฤษ, keyboard เปิด, profile name ยาว และ connection ทุกสถานะ ทดสอบ tap targetอย่างน้อย 48px, ไม่มี overflow, system status iconอ่านได้ และ screenshot/golden แยก visual regression จาก business test
