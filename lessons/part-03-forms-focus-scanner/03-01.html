TextField รับ input ระดับพื้นฐาน ส่วน TextEditingController คือ owner ของ text/selection/composing state เมื่อหน้าต้องอ่าน เขียน ล้าง หรือฟังค่าจากภายนอก ต้องกำหนด ownership และ lifecycle ให้ชัด

1. Controlled input

final _scanController = TextEditingController();

TextField(
  controller: _scanController,
  decoration: const InputDecoration(labelText: 'Pallet barcode'),
  onSubmitted: (_) => _submitScan(),
)

อ่านค่าที่ boundary ของ action ด้วย controller.text ไม่ต้อง setState ทุก keystroke หาก UI ส่วนอื่นไม่ได้ขึ้นกับข้อความนั้น

2. TextEditingValue มีมากกว่า text

Controller ถือ TextEditingValue ซึ่งรวม text, selection และ composing range การตั้ง controller.text จะ reset selection/composing หากต้องแก้ค่าและรักษา cursor ให้กำหนด controller.value = value.copyWith(...) อย่างระวัง โดยเฉพาะ IME ภาษาไทย

3. initialValue กับ controller

TextFormField ห้ามส่งทั้ง initialValue และ controller เมื่อมี controller ให้กำหนดค่าเริ่มที่ constructor/initState เช่น TextEditingController(text: model.code) และ sync ใน didUpdateWidget เฉพาะเมื่อ external model เปลี่ยนจริง เพื่อไม่เขียนทับสิ่งที่ผู้ใช้กำลังพิมพ์ทุก build

4. ตัวอย่างจากสอง WMS

wmsapp สร้าง controller ใน State ของ workflow เช่น _scanCtrl, _serialScanCtrl, _qtyEntryCtrl แล้วส่งให้ presentational field ส่วน Absolute ScanBox รับ controller ภายนอกได้ หรือสร้าง _own เมื่อไม่มี ทำให้ ownership แยกได้ชัด

5. Controller ไม่ใช่ business state

ข้อความดิบในช่องเป็น UI/editing state หลัง normalize/validate แล้วควรแปลงเป็น domain value เช่น PalletCode และส่งเข้า store/use case ไม่เก็บ controller ใน repository หรือ serialize controller ลง state การ reset form จึงล้าง UI โดยไม่ทำลายผล scan ที่ commit แล้ว

6. Listener ใช้เมื่อจำเป็น

@override
void initState() {
  super.initState();
  _scanController.addListener(_updateClearButton);
}

@override
void dispose() {
  _scanController.removeListener(_updateClearButton);
  _scanController.dispose();
  super.dispose();
}

ถ้าใช้ onChanged ได้จะเห็น contract ใกล้ widget กว่า Listener เหมาะกับ logic ที่ owner ต้องฟัง независимоจาก field callback

7. แบบฝึกหัด

ScanBox reusable ควร dispose controller ที่ parent ส่งมาให้หรือไม่?

เฉลย

ไม่ควร Controller ภายนอกเป็นของ parent; child dispose เฉพาะ controller ที่ตนสร้าง Absolute ใช้ _own?.dispose() จึงไม่ทำลาย external controller หลักเดียวกันใช้กับ FocusNode, AnimationController และ ScrollController

8. จุดพลาด

อย่าสร้าง TextEditingController() ใน build เพราะ rebuild จะสร้าง object ใหม่ ทำ text/cursor หายและ controller เก่าไม่ถูก dispose ให้สร้างใน State หรือส่งจาก owner ที่มี lifetime ตรงกับช่อง input
