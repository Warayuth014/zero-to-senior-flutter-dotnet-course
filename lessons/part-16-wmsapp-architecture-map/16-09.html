common_widgets.dart คือ design system แบบไฟล์เดียว: มี AppBar, cards, scan input, buttons, badges, info rows, loading overlay, dialogs/snackbars, section headerและ empty state รวมประมาณ 700 บรรทัด

1. Widget inventory

WmsAppBar, WmsCard, ScanTextField,
Primary/Danger/WarningButton, StatusBadge,
InfoRow, LoadingOverlay, SectionHeader, EmptyState

นอกจากนี้มี top-level dialog/snackbar helpers

2. ScanTextField

รับ controller/focus/onSubmittedและ presentation options เป็น shared seamของ scanner UX เวลาปรับ autofocus/suffix/keyboard actionต้องทดสอบทุก flowที่ใช้ ไม่ให้ widgetแอบถือ business duplicate logic

3. Buttons

semantic variantsกำหนดสี/icon/loading/disabled patternให้เหมือนกัน แต่ callbackยังเป็นเจ้าของ screen ป้องกัน double-submitต้องเกิดทั้ง UI disableและ command idempotency ไม่พึ่ง buttonอย่างเดียว

4. LoadingOverlay

วาง spinner/messageทับ child ช่วยรักษา contextเดิม แต่ถ้าครอบทั้ง screenจะบล็อก scanner/navigationทุก operation ควรเลือกระดับ overlayตาม state ownerและ semantics accessibility

5. Dialog helpers

showConfirmDialog(...) → Future<bool>
showErrorDialog(...)   → Future<void>
showSuccessSnackbar / showWarningSnackbar

confirmแปลง nullจาก barrier/backเป็น false เป็น contractที่ callersอาศัย

6. Theme dependency

widgetsเรียก AppTheme.textPrimary(context)และ semantic colors จึงรองรับ dark modeดีกว่า screenที่ใช้ legacy static colors HapticFeedbackใน snackbarเป็น platform side effectที่ widget testsต้องห่อ/ยอมรับ

7. File size refactor

แยกตาม primitive/feedback/layoutเมื่อทีมแก้ชนกันหรือ test/importช้า แต่คง barrel exportเพื่อ migration ไม่ย้าย business screen widgetsเข้าคลัง commonเพียงเพราะใช้สองครั้งถ้า semanticsต่างโดเมน

8. Design-system tests

light/dark, text scale, Thaiยาว, narrow PDA, loading/disabled, focus/submit, dialog cancel/backและ semantics labels การทดสอบ primitivesชุดเล็กช่วยลด regressionข้าม 80 screens
