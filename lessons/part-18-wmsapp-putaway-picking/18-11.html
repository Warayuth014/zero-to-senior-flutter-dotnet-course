Picking session จริงอยู่ใน PickItemsScreen: PickingSessionScreen เป็น backward-compatible redirect ส่วน state machine 5 สถานะควบคุมวงจรหลาย source pallets

1. Compatibility route

Home route เดิมเปิด PickingSessionScreen ซึ่งใช้ post-frame callback แล้ว pushReplacement ไป OrdersList การเก็บ redirect ลด breaking change แต่ควรถอดเมื่อ callers migrate ครบ

2. Five states

scanSource ↔ pickView → scanDest → afterPick
     ↑                       │
     └──── returnSource ← assign failure

widget render body ด้วย switch บน enum ทำให้ state ที่เป็นไปได้เห็นชัดกว่าหลาย boolean

3. Initial assignment

detail screen assign source ก่อน push จึงเริ่ม PickItemsScreen ที่ pickView พร้อม initialAssignment ไม่เริ่ม scanSource ส่วน scanSource ใช้รอบถัดไปของ order

4. Session state

เก็บ pickOrderId, assignment, destination pallet, last result, return pallet และ local selection/serial/qty maps Destination ถูกเก็บข้าม source เพื่อเติม pallet เดิมต่อได้

5. Reset boundary

_resetPickedSerials() ล้าง selection, serial, qty, expanded rows และ input แล้วสร้าง serial list ต่อ part ใน assignment ใหม่ ต้องเรียกทุกครั้งที่เปลี่ยน source เพื่อไม่ส่งยอดเดิมซ้ำ

6. Back navigation

PopScope อนุญาต pop เฉพาะ initial pickView; scanDest ย้อนกลับ pickView, returnSource ย้อนไป scanSource และ afterPick ไม่ทำอะไร ปิดทางย้อนที่อาจทำ command ซ้ำ แต่หลังสำเร็จควรมี exit path ที่ชัด

7. Error classification bug

เมื่อ assignPickStation fail จาก scanSource โค้ดทุก error พาไป returnSource พร้อมข้อความ “ไม่มีสินค้าที่ต้อง Pick” แม้สาเหตุอาจเป็น network/401/500 ควร branch ตาม typed error และ return เฉพาะ domain outcome no-needed-items

8. Reducer refactor

กำหนด event SourceScanned, AssignmentLoaded, PartActivated, DestScanned, PickConfirmed, ReturnRequested และ state immutable พร้อม transition tests รวม invalid transitions เช่น confirm ซ้ำขณะ loading
