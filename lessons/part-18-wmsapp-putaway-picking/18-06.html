Operator ต้องเห็นสิ่งที่จะเคลื่อนก่อนยืนยัน: pallet summary, items, lot และยอดรวมเป็น safety check ส่วน wrapping toggle เปลี่ยนเส้นทางเครื่องจักรจริง

1. PutawayPalletInfo

model มี palletId, type, status, suggestedDestination, items และ message โดย items reuse UnloadItem ทำให้ putaway ผูกกับ model ของอีก domain ซึ่งสะดวกแต่ coupling สูง

2. Pallet info card

StationPalletInfoCard แสดง identity/type/status และเปิด PalletItemsPage เมื่อกดดูสินค้า หน้าที่ card คือสรุป ไม่ควรคำนวณ business eligibility แทน service

3. Items page

หน้า detail แสดง partId, description, owner/brand, lot, image และ qty ของทุก UnloadItem พร้อม summary จำนวนรายการและผลรวม qty ช่วย operator ตรวจ pallet ก่อนส่ง

4. Aggregate correctness

totalQty = items.fold<int>(
  0,
  (sum, item) => sum + item.qty,
);

หากหน่วยรองรับทศนิยม int จะไม่พอ และรายการ duplicate part+lot ต้องตัดสินว่าควรรวมหรือแสดง line แยก

5. Wrapping toggle

StationWrappingToggle เป็น controlled widget รับ value/onChanged เจ้าของ state อยู่ StationSheet ทำให้ destination change สามารถล้าง flag ได้ใน transition เดียว

6. Fixed ASRS

send prework station ไม่แสดง destination selector แต่ยังแสดง wrapping toggle เพราะ fixedDestination คือ ASRS ส่วน station ที่ไม่มี fixed destination แสดง toggle ภายใน selector เมื่อ ASRS ถูกเลือก

7. Stale pallet details

ระหว่างเปิด items page pallet อาจถูกอีกเครื่องเปลี่ยนสถานะ ข้อมูลหน้านี้เป็น snapshot จึงต้อง validate ตอน confirm และควรแสดง loadedAt/version หากความสดสำคัญ

8. UI tests

ทดสอบ empty items, image error, long Thai/English description, lot null, qty aggregate, FG/PW color, wrapping reset เมื่อเปลี่ยน destination และ fixed-ASRS toggle บนหน้าจอ PDA
