PutawayScreen เป็น live station board: grid ไม่ได้เป็นเพียงเมนู แต่สะท้อนว่าสถานีใดว่างหรือกำลัง dispatch จาก map ที่ key ด้วย stationId

1. Static station catalog

_kStations กำหนด STN-1, STN-2 และ STN-3 พร้อม label, สี และ icon ข้อมูลคงที่นี้คือ UI configuration ส่วน availability ต้องมาจาก backend

2. Runtime status map

Map<String, Map<String, dynamic>> _stationStatus

stationStatus[stationId] = {
  palletId, destination, items
};

map ทำ lookup ต่อ card ได้เร็ว แต่ dynamic payload ทำให้ typo/type error ไปเกิด runtime ควรสร้าง typed StationStatus

3. Initial load

getStationStatus() คืนรายการแล้วแปลงเป็น map ด้วย stationId ถ้า request fail โค้ดปัจจุบันคง board เดิม/ว่างโดยไม่แสดง error จึงแยก “ไม่มีงาน” ออกจาก “โหลดสถานะไม่ได้” ไม่ได้

4. Scan station

ค่าถูก trim และ uppercase แล้วค้นใน catalog หากไม่พบจะแสดง supported stations หากพบจึงเรียก _openStationPopup นี่เป็น local guard ก่อนทำ I/O

5. Busy guard

ถ้า _stationStatus[station.id] มีค่า method จะ return และไม่เปิด sheet แม้ข้อความบน busy card เขียนว่า “กดดูรายละเอียด” จึงเกิด UX contract ไม่ตรงพฤติกรรม ควรเปิด read-only detail หรือเปลี่ยนข้อความ

6. Grid composition

PutawayStationGrid สร้าง Row ของ Expanded cards และกำหนด isDispatching จาก containsKey เหมาะกับ 3 สถานี แต่หน้าจอแคบมากอาจควรใช้ Wrap/GridView เพื่อรักษา tap target และข้อความ

7. Live updates

StationDispatched merge pallet/destination ทันที แล้วเรียก REST reconcile ส่วน PalletArrived, PalletReturned และ LabelingCompleted โหลด snapshot ใหม่ทั้งหมด ทำให้ UI responsive แต่ยัง eventually consistent

8. Widget tests

ทดสอบ unknown station, lowercase normalization, empty/error/success status, busy tap, event ของ station ที่ไม่อยู่ใน catalog และ layout ที่ความกว้าง PDA โดย fake API/SignalR แทน singleton จริง
