Generated code เป็น compiler feedback: Drift แปลง schema เป็น row/companion/query types ช่วยจับชื่อ column และ nullability ตั้งแต่ build

1. part directive

part 'offline_database.g.dart'; เชื่อม source กับ generator output ชื่อไฟล์ต้องตรงและ generated file ไม่ควรแก้ด้วยมือ

2. Annotation

@DriftDatabase(tables: [...]) ระบุ schema ที่ database class เป็นเจ้าของ จากนั้น class extends generated _$OfflineDatabase

3. Row class

CachedTask เป็น immutable row จากผล query ส่วน CachedTasksCompanion แทนค่าที่จะ insert/update และแยก absent จาก nullable

4. Value wrapper

ตอน partial update ใช้ Value(value); ถ้าไม่ส่ง field หมายถึงไม่แก้ ต่างจากส่ง null ซึ่งต้องเป็น nullable column

5. Build failures

หาก generator แจ้ง duplicate name/type mismatch ให้แก้ schema source ไม่ patch ไฟล์ .g.dart แล้ว regenerate จน reproducible

6. Watch mode

dart run build_runner watch

เหมาะระหว่างแก้ schema ต่อเนื่อง แต่ CI ควรใช้ build ครั้งเดียวและตรวจว่า generated diff ว่าง

7. Review generated diff

ไม่ต้องอ่านทุกบรรทัด แต่ตรวจ table/column/nullability/index และ migration impact เมื่อ generator เปลี่ยนมากผิดคาด

8. Checkpoint

ลบ output ใน branch ทดลองแล้ว generate ใหม่ ผลต้องเหมือนเดิมและ analyze ผ่าน จึงถือว่า build pipeline reproducible
