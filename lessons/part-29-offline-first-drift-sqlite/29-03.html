1. Runtime packages

drift ให้ ORM/query API และ drift_flutter ช่วยเปิดฐานข้อมูลตาม platform ส่วน SQLite engine มาจาก sqlite3

2. Dev packages

drift_dev เป็น generator และ build_runner จัด build pipeline ทั้งคู่ควรอยู่ dev_dependencies เพราะไม่ใช่ runtime feature

3. Install

flutter pub add drift drift_flutter
flutter pub add --dev drift_dev build_runner

4. Generate

dart run build_runner build

ทุกครั้งที่ table/query annotation เปลี่ยนต้อง regenerate และ commit generated file ตาม policy ของ repo นี้

5. Native setup

driftDatabase(name: ...) เลือกตำแหน่งฐานข้อมูลเหมาะกับ Flutter platform และ sqlite3 รุ่นใหม่ใช้ native asset build hooks

6. Web assets

Flutter Web ต้องวาง SQLite wasm และ worker ตามเอกสาร Drift พร้อมตรวจ headers/caching; build ผ่านไม่ได้แปลว่า runtime asset พร้อมเสมอ

7. Version discipline

อ่าน changelog/migration guide ก่อน major upgrade รัน generator, analyze, tests และเปิดฐานข้อมูลจากเวอร์ชันก่อนใน CI

8. Checkpoint

เปิด pubspec.lock เพื่อดูเวอร์ชันที่ resolve จริง แล้วบันทึกคำสั่ง regenerate ไว้ใน README ของทีม
