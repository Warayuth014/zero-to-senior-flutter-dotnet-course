FutureBuilder ไม่ได้ cache Future: ถ้าสร้าง future ใหม่ใน build() ทุก rebuild จะเริ่ม resolve URL หรือโหลด metadata ซ้ำ และอาจกระพริบกลับไป loading

1. ปัญหาที่พบบ่อย

FutureBuilder<String>(
  future: api.getImageFullUrl(relativePath), // สร้างทุก build
  builder: ...,
)

parent rebuild จาก search, theme หรือ progress ก็เรียก async งานเดิมอีกครั้ง แม้ network image จะ cache bytes ได้ แต่ future และ state transition ยังเกิดซ้ำ

2. เก็บ Future ใน State

late Future<Uri> _imageUri;

@override
void initState() {
  super.initState();
  _imageUri = repository.resolveImage(widget.relativePath);
}

@override
void didUpdateWidget(covariant PartThumbnail old) {
  super.didUpdateWidget(old);
  if (old.relativePath != widget.relativePath) {
    _imageUri = repository.resolveImage(widget.relativePath);
  }
}

3. ครบทุก snapshot state

if (snapshot.connectionState != ConnectionState.done) {
  return const ThumbnailSkeleton();
}
if (snapshot.hasError) return const BrokenThumbnail();
final uri = snapshot.data;
if (uri == null) return const EmptyThumbnail();
return Image.network(uri.toString(), fit: BoxFit.cover);

4. FutureBuilder ไม่จำเป็นเสมอ

หากการ resolve เป็น pure synchronous operation ให้คืน Uri ทันที ไม่ต้องสร้าง Future ถ้า base URL มาจาก settings async ให้ load settings ครั้งเดียวใน repository/store แล้วส่ง media base ลงมา ลด nested async widget

5. List identity

thumbnail ใน list ควรมี ValueKey(partId) เพื่อไม่ให้ State ของแถวหนึ่งย้ายไปอีกแถวหลัง filter/reorder และ image cache key ต้องรวม URL/version จริง ไม่ใช่เพียงตำแหน่ง index

6. Retry เฉพาะที่

void retry() => setState(() {
  _imageUri = widget.repository.resolveImage(widget.relativePath);
});

แสดง retry ที่ thumbnail โดยไม่ reload ทั้งรายการ แยก error resolve URL ออกจาก error ดาวน์โหลดรูป เพื่อให้ log และข้อความตรงสาเหตุ

7. ป้องกัน stale result

FutureBuilder จับกับ future ล่าสุด แต่หากเราเขียน callback/setState เองต้องใช้ request generation หรือเปรียบเทียบ partId/path ก่อน apply ผล เพื่อไม่ให้รูปของ query เก่าทับรายการใหม่หลังผู้ใช้ค้นหาเร็ว

8. Widget tests

ทดสอบ loading → image, empty, malformed URL, resolve failure, network error, retry, เปลี่ยน relativePath และ parent rebuild หลายครั้ง โดย assert ว่า repository ถูกเรียกครั้งเดียวต่อ path
