URL ใน response คือข้อมูลที่ต้องออกแบบ: อย่าต่อ string ด้วยการลบ /api อย่างเดียว เพราะ base path, reverse proxy, CDN และ tenant path เปลี่ยนได้

1. โค้ดจริงและข้อจำกัด

final base = await ApiService._resolveBase();
final serverBase = base.replaceAll('/api', '');
return '$serverBase$relativePath';

ใช้ได้เมื่อ base ลงท้าย /api เสมอ แต่ replaceAll อาจลบคำว่า api ตำแหน่งอื่น และการต่อ string ทำ slash หาย/ซ้ำหรือ encode path ผิดได้

2. Response DTO

{
  "imageUrl": "/media/parts/8f0c.jpg",
  "contentType": "image/jpeg",
  "width": 1024,
  "height": 768,
  "etag": "\"a1b2\""
}

คืน public URL หรือ stable media ID ไม่คืน physical disk path เช่น C:\uploads\...

3. Resolve ด้วย Uri

Uri resolveMedia(Uri apiBase, String value) {
  final candidate = Uri.parse(value);
  if (candidate.hasScheme) return validateMediaOrigin(candidate);
  final origin = apiBase.replace(path: '/', query: null, fragment: null);
  return origin.resolveUri(candidate);
}

หากระบบอยู่ใต้ path เช่น /wms/ ให้ server คืน absolute public URL หรือ client config media base โดยตรง ไม่เดาจาก API path

4. Trust boundary

ถ้า response คืน absolute URL ให้ allowlist scheme https และ host ที่ไว้ใจได้ ป้องกัน UI โหลดรูปจาก host แปลก, ส่ง auth header ผิด origin หรือเปิดช่อง tracking ห้ามนำ URL จาก server ไปอ่านเป็น local file path

5. Cache busting

ถ้า replace รูปที่ URL เดิม cache อาจยังแสดงรูปเก่า ใช้ content-addressed filename, version query เช่น ?v=etag หรือ HTTP ETag/Cache-Control ที่ถูกต้อง วิธีสร้างชื่อใหม่ทุก version ง่ายและปลอดภัยกว่าการ disable cache ทั้งหมด

6. NetworkImage error

Image.network(
  imageUri.toString(),
  fit: BoxFit.cover,
  errorBuilder: (_, error, __) => const Icon(Icons.broken_image),
  loadingBuilder: (_, child, progress) =>
      progress == null ? child : const CircularProgressIndicator(),
)

7. Authenticated media

หาก endpoint รูปต้องใช้ JWT, Image.network รองรับ headers บางกรณีแต่ cache/key ต้องระวัง token rotation ทางเลือกคือ signed URL อายุสั้นหรือ image provider/client ที่ inject auth และไม่บันทึก token ใน URL/log

8. Tests

ทดสอบ relative path มี/ไม่มี slash, base มี subpath, URL encoded Unicode/space, absolute trusted/untrusted host, HTTP ถูกปฏิเสธใน production และ URL version เปลี่ยนหลัง replace รูป
