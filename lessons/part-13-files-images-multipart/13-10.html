Lab ปลาย Part: ทำ flow เลือก → preview → validate → upload → แสดง URL ใหม่ โดยยึด part_image_screen.dart, upload_api.dart และ ApiService._uploadFile ของ wmsapp แล้วปรับ contract ให้ production-safe

1. Acceptance criteria

  1. เลือก camera/gallery และ cancel ได้
  2. preview ไม่ decode เกินขนาดจอ
  3. รับเฉพาะ JPEG/PNG ไม่เกิน 5 MB
  4. ส่ง partId, uploadId และ file
  5. progress/cancel/error แยกสถานะ
  6. response URL แสดงรูปใหม่และไม่เกิด duplicate เมื่อ retry

2. Flutter contract

abstract interface class PartImageRepository {
  Future<PartImage> upload({
    required String partId,
    required XFile file,
    required String uploadId,
    required void Function(double value) onProgress,
    required CancelToken cancelToken,
  });
}

screen ไม่รู้ multipart/URL/token และ repository แปล transport error เป็น domain failure

3. Picker + preview

final picked = await picker.pickImage(
  source: source, maxWidth: 1600, maxHeight: 1600, imageQuality: 85,
);
if (picked == null || !mounted) return;
final candidate = await validator.validate(picked);
setState(() => _candidate = candidate);

ยังไม่อัปโหลดจนผู้ใช้กดยืนยัน และ restore lost data บน Android ผ่าน flow validation เดียวกัน

4. .NET endpoint

app.MapPost("/api/upload/part-image", async (
  HttpRequest request, IPartImageService service, ClaimsPrincipal user,
  CancellationToken ct) => {
    var form = await request.ReadFormAsync(ct);
    var file = form.Files.GetFile("file");
    var result = await service.SaveAsync(
      user, form["partId"]!, form["uploadId"]!, file, ct);
    return Results.Created(result.ImageUrl, result);
}).RequireAuthorization();

service ต้องตรวจ null/length/signature/dimensions/permission และสร้าง filename เอง; endpoint จำกัด request body ก่อนอ่าน form

6. State transition

idle → picking → preview → uploading(progress)
                       ↘ cancelled → preview
                       ↘ rejected  → preview + field error
                       ↘ success   → refresh/replace image version

ใช้ operation ID ป้องกัน response งานเก่าทับงานใหม่ และหลัง timeout ให้ reconcile ด้วย uploadId ก่อน retry

7. Test plan

Flutter unit test validator/repository mapping, widget test cancel-preview-progress-retry, .NET integration test multipart จริงผ่าน WebApplicationFactory, authorization/limits/signature/idempotency และ end-to-end บน device ผ่าน Wi‑Fi/HTTPS ของสภาพแวดล้อมจริง

8. Definition of Done

ไม่ใช่เพียง “รูปขึ้น”: ไม่มี token/path หลุด log, ไม่ไว้ใจ filename/MIME, ไม่เกิด orphan/duplicate, cancel หยุดงานจริง, รูปใหม่ไม่ติด cache เก่า, memory ไม่พุ่งบน PDA และ error ทุกแบบมีทางให้ผู้ใช้แก้ต่อได้
