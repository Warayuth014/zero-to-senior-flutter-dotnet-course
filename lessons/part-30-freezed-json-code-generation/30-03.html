Freezed data class: declarationสั้นแต่ยังเป็น public API จริง ชื่อ field, nullability และ constructor shapeต้องออกแบบอย่างตั้งใจ

1. Imports/parts

import 'package:freezed_annotation/freezed_annotation.dart';
part 'wms_task.freezed.dart';
part 'wms_task.g.dart';

2. Annotation

@freezed บอก builderให้สร้าง implementation, equality, hashCode, toString และ copyWith

3. Declaration

Freezed 3ใช้ abstract class WmsTask with _$WmsTask และ redirecting const factoryไป private implementation _WmsTask

4. Required/nullable

required String id บังคับ callerส่งค่าแต่ไม่รับประกัน non-empty ส่วน String? แปลว่า nullเป็น stateที่ domainยอมรับจริง

5. Private constructor

เพิ่ม const Model._() เมื่อจำเป็นต้องมี custom getters/methodsบน base class เช่น labelของ union

6. Const

const factoryช่วยสร้าง compile-time constantsใน fixtures/widgetsเมื่อทุก fieldเป็น const และสื่อว่า objectไม่เปลี่ยนภายหลัง

7. Naming

ชื่อ private generated classอาจเปลี่ยนตาม generator version อย่าพึ่งชื่อ implementationจาก featureอื่น ใช้ public factory/typeเป็นหลัก

8. Exercise

เปิด wms_task.dart เทียบกับ generated implementation แล้วหา constructor, getters, equality และ copyWith ที่ declarationหนึ่งชุดสร้างให้
