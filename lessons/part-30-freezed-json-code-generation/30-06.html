JSON generation คือ syntax mapping: business validationและ API semanticsยังต้องอยู่รอบ generated parser

1. Factory hook

factory WmsTask.fromJson(Map<String, dynamic> json) =>
  _$WmsTaskFromJson(_normalizeTaskJson(json));

2. toJson

เมื่อ Freezedเห็น fromJson factoryและมี json_serializable จะสร้าง toJsonให้ modelด้วย ใช้สำหรับ request/cache/logที่ redactแล้ว

3. Wire types

JSON objectเข้า Dartเป็น Map<String,dynamic>; generator castตาม declared type จึงจับ number/string mismatchแทนการเรียก toStringแบบไม่ตั้งใจ

4. Normalization

lab normalize trimและ status caseก่อน generated decode เพื่อรักษา contractเดิม แต่ productionควรถามก่อนว่า tolerant parsingซ่อน backend bugหรือไม่

5. Round trip

fromJson(toJson(model)) == model เป็น useful propertyแต่ไม่พิสูจน์ compatibilityกับ server ต้องมี fixtureจาก wireจริงด้วย

6. Direction

response DTOกับ request DTOอาจคนละ shape อย่าฝืน classเดียวหาก server-generated fieldsและ writable fieldsต่างกัน

7. Errors

แปลง low-level decode errorเป็น ApiExceptionที่มี path/correlationและไม่เปิด payloadลับให้ UI/log

8. Checkpoint

เปิด wms_task.g.dart แล้ว trace enum decode/toJson map จาก wire keyถึง Dart fieldและกลับ
