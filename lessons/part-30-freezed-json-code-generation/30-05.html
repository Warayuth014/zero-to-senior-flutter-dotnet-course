copyWith สร้าง snapshotใหม่: ใช้อธิบาย transitionอย่างชัดโดย objectเดิมไม่เปลี่ยน แต่ nullable fieldมีรายละเอียดสำคัญ

1. Basic copy

final working = task.copyWith(status: TaskStatus.working);

fieldsที่ไม่ส่งคงค่าเดิมและคืน instanceใหม่

2. Nullable distinction

generated proxyแยก “ไม่ส่ง argument” จาก “ส่ง null” จึง clear nullable fieldได้ ตรวจ signatureจริงเมื่อใช้ร่วมกับ custom wrapper

3. Nested copy

Freezedรองรับ deep copy syntaxสำหรับ nested Freezed objects แต่การ chainยาวอาจบอกว่า aggregateใหญ่เกินหรือ ownershipไม่ชัด

4. Collections

การ copy modelพร้อม Listเดิมอาจแชร์สมาชิกเดิม ถ้าต้องเปลี่ยนรายการให้สร้าง collectionใหม่และรักษา element immutability

5. Invariants

copyWithอาจสร้าง combinationที่ domainห้าม เช่น completedแต่ไม่มี completedAt ใช้ union/named command/domain methodเมื่อ fieldsต้องเปลี่ยนพร้อมกัน

6. Patch semantics

อย่าสับสน copyWithใน memoryกับ HTTP PATCH; omit/null/valueบน wireต้องมี DTO tri-state contractแยก

7. Lab

wms_task_test.dart เปลี่ยน statusด้วย copyWith แล้วตรวจ originalยัง waitingและ snapshotใหม่เป็น working

8. Exercise

แทนการแก้ mutable stateหนึ่งจุดด้วย copyWith แล้วเพิ่ม testทั้งค่าใหม่และการไม่เปลี่ยนค่าเดิม
