Enum wire values unknown values และ JsonConverter

Part 30: Freezed, JSON Serialization & Code Generation

Enum บน wire เปลี่ยนได้: เลือก fail-fast, unknown sentinel หรือ raw-value preservationตามความเสี่ยงของ workflow ไม่ใช้คำตอบเดียวทุกหน้าจอ

1. Default enum

json_serializableสร้าง enum mapจากชื่อ Dart โดย default เช่น TaskStatus.working ↔ "working"

2. JsonValue

ใช้ @JsonValue('IN_PROGRESS') เมื่อ wire valueต่างจากชื่อ Dart และให้ contract testป้องกันการ renameทำลาย API

3. Unknown

unknownEnumValue ช่วย forward compatibilityในหน้ารายงาน แต่ action-critical statusอาจต้อง rejectเพื่อไม่เปิดปุ่มผิด

4. Lab policy

WmsTaskยัง reject statusใหม่ด้วย FormatException เพราะการเดาความหมาย cancelled/heldใน workflowปิดงานอาจไม่ปลอดภัย

5. JsonConverter

สร้าง converterเมื่อ typeเดียวมี wire encodingซ้ำหลาย field เช่น WMS timestamp, decimal-as-string หรือ identifier format

6. Converter purity

converterควร deterministicและไม่มี network/service dependency ทำให้ generatorเรียกง่ายและ unit testได้โดยตรง

7. Time/number

กำหนด UTC/offsetและ decimal precisionชัด อย่าปล่อย DateTime.parse/double conversionเป็น business ruleโดยบังเอิญ

8. Checkpoint

เพิ่ม enumใหม่ใน fixtureโดยไม่เพิ่ม Dart case แล้วตรวจว่า behaviorตรง policy: reject, map unknown หรือเก็บ raw value
