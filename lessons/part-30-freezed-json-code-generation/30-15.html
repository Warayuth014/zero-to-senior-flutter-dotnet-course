Tests ตรวจ contract ไม่ตรวจว่า generator “น่าจะถูก”: ตรึง wire fixturesและ public behaviorที่แอปพึ่งเพื่อให้ upgrade/refactorปลอดภัย

1. Golden fixtures

เก็บ JSONขั้นต่ำ/เต็ม/legacyจาก API contractโดย redactข้อมูลจริง ตรวจ decode fieldsและ errorของ malformed payload

2. Round trip

test model→JSON→modelสำหรับ writable DTO พร้อมยอมรับ normalizationที่ตั้งใจ เช่น status input uppercaseออก lowercase

3. Equality/copy

ตรวจ value equality, hash collection behavior, copyWithและ original immutabilityโดยเฉพาะ nested list/map

4. Union cases

สร้างทุก case ตรวจ payload/label/serializationและ exhaustive switch; เพิ่ม caseใหม่ควรทำให้จุดที่ต้องตัดสิน behavior compile fail

5. Compatibility matrix

test missing/null/extra/renamed/unknown enum/wrong type แยกกันเพื่อบอก policyชัด ไม่ใช้ fixtureเดียวที่ failหลายเหตุผล

6. Generated drift

CI regenerateและตรวจ Git diff รวม analyze/test ทำให้ source, lockfileและ generated outputอยู่ชุดเดียวกัน

7. Performance

benchmarkเฉพาะ large payload/hot pathจริง Codegenมักลด reflection overheadแต่ allocation/deep equalityใหญ่ยังมีต้นทุน

8. Checkpoint

ก่อน upgrade generatorให้รัน compatibility suiteบน old fixturesและตรวจ generated diff ไม่พึ่ง compileผ่านอย่างเดียว
