ยินดีต้อนรับ: บทนี้ไม่ให้คุณจำโค้ด เราจะทำความเข้าใจก่อนว่า Flutter ใช้สร้างอะไร และเมื่อเรียนจบคอร์สนี้คุณจะทำอะไรได้บ้าง

1. เราจะสร้างอะไรในคอร์สนี้

เราจะเริ่มจากแอปเล็กที่มีข้อความและปุ่ม จากนั้นค่อยเพิ่มหลายหน้าจอ แบบฟอร์ม การเรียก API การเก็บข้อมูล และการทดสอบ จนประกอบเป็น Mobile WMS ที่เชื่อมกับ .NET ได้

ข้อความ + ปุ่ม → หลายหน้าจอ → Login / Scan / Task
                         → เชื่อม .NET API
                         → Test / Offline / Release

คุณไม่จำเป็นต้องรู้คำทั้งหมดทางขวาตอนนี้ แต่ควรเห็นว่าทุกบทจะต่อยอดจากของที่สร้างได้แล้ว

2. Flutter คืออะไร

Flutter คือชุดเครื่องมือสำหรับสร้างหน้าจอและพฤติกรรมของแอปจาก codebase เดียว แอปสามารถรันบน Android, iOS, Web และ Desktop ได้ แต่แต่ละ platform ยังมีข้อแตกต่างที่ต้องทดสอบจริง

ในคอร์สนี้เป้าหมายหลักคือ Android/PDA สำหรับงานคลังสินค้า ส่วน Web ใช้ช่วยทดลองบางบทได้เร็วขึ้น

3. Dart คืออะไร

Dart คือภาษาที่ใช้เขียน Flutter เปรียบเหมือนภาษาไทยที่เราใช้เขียนหนังสือ ส่วน Flutter คือเครื่องมือจัดหน้าหนังสือและแสดงผล

ชื่อหน้าที่ตัวอย่าง
Dartภาษาเขียน logic และข้อมูลตัวแปร, function, class
Flutterสร้าง UI และรับ inputข้อความ, ปุ่ม, หน้าจอ
.NET APIประมวลผลฝั่ง serverLogin, บันทึกงาน, อ่านฐานข้อมูล

4. แอปกับ Server คนละโปรแกรม

Flutter รันบนโทรศัพท์ ส่วน .NET API มักรันบน server ทั้งสองคุยกันผ่าน network โดยส่ง request และ response การกดปุ่มใน Flutter จึงไม่ได้เรียก C# method โดยตรง

โทรศัพท์                    Server
Flutter ── request ──────► .NET API
        ◄──── response ─── Database / business rules

ตอนเริ่มต้นเราจะยังไม่เชื่อม server เพื่อให้เข้าใจ Flutter ทีละชั้นก่อน

5. สิ่งที่มือใหม่ไม่ต้องกังวลตอนนี้

  • ยังไม่ต้องรู้ architecture เช่น Repository หรือ dependency injection
  • ยังไม่ต้องรู้ Widget tree, lifecycle หรือ state management package
  • ยังไม่ต้องเปิดโปรเจกต์ WMS ขนาดใหญ่
  • ยังไม่ต้องจำ command ทุกคำสั่ง เพราะทุกบทจะบอกคำสั่งที่ต้องใช้

เมื่อศัพท์เหล่านี้ปรากฏครั้งแรก เราจะอธิบายความหมายและสร้างตัวอย่างเล็กก่อนเสมอ

6. วิธีเรียนให้ได้ผล

  1. อ่านบทตามลำดับ อย่าข้าม Foundation หากยังไม่เคยเขียน Flutter
  2. พิมพ์และรันตัวอย่างด้วยตัวเอง ไม่อ่านผ่านอย่างเดียว
  3. ลองเปลี่ยนค่าหนึ่งอย่างแล้วสังเกตผล
  4. ทำแบบฝึกหัดก่อนเปิดเฉลย
  5. ถ้าพบ error ให้อ่านข้อความบรรทัดแรกและหาหลักฐานก่อนแก้

7. เลือกอุปกรณ์สำหรับเรียน

เริ่มเร็ว

ใช้ Chrome เพื่อเห็นหน้าจอแรกเร็ว แต่บาง plugin ของมือถือทำงานต่างกัน

ตรงกับงานจริง

ใช้ Android Emulator หรือมือถือ Android เหมาะกับคอร์ส Mobile WMS มากที่สุด

คุณสามารถเริ่มด้วย Chrome แล้วกลับมาทดสอบ Android ในบทเกี่ยวกับ device, permission และ scanner

8. แบบฝึกหัดแรก

เขียนคำตอบสั้น ๆ โดยไม่ต้องใช้ศัพท์เทคนิค: คุณอยากสร้างแอปอะไร ผู้ใช้กดหรือกรอกอะไร และคาดหวังให้หน้าจอแสดงผลอย่างไร

ดูตัวอย่างคำตอบ

“ฉันอยากสร้างแอปนับสินค้า ผู้ใช้กดปุ่มเพิ่มจำนวน เมื่อกดแล้วตัวเลขบนหน้าจอเพิ่มขึ้นหนึ่ง” นี่เพียงพอสำหรับ mini project แรกแล้ว

9. Checklist ก่อนเรียนต่อ

  • อธิบายได้ว่า Dart เป็นภาษาและ Flutter เป็นเครื่องมือสร้างแอป
  • รู้ว่า Flutter app กับ .NET API เป็นคนละโปรแกรม
  • เลือกได้ว่าจะเริ่มรันบน Chrome หรือ Android
  • ยอมรับได้ว่ายังไม่ต้องเข้าใจศัพท์ระดับสูงในวันนี้

10. สรุปจำเร็ว

เส้นทางของเราคือ “รันให้ได้ → เข้าใจ Dart → สร้าง UI → จัดการข้อมูล → เชื่อม API → ออกแบบและทดสอบระดับ production” บทถัดไปจะติดตั้งเครื่องมือทีละขั้น
