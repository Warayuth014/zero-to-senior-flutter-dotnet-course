ระดับ: Beginnerไฟล์หลัก: pubspec.yamlเป้าหมาย: เพิ่ม package อย่างปลอดภัย
pubspec.yaml คือบัตรประจำตัว project: เก็บชื่อ, version, SDK constraint, dependencies และ assets ช่องว่างใน YAML มีความหมายจึงควรแก้ด้วยความระวัง

1. ส่วนที่ต้องรู้

name: hello_flutter
version: 1.0.0+1
environment:
  sdk: ^3.0.0
dependencies:
  flutter:
    sdk: flutter
dev_dependencies:
  flutter_test:
    sdk: flutter

2. Dependency คืออะไร

Dependencyคือ codeจาก packageอื่นที่ projectนำมาใช้ เช่น HTTP client Runtime packageอยู่ dependencies ส่วน generator/test toolอยู่ dev_dependencies

3. เพิ่ม Package ด้วยคำสั่ง

flutter pub add http
flutter pub add --dev build_runner

คำสั่งช่วยแก้ YAMLและ resolve version ลดปัญหา indentation แต่ยังต้อง review diffและอ่าน package documentation

4. Lockfile

pubspec.yaml ระบุช่วง version ส่วน pubspec.lock บันทึก versionที่เลือกจริง Applicationควร commit lockfileเพื่อให้ทีมและ CIใช้ชุดเดียวกัน

5. Assets

flutter:
  assets:
    - assets/images/

สร้างไฟล์จริงให้ตรง pathและรักษา indentation จากนั้น Full Restartเมื่อ assetไม่ถูกพบ

6. อย่าเลือก Packageจากยอด Like อย่างเดียว

  • ดูวันที่อัปเดตและ SDK compatibility
  • อ่าน licenseและplatform support
  • ดู issue/maintenanceและAPI surface
  • ทดลองใน branchและเพิ่ม testที่ boundary

7. แบบฝึกหัด

เปิด pubspecของแอปแรก แยก runtime/dev dependenciesและหา versionจริงใน lockfile

ตรวจคำตอบ

flutterเป็น SDK dependency, flutter_testเป็น dev dependency และ lockfileมีรายการ packageรวม transitive dependencies

8. สรุป

ใช้ pub add, commit pubspecกับ lockfile, review packageก่อนใช้ และอย่าแก้ generated dependency cacheด้วยมือ
