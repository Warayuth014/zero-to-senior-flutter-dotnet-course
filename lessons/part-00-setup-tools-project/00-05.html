ระดับ: เริ่มจากศูนย์ลงมือทำ: แอปแรกผลลัพธ์: เห็น Flutter บนจอ
บทสำคัญที่สุดของช่วงเริ่มต้น: เราจะสร้าง project, รัน code ที่ Flutter สร้างให้ และแก้ข้อความหนึ่งจุด ยังไม่ต้องเข้าใจทุกบรรทัด

1. เลือกโฟลเดอร์ทำงาน

เปิด Terminal ในโฟลเดอร์ที่เก็บ project เช่น C:\Users\User\Documents\GitHub ชื่อ project ใช้ตัวพิมพ์เล็กและ underscore

flutter create hello_flutter
cd hello_flutter

2. ตรวจว่า Project ถูกสร้าง

flutter pub get
flutter analyze

pub get เตรียม dependencies ส่วน analyze ตรวจ code โดยยังไม่เปิดแอป หากสองคำสั่งผ่าน เรามี baseline ที่ดี

3. รันแอป

flutter devices
flutter run -d chrome

เปลี่ยน chrome เป็น device ID ของ Emulator/มือถือได้ Terminal จะ build แล้วเปิดแอปตัวอย่าง Counter

4. ไฟล์แรกที่ต้องเปิด

เปิด lib/main.dart แล้วค้นหาข้อความ Flutter Demo Home Page ตอนนี้ให้คิดว่าไฟล์นี้คือจุดเริ่มของแอป ส่วนรายละเอียด class และ widget จะเรียนหลัง Dart Foundation

5. แก้สิ่งที่มองเห็นได้

เปลี่ยน title เป็นข้อความของคุณ เช่น คลังสินค้าของฉัน บันทึกไฟล์แล้วดูหน้าจอ

home: const MyHomePage(title: 'คลังสินค้าของฉัน'),

ถ้าหน้าจอเปลี่ยน แปลว่า source → build → device ทำงานครบเส้นทางแล้ว

6. หยุดและรันใหม่

ใน Terminal ที่กำลังรัน กด q เพื่อหยุด จากนั้นใช้คำสั่งเดิมเพื่อเปิดใหม่ การปิด browser อย่างเดียวอาจไม่หยุด process

7. Error แรกควรทำอย่างไร

  1. อ่านข้อความ error แรก ไม่เริ่มจากบรรทัดท้ายทั้งหมด
  2. ดูชื่อไฟล์และเลขบรรทัด
  3. ย้อนการแก้ล่าสุดหนึ่งจุด
  4. รัน flutter analyze
อย่าคัดลอก project ใหม่ทับของเดิมเพื่อหนี error เพราะเราจะเสียโอกาสเรียนรู้วิธีอ่านหลักฐาน

8. แบบฝึกหัดและเฉลย

เปลี่ยน title เป็นชื่อแอปที่คุณอยากสร้าง รันบน device และถ่ายภาพผลลัพธ์ไว้เป็น checkpoint

ผ่านเมื่อใด

ผ่านเมื่อแอปเปิดบน device, แสดงข้อความใหม่ และ flutter analyze ไม่มี error ไม่จำเป็นต้องลบ counter เดิมในบทนี้

9. สรุปจำเร็ว

flutter create สร้าง project, flutter run เปิดแอป และ lib/main.dart คือ source เริ่มต้น บทถัดไปจะอธิบายว่าโฟลเดอร์อื่นมีไว้ทำอะไร
