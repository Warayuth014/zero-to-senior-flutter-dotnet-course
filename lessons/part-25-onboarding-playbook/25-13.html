แบบประเมินจบคอร์ส: วัดจากการ trace/diagnose/change/prove/operate codeจริง ไม่ใช่จำชื่อ widgetหรืออ่านครบกี่เปอร์เซ็นต์

1. Level 1 — Read

เปิดโปรเจกต์ใหม่แล้วหา entry, composition root, feature, state owner, repository/API, modelและ testsของหนึ่ง flowได้ อธิบาย local/server source of truthและ lifecycle resources

2. Level 2 — Trace

trace scan/tapจาก UIถึง .NETและกลับผ่าน response/SignalR/pollingได้ ระบุ exact route/body/status, auth, mapping, state commit/rebuildและ failure pathโดยมี evidence

3. Level 3 — Diagnose

แยก layout/state/lifecycle/network/contract/server bug, reproduce deterministic, อ่าน stack/log/traceIdและสร้าง regression testโดยไม่แก้เดาสุ่มหรือเปิด security bypass

4. Level 4 — Change

เพิ่ม typed endpoint+repository+store+screen/workflowผ่าน composition root รักษา async/idempotency/session semanticsและไม่สร้าง raw JSON/global dependency/God Storeใหม่

5. Level 5 — Prove

มี unit/store/widget/contract/integration testsครอบ happy/failure/race, analyze/buildผ่าน, review diff/generated filesและอธิบาย compatibility/deploy/rollbackได้

6. Level 6 — Operate

สร้าง signed release, configure HTTPS/server profile, monitor correlation/metrics, handle expired session/reconnect/incidentและเขียน runbookที่ทีมอื่นใช้ได้โดยไม่เปิด secrets

7. Practical exam

โจทย์: เพิ่ม “Hold Task with reason”
1 trace current Task flow
2 define .NET contract/auth/idempotency
3 implement typed vertical slice
4 test 409, double tap, timeout-after-commit, SignalR
5 release note + rollback + support evidence

8. พร้อมทำงานจริงเมื่อใด

พร้อมเมื่อทำ Level 1–5กับ flowที่ไม่เคยเห็นได้อย่างอิสระและรู้ว่าเมื่อใดต้องถาม domain/backend/security owner Seniorไม่ใช่คนที่เดาทุกอย่างถูก แต่ทำ uncertaintyให้มองเห็นและพิสูจน์ก่อนเสี่ยง production
