fromJson คือ untrusted boundary; toJson คือ request contract ทั้งสองควร testและไม่ assumeชนิด runtime

1. Parse

factory TaskDto.fromJson(Map<String, dynamic> j) => TaskDto(
  id: requireString(j, 'id'),
  qty: readDouble(j['qty']),
);

2. Serialize

Map<String, Object?> toJson() => {'taskId': id, 'qty': qty};
