ข้อความเป็นข้อมูลแบบ dynamic: ภาษา, font, text scale และค่าจาก API เปลี่ยนความยาวได้ Responsive UI ต้องกำหนด priority, line budget และ fallback โดยไม่ซ่อนข้อมูลปฏิบัติงานสำคัญ

1. Text overflow ต้องมี bounded width

Row(children: [
  const Icon(Icons.inventory),
  const SizedBox(width: 8),
  Expanded(
    child: Text(
      partName,
      maxLines: 2,
      overflow: TextOverflow.ellipsis,
    ),
  ),
])

ถ้า Text ใน Row ไม่ได้รับ maxWidth ที่จำกัด ellipsis ไม่มีจุดตัด จึงต้องใช้ Expanded/Flexible/ConstrainedBox ก่อนตั้ง overflow

2. clip, fade, ellipsis และ visible

ellipsis สื่อว่ามีข้อความต่อแต่ต้องมีทางดูเต็ม เช่น detail/tooltip; fade เหมาะ decorative text; clip อาจดูเหมือนข้อมูลขาด; visible เสี่ยงชน widget อื่น สำหรับ barcode, location หรือ quantity ที่ห้ามตีความผิด ควร wrap/แยกบรรทัดหรือเปิด detail มากกว่าตัดเงียบ

3. AutoSizeText ทำอะไร

AutoSizeText(
  title,
  maxLines: 2,
  minFontSize: 10,
  stepGranularity: 0.5,
  overflow: TextOverflow.ellipsis,
)

มันลองลด font ภายใน bounds จนพอดีหรือถึง min แล้วใช้ overflow Absolute Home ใช้กับ title/subtitle ของ tile ที่ height เปลี่ยน แต่ต้องมี bounded width/height และห้ามตั้ง min ต่ำจนอ่านไม่ได้

4. ลำดับ fallback ที่ปลอดภัย

  1. ให้ width/flex ที่ถูกต้อง
  2. อนุญาตเพิ่มบรรทัด
  3. ปรับ composition/ซ่อน secondary content เมื่อ narrow
  4. ลด font ในช่วงจำกัด
  5. ellipsis พร้อมทางดูข้อมูลเต็ม

อย่าเริ่มจากลด font เพราะแก้ภาพได้แต่ทำลาย ergonomics

5. Text scale และ accessibility

ทดสอบ TextScaler สูงอย่างน้อย 1.3 และ 2.0 หลีกเลี่ยง Container height ตายตัวรอบข้อความสำคัญ ปุ่มควรขยายสูงหรือ wrap ได้ ไม่ clamp text scale ทั้งแอปเพื่อรักษาหน้าตา หาก PDA มี policy เฉพาะต้องบันทึกเหตุผลและยังมีขนาดอ่านได้

6. Localization จริง

คำไทยอาจตัดบรรทัดต่างจากอังกฤษและรหัสคลังอาจไม่มีจุดตัด ใช้ softWrap, zero-width strategy เฉพาะ identifier ที่ยอมตัดได้ และทดสอบค่าจาก API ยาวสุด Absolute ส่ง narrow ให้ tile เพื่อกำหนด maxLines/sub style ตามพื้นที่

7. แบบฝึกหัด

Tile แสดงชื่อ location, description และจำนวนค้าง บนจอเตี้ย ควรเก็บอะไรและยอมลดอะไร?

แนวคำตอบ

รักษา location identifier และจำนวนค้างซึ่งใช้ตัดสินงาน; description เป็น secondary จึงซ่อน/ellipsis เมื่อ tight; เปลี่ยน tile เป็น Row, ให้ชื่อ 1–2 บรรทัด แล้ว AutoSize ในช่วงอ่านได้ ไม่ตัดจำนวนหรือทำ font ทั้ง tile เหลือ 7px

8. จุดพลาด

Tooltip ที่แสดงเฉพาะ hover ไม่ช่วยผู้ใช้ PDA แบบสัมผัส ให้ข้อมูลเต็มเข้าถึงได้ด้วย tap/detail/semantics และอย่าใช้ ellipsis กับ serial/lot/location แล้วให้ผู้ใช้เดาว่ารายการใด
