Stack เหมาะกับองค์ประกอบที่ซ้อนเชิงภาพและมี owner ของพื้นที่ชัด เช่น badge บนการ์ด, loading overlay หรือปุ่มลอย ไม่เหมาะกับการสร้าง layout ปกติทั้งหน้าด้วยพิกัดคงที่

1. Stack วัดลูกอย่างไร

Non-positioned children มีส่วนกำหนดขนาด Stack ส่วน Positioned children ถูกวางหลัง Stack รู้ขนาดแล้ว ค่า alignment จัด non-positioned/partially positioned child และ fit ควบคุม constraints ที่ส่งให้ non-positioned children

2. Badge บน tile

Stack(
  clipBehavior: Clip.none,
  children: [
    WarehouseTile(onTap: onTap),
    if (count > 0)
      Positioned(top: -6, right: -6, child: CountBadge(count)),
  ],
)

Tile ยังเป็น non-positioned owner ของขนาด Badge เป็น decoration ที่ไม่เปลี่ยน flow ต้องเผื่อไม่ให้ถูก parent clip และเพิ่ม semantics ให้ screen reader อ่านจำนวนด้วย

3. Positioned และ Positioned.fill

กำหนด left+right จะบังคับ width, top+bottom จะบังคับ height; กำหนดเพียงด้านเดียว child เลือกขนาดอีกส่วน Positioned.fill เหมาะกับ overlay เต็มพื้นที่ เช่น absorb input ระหว่าง submit

4. Loading overlay ที่ปลอดภัย

Stack(children: [
  const WorkflowBody(),
  if (busy)
    const Positioned.fill(
      child: ColoredBox(
        color: Color(0x55000000),
        child: Center(child: CircularProgressIndicator()),
      ),
    ),
])

ถ้าต้อง block tap ใช้ ModalBarrier หรือ AbsorbPointer อย่างชัดเจน พร้อม semantics/label และอย่าลืม error path ที่ปิด busy

5. clipBehavior และ hit testing

Clip.none ทำให้ภาพวาดล้นได้ แต่ส่วนที่อยู่นอก bounds ของ Stack อาจไม่ได้รับ hit ตามที่คาดและอาจชน sibling ถ้าต้องกดได้ให้ขยาย owner bounds/touch target ไม่ใช้การวาดล้นเป็นพื้นที่ปฏิสัมพันธ์หลัก

6. Overlay/Portal ต่างจาก Stack

Dropdown, tooltip, toast และ menu ที่ต้องลอยเหนือ route หรือหนี clip ของ ancestor ควรใช้ Overlay, OverlayPortal หรือ API ของ Material เช่น showMenu/showDialog Stack ใช้ได้เฉพาะขอบเขต subtree ของมัน

7. แบบฝึกหัด

จะแสดงวงกลมสถานะ online ที่มุม avatar และต้องกด avatar ได้เต็ม 48×48 ควรให้ใครรับ gesture?

เฉลย

ให้ Stack/SizedBox มีขนาด 48×48 และ avatar เป็นปุ่ม/InkWell เจ้าของ gesture วาง status เป็น Positioned ภายใน bounds หรือ IgnorePointer ถ้าเป็น decoration เท่านั้น เพิ่ม semantic value “ออนไลน์” ให้ avatar ไม่ทำวงกลมเล็กเป็น target แยก

8. จุดพลาด

การวาง form ด้วย Positioned(top: 120, left: 16...) จะพังเมื่อ keyboard, rotation, tablet หรือ text scale เปลี่ยน ใช้ Flex/scroll/constraints สำหรับ flow ปกติ และใช้ Stack เฉพาะความสัมพันธ์การซ้อนจริง
