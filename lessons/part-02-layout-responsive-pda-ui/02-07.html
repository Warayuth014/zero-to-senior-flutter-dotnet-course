List/Grid ที่ดีต้องตัดสินใจ 4 เรื่อง: lazy creation, item identity, extent และ responsive column count โดยไม่ผูก business model เข้ากับ index ที่เปลี่ยนได้

1. ListView.builder contract

ListView.builder(
  itemCount: visibleTasks.length,
  itemExtent: 64,
  itemBuilder: (_, i) {
    final task = visibleTasks[i];
    return TaskTile(key: ValueKey(task.id), task: task);
  },
)

itemCount ป้องกันเรียกเกิน, stable key รักษา state ตาม task, itemExtent/prototypeItem ช่วยคำนวณ scroll geometry เร็วเมื่อความสูงคงที่

2. Separator และ empty/loading/error

ใช้ ListView.separated เมื่อ separator ไม่ใช่ข้อมูล อย่าแทรก divider แล้วคูณ index เพราะ key/semantics ซับซ้อน State ของหน้าต้องแยก loading, error, empty และ data ให้ชัด ไม่ใช้ list ว่างแทนทุกสถานะ

3. GridView delegate

GridView.builder(
  gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: columns,
    mainAxisSpacing: gap,
    crossAxisSpacing: gap,
    mainAxisExtent: tileHeight,
  ),
  itemCount: menus.length,
  itemBuilder: (_, i) => MenuTile(menu: menus[i]),
)

FixedCrossAxisCount คุมจำนวนคอลัมน์; MaxCrossAxisExtent คุมความกว้างสูงสุดต่อ tile และให้ frameworkหาจำนวนคอลัมน์ เหมาะกับ tablet/web ที่ช่วงกว้างมาก

4. Absolute Home grid

Home กำหนด 2 คอลัมน์คงที่สำหรับงาน PDA และคำนวณ mainAxisExtent ให้สามแถวพอดีกับพื้นที่ Expanded เมนูที่เกินแถวสามจึงเลื่อน เป็น design decision ที่ทำให้ operation หลักอยู่ first viewport เสมอ ไม่ใช่ grid auto-fit ทั่วไป

5. Grid aspect ratio vs mainAxisExtent

childAspectRatio ผูกสูงกับความกว้าง เหมาะ tile รูปทรงสม่ำเสมอ; mainAxisExtent ระบุความสูงตรง เหมาะเมื่อความสูง viewport/ข้อความเป็นตัวกำหนด ห้ามใส่ทั้งคู่ใน delegate เดียว ตรวจชื่อไทย/อังกฤษและ text scale ก่อนล็อก extent

6. Pagination และ cache extent

รายการจาก API จำนวนมากควรโหลดเป็นหน้าเมื่อใกล้ท้าย, ป้องกัน request ซ้ำ และแสดง retry row อย่าเพิ่ม cacheExtent มากเพื่อซ่อน jank โดยไม่ profile เพราะแลก memory/build ล่วงหน้า รูปควร resize/cache ตามขนาดแสดง

7. แบบฝึกหัด

บน PDA ต้อง 2 คอลัมน์ แต่ tablet ต้อง tile กว้างอย่างน้อย 180 และไม่เกิน 260 จะเลือก delegate อย่างไร?

แนวคำตอบ

ที่ breakpoint PDA ใช้ fixed 2 columns; tablet ใช้ LayoutBuilder คำนวณ columns จาก availableWidth หรือใช้ SliverGridDelegateWithMaxCrossAxisExtent(maxCrossAxisExtent: 260) แล้วตรวจว่าความกว้างจริงไม่ต่ำกว่า 180 โดยคำนวณขั้นต่ำ/จำกัด max content width

8. จุดพลาด

ห้ามใช้ index เป็น identity ของ item ที่ reorder/filter/insert เพราะ checkbox, animation หรือ controller อาจย้ายไปอยู่ข้อมูลคนละแถว ใช้ key จาก domain ID และให้ selection state อ้าง ID ไม่อ้างตำแหน่ง
