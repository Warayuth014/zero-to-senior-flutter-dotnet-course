Lab: สร้าง Responsive Warehouse Home จาก menu data ชุดเดียว ให้ PDA แคบ/เตี้ยและ tablet ใช้งานได้ รักษา touch target, ข้อมูลหลัก, scroll ownership และ widget identity พร้อมเทียบ design decision กับ Home ของสอง codebase

1. Acceptance criteria

  • PDA 320×568 และ 400×800 แสดง operation หลัก 6 รายการโดยไม่ RenderFlex overflow
  • จอเตี้ยใช้ compact/tile แนวนอน; tablet เพิ่ม columns และจำกัด content width
  • เมนูเกิน first viewport เลื่อนได้ด้วย GridView เดียว
  • badge มี label/icon/สีและ semantics ไม่พึ่งสีอย่างเดียว
  • ชื่อยาว/text scale 2.0 ยังเข้าถึงข้อมูลเต็มได้
  • tap ส่ง menu ID กลับ owner ไม่เรียก API ใน tile

2. Model และ layout policy

typedef WarehouseMenu = ({
  String id,
  String title,
  String subtitle,
  IconData icon,
  int pending,
});

class WarehouseLayout {
  const WarehouseLayout(this.columns, this.compact, this.gap);
  final int columns;
  final bool compact;
  final double gap;

  factory WarehouseLayout.from(BoxConstraints c) {
    final compact = c.maxHeight < 650 || c.maxWidth < 360;
    final columns = c.maxWidth >= 900 ? 4 : c.maxWidth >= 600 ? 3 : 2;
    return WarehouseLayout(columns, compact, compact ? 8 : 12);
  }
}

4. Responsive grid implementation

LayoutBuilder(builder: (context, c) {
  final spec = WarehouseLayout.from(c);
  return Column(children: [
    WarehouseHeader(compact: spec.compact),
    SizedBox(height: spec.gap),
    Expanded(
      child: GridView.builder(
        key: const PageStorageKey('warehouse-home-grid'),
        padding: EdgeInsets.all(spec.gap),
        gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
          crossAxisCount: spec.columns,
          crossAxisSpacing: spec.gap,
          mainAxisSpacing: spec.gap,
          mainAxisExtent: spec.compact ? 88 : 136,
        ),
        itemCount: menus.length,
        itemBuilder: (_, i) => WarehouseMenuTile(
          key: ValueKey(menus[i].id),
          menu: menus[i],
          compact: spec.compact,
          onTap: () => onSelected(menus[i].id),
        ),
      ),
    ),
  ]);
})

5. Tile contract

เมื่อ compact ใช้ Row(icon → Expanded title/subtitle → chevron) เมื่อปกติใช้ Column; badge วางด้วย Stack แต่ยังอยู่ใน tile bounds; title มี maxLines 2, subtitle เป็น secondary; InkWell/Material ครอบพื้นที่เต็มและ Semantics อ่าน “รับสินค้าเข้า, งานค้าง 12, ปุ่ม”

6. Widget tests

testWidgets('PDA uses two columns without overflow', (tester) async {
  tester.view.physicalSize = const Size(320, 568);
  tester.view.devicePixelRatio = 1;
  addTearDown(tester.view.resetPhysicalSize);
  addTearDown(tester.view.resetDevicePixelRatio);

  await tester.pumpWidget(buildHome(textScale: 1));
  expect(find.byType(WarehouseMenuTile), findsWidgets);
  expect(tester.takeException(), isNull);
});

testWidgets('tap returns stable domain id', (tester) async {
  String? selected;
  await tester.pumpWidget(buildHome(onSelected: (id) => selected = id));
  await tester.tap(find.byKey(const ValueKey('receive')));
  expect(selected, 'receive');
});

7. เทียบกับโปรเจกต์จริง

Absolute เหมาะกับ fixed PDA operations: 2 columns และคำนวณสามแถวจาก available height พร้อม tile เปลี่ยน composition รายใบ ส่วน wmsapp Home ใช้คู่ Row/Expanded ใน SingleChildScrollView อ่านง่ายสำหรับเมนูคงที่แต่ยังไม่ adapt columns จาก width Lab นี้เก็บข้อดีทั้งสอง: data-driven lazy grid + local constraints + component vocabulary
