Row และ Column คือ Flex คนละทิศ: main axis อยู่ตามทิศวางลูก ส่วน cross axis ตั้งฉากกัน การอ่าน layout ให้เริ่มจากทิศ ไม่เริ่มจากชื่อ property

1. แผนที่แกน

WidgetMain axisCross axis
Rowซ้าย→ขวา (ตาม text direction)บน→ล่าง
Columnบน→ล่างซ้าย→ขวา

MainAxisAlignment แจกพื้นที่ตามแนววางลูก; CrossAxisAlignment จัดลูกข้ามแนว การตั้ง stretch ต้องมี cross-axis constraint ที่ชัดเจน

2. Row สำหรับข้อมูลหนึ่งบรรทัด

Row(children: [
  const Icon(Icons.inventory_2),
  const SizedBox(width: 8),
  Expanded(child: Text(partName, overflow: TextOverflow.ellipsis)),
  Text(quantity.toString()),
])

ข้อความกลางรับพื้นที่ที่เหลือผ่าน Expanded จึงเป็นผู้ยอมตัดก่อน quantity สำคัญทางขวา นี่คือการกำหนด priority ไม่ใช่แค่ตกแต่ง

3. Column สำหรับโครงหน้าจอ

Column(
  crossAxisAlignment: CrossAxisAlignment.stretch,
  children: [
    const ScanHeader(),
    Expanded(child: ResultList()),
    const ConfirmButton(),
  ],
)

Header และปุ่มใช้ intrinsic/fixed height; list เป็น flex child กินพื้นที่ที่เหลือ CrossAxis stretch ทำให้ลูกที่ยอมรับ constraint เต็มความกว้าง

4. mainAxisSize และพื้นที่ขั้นต่ำ

MainAxisSize.max พยายามใช้ main-axis สูงสุดที่ bounded; min หดเท่าผลรวมลูก เหมาะกับ dialog/card แต่ถ้า parent ส่ง main-axis tight ค่า min ไม่สามารถฝ่าฝืน constraint ได้ อย่าสับสนว่า min ทำให้ widget เล็กเสมอ

5. Baseline และข้อความหลายภาษา

การจัด CrossAxisAlignment.center ไม่เท่ากับ baseline ของตัวอักษร ถ้าต้องจัด text ต่าง font size บนฐานเดียว ใช้ baseline พร้อม textBaseline แต่ UI ไทย/อังกฤษหลายบรรทัดมักปลอดภัยกว่าด้วย start + explicit line height และทดสอบข้อความจริง

6. จากสอง WMS

wmsapp ใช้ Row + Expanded เป็นคู่การ์ดหน้า Home ทำให้แต่ละใบกว้างเท่ากัน แต่ชื่อยาวอาจทำความสูงไม่เท่ากันจึงครอบ IntrinsicHeight ซึ่งมี cost เพิ่ม ส่วน Absolute ใช้ Row ใน summary โดยซ่อน status เมื่อ narrow และให้ label เป็น Expanded เพื่อรักษาค่าตัวเลขทางขวา

7. แบบฝึกหัด

Header มีชื่อคลังยาว, connection chip และปุ่ม logout บน PDA กว้าง 320 ควรกำหนดลำดับการยอมเสียพื้นที่อย่างไร?

แนวคำตอบ

ให้ชื่อคลังอยู่ Expanded + maxLines 1 + ellipsis, chip จำกัดขนาด/ใช้ icon เมื่อ narrow, logout มี touch target คงที่ ใช้ SizedBox gap ที่ชัด ไม่ใช้ spaceBetween เป็นตัวแก้ชื่อยาวเพราะมันไม่จำกัด child

8. จุดพลาด

mainAxisAlignment: spaceBetween ไม่ได้ป้องกัน overflow มันแจกเฉพาะพื้นที่ “ที่เหลือหลังวัดลูก” ถ้าผลรวมลูกใหญ่กว่า Row ก็ยังล้น ต้องทำให้ child ที่ยืดหยุ่นได้รับ bounded width ด้วย Expanded/Flexible
