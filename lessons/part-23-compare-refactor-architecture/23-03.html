โค้ดจริง: wmsapp.ApiServiceคืน ApiResult<T>; absolute.ApiClientโยน ApiExceptionแล้ว repository/storeกำหนดว่าจะ catchตรงไหน

1. ApiResult model

ผู้เรียกเห็น success/data/error/statusCodeใน typeและถูกบังคับเชิง conventionให้ branch เหมาะกับ expected failuresและทำให้ UIแสดงข้อความโดยไม่ใช้ try/catch แต่ nullable data+errorยังสร้าง invalid combinationsได้หาก classไม่ sealed

2. Exception model

happy pathคืน valueตรงๆและ failureข้าม stackถึง boundaryที่เลือกได้ Absoluteแปล network/statusเป็น ApiException แต่ unexpected parse/type errorsบางชนิดยังหลุดเป็น exceptionอื่น จึงต้องกำหนด catch policyไม่กลืน programmer bug

3. Expected vs exceptional

validation conflict, not foundที่เป็น flowและ insufficient stockควรเป็น typed domain failure ส่วน socket/timeout/invalid server payloadอาจเป็น infrastructure exception ไม่ควรใช้ข้อความภาษาไทย stringเดียวเป็น machine-readable decision

4. Sealed Result ที่แข็งแรงกว่า

sealed class Result<T> {}
final class Ok<T> extends Result<T> { final T value; }
final class Err<T> extends Result<T> { final AppFailure failure; }

AppFailure(code, message, status, retryable, cause)

pattern matchingบังคับ exhaustive branchesและไม่มี data/errorพร้อมกัน

5. อย่าแปลง errorเร็วเกินไป

wmsapp ApiServiceแปลง catchทั่วไปเป็นข้อความ ทำให้ stack/causeหาย ส่วน absoluteบาง store catch ApiExceptionเพื่อ toastแล้วกลืน Senior boundaryควรเก็บ structured causeเพื่อ log/metrics ขณะ UIเห็นข้อความปลอดภัย

6. Command uncertainty

timeoutของ GET retryได้ง่าย แต่ timeoutหลัง POSTอาจ commitแล้ว ทั้ง ResultและExceptionไม่ได้แก้ปัญหานี้ ต้องมี failure kind “outcome unknown”, idempotency keyและ reconciliation query

7. Migration โดยไม่ big bang

สร้าง adapterจาก ApiResultเดิมเป็น Resultใหม่ที่ repository seam แล้ว migrateทีละ feature ไม่เปลี่ยนทุก extensionพร้อมกัน Testsต้องล็อก status/message/retryabilityและ unexpected JSON behavior

8. Decision

เลือก styleเดียวภายใน layer, ใช้ typed failuresข้าม domain boundary, exceptionสำหรับ truly unexpected/infrastructureแล้ว catchที่ explicit boundary และไม่ให้ widgetตัดสิน business flowจากข้อความ string
