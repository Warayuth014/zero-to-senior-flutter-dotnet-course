Security reviewจริง: wmsapp loginเป็น mock user/passwordและเก็บ identityใน SharedPreferences; absoluteเรียก .NET Authenticate, ถือ JWTใน memoryและแนบ Bearer แต่ยังไม่มี secure persistence/roles enforcement/central 401 flow

1. Authentication vs UI gate

wmsappตรวจ password 1234ใน clientและเลือก seeded userจึงเป็น demo gate ไม่ใช่ authentication Backend APIsไม่ควรเชื่อ userId/roleจาก SharedPreferencesหรือปุ่มที่ซ่อน ต้อง authorizeทุก mutationฝั่ง .NET

2. Absolute baseline

AuthRepositoryรับ token/expirationจาก /api/Authenticate/login, ตั้ง ApiClient.authTokenและ clearเมื่อ logout ดีกว่าสำหรับ authenticated requests แต่ rolesถูกตั้งว่างและ expirationยังใช้แสดงมากกว่าบังคับ session lifecycle

3. Token storage

memory-onlyลดความเสี่ยง diskแต่ต้อง loginเมื่อ app restart หากต้อง remember sessionใช้ platform secure storage ไม่ใช้ SharedPreferencesและกำหนด refresh/revocation policy ชัดเจน Flutter Webมี threat modelต่างจาก Android PDA

4. 401 boundary

ApiClientควรแยก unauthenticatedจาก generic ApiException แจ้ง session coordinatorให้ logout/refreshหนึ่งครั้งและหยุด commandsที่รอ ไม่ให้ทุก screenจับ 401เองจน dialogซ้ำหรือใช้ tokenเก่า

5. Server switching

absoluteเก็บ ApiClientตลอด sessionขณะ active base URLอ่านใหม่ทุก request หากเปลี่ยน server tokenเดิมอาจถูกส่งไป hostใหม่ ควรบังคับ logout/re-authหรือ verify trust boundaryก่อน activate profile

6. Local data hygiene

logoutต้อง clear domain stores, scans, cached operator identity, SignalR subscriptionsและpending async generations ไม่ใช่ลบ tokenอย่างเดียว wmsapp prefs.clear()กว้างเกินไปเพราะอาจลบ settingsที่ไม่ใช่ session

7. Logging และ transport

ห้าม log JWT/password/full sensitive payload ใช้ HTTPSและ certificate trustที่เหมาะกับ private network ข้อความ errorไม่ควรเผย stack/SQL Backend auditต้องบันทึก authenticated user ไม่เชื่อ usernameที่ clientส่งใน body

8. Security test matrix

ทดสอบ bad credentials, expired/revoked token, concurrent 401, logoutระหว่าง request, server switch, role denied, app restartและ log redaction พร้อม .NET authorization integration tests เพราะ widgetซ่อนปุ่มไม่ใช่ security control
