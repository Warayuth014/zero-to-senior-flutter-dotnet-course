API Extension vs Repository

Part 23: Senior Architecture Decisions

เปรียบเทียบ: wmsappแบ่ง endpointด้วย part extensionsบน singleton ApiService; absoluteประกาศ *Repository interfacesและให้ *Api implement

1. API extension จุดแข็ง

ReceivingApi/PackingApi extensionsจัดไฟล์ endpointตาม domainโดย reuse transport private methodsและ typed models Call siteสั้น, boilerplateน้อยและเหมาะกับ clientตรงไปตรงมาที่ behaviorไม่มีหลาย implementation

2. ข้อจำกัด extension

extensionไม่มี instance identityหรือ dependencyของตัวเอง ทุก screenยังผูก ApiService singletonและการ fakeต้องแตะ global/network ทำให้ widget testsยาก แม้ไฟล์ดู modularแต่ runtime couplingยังรวมศูนย์

3. Repository จุดแข็ง

Absolute storeพึ่ง ReceivingRepository/TasksRepository interfaces ไม่รู้ HTTP path/JSON Testsส่ง FakeRepositoriesได้ Repositoryยังรวมหลาย endpointsเป็น domain projection เช่น completed pick historyและ queue summary

4. Repository ไม่ควรเป็นชื่อใหม่ของ API

ถ้า interface mirrorทุก endpointและคืน raw map จะเพิ่ม boilerplateโดยไม่เพิ่ม seam Repositoryควรใช้ภาษาของ caller, คืน typed domain data, แปล transport failuresและซ่อน N+1/pagination/caching decisions

5. Layer boundary

Widget → Feature controller/store
       → Repository contract
       → HTTP data source / existing ApiService extension
       → .NET API

ใช้ extensionเดิมเป็น data sourceใต้ repositoryได้ ไม่ต้องทิ้งโค้ดที่ทำงานแล้ว

6. Interface placement

contractควรอยู่ใกล้ consumer/domain ไม่ผูก package http/json เพื่อให้ fakeไม่ต้องเลียน HTTP ส่วน implementationอยู่ infrastructure/APIและมี contract testsเทียบ endpointจริง

7. เลือกตาม volatility

simple read-only featureอาจใช้ typed API clientตรงๆ แต่ workflowที่หลาย call, testสำคัญ, offline/cacheหรือ backendเปลี่ยนบ่อยคุ้มกับ repository Absoluteได้ประโยชน์ใน warehouse flowsแต่ AuthRepositoryยังผูก ApiClientได้เพราะ scopeเล็ก

8. Exercise

ครอบ PackingApiหนึ่ง featureด้วย PackingRepositoryโดยไม่แก้ endpointเดิม เขียน fake success/failureและ contract test mapping หาก interfaceเพียง copy methodเดิมทุกตัว ให้ทบทวนว่ามี abstraction valueจริงหรือไม่
