2. Startup

load() ต้องเสร็จก่อน requestแรก: decode/migrate/seed → resolve active → notify/ready แล้ว auth restoreจึง bindกับ serverถูกตัว

3. Commands

แยก saveAsNew, saveEdits, select, delete, refreshStatus เพื่อ invariants/testsชัด ไม่ expose mutable listหรือ activeId setter

4. Probe generation

final generation = ++_probeGeneration;
_phase = ConnectionPhase.checking; notifyListeners();
final result = await probe(resolvedUrl);
if (generation != _probeGeneration) return;
lastResult = result; _phase = result.ok ? online : offline;
notifyListeners();

5. Dependency direction
