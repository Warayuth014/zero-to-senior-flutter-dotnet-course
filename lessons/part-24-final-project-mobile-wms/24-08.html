1. Store responsibilities

ถือ immutable view state, expose derived gettersและรับ user intentsเป็น methods Storeรักษา invariant/async semanticsแต่ไม่เปิด dialog, BuildContext, colorsหรือ TextEditingController

2. State shape

sealed LoadState<T> = initial|loading|data|failure
CommandState = idle|submitting(key)|success|failure
FeatureState = query snapshot + selection + command state

แยก initial loadจาก refreshเพื่อไม่ซ่อนข้อมูลเดิมด้วย spinnerทุกครั้ง

3. Feature scope

Auth/Connection app/session scope; Receiving, Inventory, CycleCount, Tasks feature scope Shell coordinatorถือ route/tabและส่ง cross-feature invalidation เช่น receive success→inventory stale

4. DI without framework first

constructor injectionและ composition rootพอสำหรับขนาดนี้ Provider/Riverpod/get_itเพิ่มเมื่อช่วย lifecycle/readabilityจริง ไม่ใช้ service locatorให้ leaf widgetค้น global dependenciesเอง

5. Async safety

latest-wins lookupใช้ generation, submitใช้ in-flight key/exhaust, polling single-flight+pending refresh, logoutเพิ่ม session generationและ dispose cancel timer/subscription Future completionต้องตรวจ identityก่อน commit

6. Notify boundary

mutation transactionตั้ง stateครบแล้ว notifyหนึ่งครั้งเท่าที่เป็นไปได้ Public listsเป็น unmodifiableและ widgetsเรียก commandsแทนแก้ field หาก rebuildกว้างให้ split listenable/selector ไม่ละ notify

7. Ownership/disposal

objectที่สร้าง storeเป็นผู้ dispose Store dispose timer/stream/http-owned resources Widget dispose local focus/controllers ห้าม TaskScreen dispose storeถ้า composition rootต้อง reuseข้าม route—ประกาศ ownershipให้ชัด

8. Store test matrix

initial/loading/data/empty/failure, retry, responseเก่ามาทีหลัง, duplicate submit, dispose/logoutระหว่าง await, refreshรักษาข้อมูลเดิมและ cross-feature invalidationด้วย fakes+controllable completers
