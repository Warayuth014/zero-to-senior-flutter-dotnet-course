Final Project contract: ต่อยอด labs/flutter_wms_companion และ labs/dotnet/WmsMobileApi จาก task vertical sliceให้เป็น Mobile WMS ที่มี production qualities โดยไม่จำลองว่า demoคือระบบพร้อมใช้งานจริง

1. Product outcome

Operator login, เลือก server, เห็น dashboard, รับสินค้า, ค้น inventory, ทำ cycle count, dispatch/complete manual task, รับ task updateและแนบรูปได้ ทุก mutationมี loading/error/retry/audit contextและไม่ส่งซ้ำจาก double scan

2. In scope

  • Flutter architecture/PDA UXครบ flow
  • HTTP/JWT/JSON/SignalR/multipart contracts
  • .NET endpointsบางเพื่อรัน integration
  • unit/widget/contract smoke tests
  • Android release/config/security checklist

3. Out of scope

ไม่สร้าง ERP, slotting algorithm, EF schemaจริง, Identity administration, AGV/ESS simulatorเต็มระบบหรือ offline conflict engine Logic .NETภายในให้อ้างคอร์ส backend; โปรเจกต์นี้เน้น clientและรอยต่อที่พิสูจน์ได้

4. Vertical slices

M0 starter: health + tasks + complete
M1 platform: shell + profile + auth
M2 read: dashboard + inventory
M3 mutations: receiving + cycle count + manual task
M4 integration: SignalR + image upload
M5 production: tests + release + observability

5. Acceptance criteria format

เขียน Given/When/Thenพร้อม error/race เช่น “Given task waiting, Whenสแกน palletถูกและ destinationถูก, Then completeครั้งเดียว; หาก response timeoutให้แสดง outcome unknownและ reloadก่อน retry” ไม่ใช้เกณฑ์กว้างว่า “หน้าทำงานได้”

6. Non-functional criteria

PDA viewportไม่ overflow, hardware Enterทำงาน, Thai/Englishอ่านได้, cold startชัดเจน, requests timeout, secretsไม่อยู่ source, logoutล้าง session, stale responseไม่ทับ stateใหม่และ release buildติดตั้งได้

7. Evidence pack

ส่ง source, README runbook, API examples, test output, architecture diagram, ADRหลัก, release artifact checksumและรายการข้อจำกัด Known Issues Screenshotอย่างเดียวไม่พิสูจน์ side effectsหรือ failure handling

8. Definition of done

ทุก slice traceได้ Widget→Store→Repository→ApiClient→.NET→state, acceptance testsผ่าน,ไม่มี P0/P1 known defect, configurationแยก environmentและ reviewerใหม่รันระบบได้จาก READMEโดยไม่ถามผู้เขียน
