Single source of truth: widgets อ่าน snapshot จาก TaskStore และส่ง intent กลับ Store ไม่มี widget ใดถือสำเนา task list ของตัวเอง

1. Encapsulation

Store เปลี่ยน fields เป็น private และเปิด List.unmodifiable(_tasks) เพื่อห้าม UI add/remove โดยไม่ผ่าน action ถ้า expose mutable list caller อาจเปลี่ยน state โดยไม่มี notifyListeners

2. State dimensions

  • _tasks: server snapshot ล่าสุดที่เชื่อถือ
  • _loading: read operation
  • _busyTaskIds: mutation ราย entity
  • _error: ปัญหาที่ต้องให้ผู้ใช้ตัดสินใจ
  • _actionMessage: feedback ของ action ล่าสุด

3. Derived state

bool get initialLoading => _loading && _tasks.isEmpty;
bool get refreshing => _loading && _tasks.isNotEmpty;

ไม่เก็บ booleans ซ้ำที่อาจขัดกัน เช่น initialLoading และ refreshing เป็น true พร้อมกัน

4. Intent methods

load และ complete เป็น public commands ที่รักษา invariant ทั้งหมด Widget ไม่เรียก repository ตรงและไม่ลบรายการเองหลัง response

5. Immutable update

หลัง complete สำเร็จ Store สร้าง list ใหม่ด้วย where(...).toList() ทำให้ listener เห็น snapshot ใหม่ชัด และหลีกเลี่ยงการ mutate collection ระหว่าง build

6. Error lifetime

เริ่ม action ใหม่เคลียร์ error/action message ที่เกี่ยวข้อง แต่ timeout reconciliation อาจ preserve warning ระหว่าง reload ต้องกำหนดว่า message ใด transient และ message ใดต้องอยู่จนผู้ใช้รับรู้

7. เมื่อ Store ใหญ่ขึ้น

ถ้าเพิ่ม filters, pagination, assignment, scan state จน change reasons มาก ให้แยก feature stores/immutable state ไม่ใช่ย้ายทุกอย่างเข้า God Store เพียงเพื่อมี SSOT เดียว

8. Review

ทุกการเปลี่ยน task list ต้องค้นเจอใน TaskStore เท่านั้น หากมี setState ลบ task ใน card หรือ screen แสดงว่าเกิด source of truth ที่สอง
