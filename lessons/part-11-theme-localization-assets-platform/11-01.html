ThemeData คือระบบ ไม่ใช่แค่สีหลัก: ColorSchemeกำหนด semantic colors ส่วน ThemeDataกำหนด typography, component defaults, density, shapesและ platform behaviorให้ UIสม่ำเสมอ

1. Color roles

const scheme = ColorScheme.light(
  primary: AppColors.primary,
  onPrimary: Colors.white,
  surface: AppColors.surface,
  onSurface: AppColors.heading,
  error: AppColors.danger,
  onError: Colors.white,
);

ใช้ roleเช่น surface/onSurface แทน hardcode black/whiteเพื่อรองรับหลาย theme

2. Component themes

กำหนด Card, InputDecoration, Filled/OutlinedButton, Dialog, SnackBarและProgressIndicatorส่วนกลาง ลด styleซ้ำและทำ touch targetทั้งแอปถูกพร้อมกัน

3. Material 3

useMaterial3: true เปลี่ยน defaultsหลาย component ควร screenshot/testหน้าหลักหลังเปิดและ customizeผ่าน theme ไม่แก้ widgetทุกจุด

4. Semantic status

success/warning/dangerอาจเป็น app tokensนอก ColorSchemeมาตรฐาน แต่ต้องมีคู่ foreground/backgroundที่ contrastพอและไม่ใช้สีเป็นข้อมูลเพียงอย่างเดียว

5. Context-aware access

final theme = Theme.of(context);
Text('งานรับเข้า', style: theme.textTheme.titleLarge);
Icon(Icons.inventory_2, color: theme.colorScheme.primary);

6. ของจริง

wmsapp/theme/theme.dart สร้าง light/darkจาก ColorSchemeและกำหนด component themesจำนวนมาก อีกแอปใช้ buildAppTheme() สำหรับ compact PDA light theme

7. แบบฝึกหัด

Card hardcode Colors.white และ text Colors.black จะเกิดอะไรใน dark mode?

เฉลย

Cardสว่างผิดธีม/contrastไม่สม่ำเสมอ ให้ใช้ colorScheme.surface/onSurfaceหรือ CardTheme

8. Theme tests

ตรวจ contrast, disabled/error/focus states, text scaling, light/dark, Material 3 componentsและ PDA touch targetsอย่างน้อย 48dp
