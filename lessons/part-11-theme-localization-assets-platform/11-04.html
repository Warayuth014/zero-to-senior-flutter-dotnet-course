ฟอนต์ไทยต้องประกาศ family + weightจริง: หาก weightไม่มี Flutterอาจ synthesize ทำให้ตัวอักษรเบลอ/metricsเปลี่ยนและ layout overflowต่างจากเครื่องพัฒนา

1. pubspec

flutter:
  fonts:
    - family: Sarabun
      fonts:
        - asset: assets/fonts/Sarabun-Regular.ttf
          weight: 400
        - asset: assets/fonts/Sarabun-Medium.ttf
          weight: 500
        - asset: assets/fonts/Sarabun-Bold.ttf
          weight: 700

2. Apply globally

ThemeData(
  fontFamily: 'Sarabun',
  textTheme: const TextTheme(/* Thai-friendly height/weights */),
);

3. YAML sensitivity

indentผิดหรือ asset path/caseไม่ตรงทำ build/runtimeหาไม่ได้ หลังแก้ pubspecรัน flutter pub get และ full restart ไม่หวัง hot reloadกับ asset manifest

4. Thai metrics

ทดสอบสระ/วรรณยุกต์, line height, clippingใน button/chip, ตัวเลขและอังกฤษผสม อย่าล็อก container heightจาก Latin textเพียงอย่างเดียว

5. Font license/size

เก็บ licenseตามข้อกำหนดและ includeเฉพาะ weightsที่ใช้ ฟอนต์หลายชุดเพิ่ม artifact sizeและ fallbackอาจทำ UIไม่สม่ำเสมอ

6. ของจริง

wmsapp/pubspec.yaml ประกาศ Sarabun Regular/Medium/Bold และ AppThemeกำหนด fontFamily: 'Sarabun' เป็นตัวอย่างครบเส้นทาง

7. แบบฝึกหัด

Textใช้ FontWeight.w600แต่มีไฟล์ 500/700เท่านั้นจะเกิดอะไร?

เฉลย

engineเลือก/synthesize weightใกล้เคียง ผลอาจไม่ตรง design; ใช้ weightที่มีหรือเพิ่มไฟล์ 600พร้อมประกาศถูก

8. Visual tests

ไทยยาว, mixed Thai/English/code, scale 1.0–2.0, light/darkและ Android/Windows rendererโดยไม่ clip/overflow
