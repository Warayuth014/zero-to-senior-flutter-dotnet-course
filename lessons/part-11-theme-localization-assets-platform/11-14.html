Lab ปิด Part 11: สร้าง branded PDA shellสองภาษา มี light/dark, design tokens, Sarabun/assets, localized formatting, accessible iconsและ system barsที่ถูกต้อง

1. Acceptance criteria

  • ThemeData light/darkใช้ semantic colors/component themes
  • mode/language persistและ bootstrapไม่ flash
  • ไทย/อังกฤษเปลี่ยนทั้ง Material + app labels
  • date/number formatตาม localeแต่ wire data invariant
  • assets/icons/font/launcher configถูก
  • SafeArea/system barsผ่านอุปกรณ์จริง
  • text scale 200%ไม่มี critical overflow

2. Shell composition

MaterialApp
 └─ AnnotatedRegion<SystemUiOverlayStyle>
    └─ SafeArea
       └─ WarehouseShell
          ├─ PdaStatusBar (server + connection)
          ├─ Header (logo + language + theme + user)
          └─ Feature body + bottom navigation

3. State wiring

ThemeControllerและAppLanguageControllerเป็น app-scoped listenables; ConnectionController/AuthStoreให้ server/user/status Shell render stateแต่ไม่ถือ duplicate

4. Localization set

แปล home actions, settings, auth/error/empty/loading, tooltipsและ dialog buttons; location/product codes verbatim; status/error codeผ่าน typed mapping

5. Visual matrix

  • TH/EN × light/dark
  • 360×640 PDA และ tablet
  • text scale 1.0/1.5/2.0
  • online/offline/error/long server name
  • keyboard open และ notch

6. Automated checks

widget testsเปลี่ยน locale/mode, goldenหรือ screenshot critical states, semantics labels/tooltips, asset load smokeและ analyzeป้องกัน hardcoded deprecated colorsตาม lintทีม

7. Code review

ค้น hardcoded user-facing strings/colors/magic spacing, formatter cache localeเก่า, icon-onlyไร้ tooltip, fixed heightที่ clipไทยและ SafeAreaซ้อนจน paddingเกิน

8. Exit test

เมื่อจบต้องเปลี่ยน brand/theme/languageจากจุดกลางได้ UIไทย/อังกฤษยังอ่านและแตะง่ายบน PDA, formattingไม่ทำ API contractพัง และ native system UIดูกลมกลืนทุก route
