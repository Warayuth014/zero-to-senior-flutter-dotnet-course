1. Declare

flutter:
  assets:
    - assets/icons/wms/
    - assets/images/branding/

directory entryรวมไฟล์ใน directoryตาม manifestแต่จัดโครงชัดและตรวจ case-sensitive CI

2. Resolution variants

assets/images/logo.png
assets/images/2.0x/logo.png
assets/images/3.0x/logo.png

Flutterเลือกตาม device pixel ratio ใช้ขนาด logicalใน widget

3. Fit and constraints

Image.asset('assets/images/branding/logo.png',
  width: 160, height: 56, fit: BoxFit.contain,
  errorBuilder: (_, __, ___) => const Icon(Icons.broken_image));

4. Raster vs vector

PNGเหมาะภาพ/alphaซับซ้อน, SVGเหมาะ logo/iconที่ scaleหลายจอ แต่ SVG featureบางอย่างอาจ renderต่าง ต้อง optimizeและ test package

5. Memory

อย่า decodeรูปกล้องหลาย megapixelเต็มขนาดเพื่อ thumbnail ใช้ cacheWidth/cacheHeightหรือ preprocess; assetขนาดใหญ่เพิ่ม appและmemoryแม้แสดงเล็ก

6. Hot reload

เพิ่ม pubspec/assetใหม่มักต้อง flutter pub get และ full restart หาก releaseหาไฟล์ไม่ได้ตรวจ case/pathและ asset manifestก่อนแก้ code
