1. SafeArea

Scaffold(
  body: SafeArea(
    bottom: false,
    child: WarehouseShell(),
  ),
);

หลีกเลี่ยง notch/status barแต่เลือก edgeตาม layout/navigation barจริง

2. Edge-to-edge

Androidรุ่นใหม่อาจวาด Flutterใต้ system bars ใช้ AnnotatedRegion<SystemUiOverlayStyle> + background color + SafeAreaให้พื้นที่ exposedดูเป็นแถบเดียว

3. Overlay style

const style = SystemUiOverlayStyle(
  statusBarColor: AppColors.statusBar,
  statusBarIconBrightness: Brightness.light,
  systemNavigationBarColor: AppColors.surface,
  systemNavigationBarIconBrightness: Brightness.dark,
);

4. Theme coordination

light/dark routeอาจต้อง styleต่าง AppBarThemeมี systemOverlayStyle ได้แต่ full-screen/route-specificใช้ AnnotatedRegionใกล้พื้นที่ที่วาดจริง

5. Keyboard/insets

SafeAreaไม่แก้ keyboardทั้งหมด ตรวจ viewInsets.bottom, Scaffold resizeและ scroll formให้ field/actionไม่ถูก IMEบังบน PDAจอสั้น

6. ของจริง

wms_absolute_mobile/main.dart ใช้ AnnotatedRegion, ColoredBoxและ SafeAreaใต้ MaterialApp builderเพื่อรวม native status barกับ branded navy PDA strip
