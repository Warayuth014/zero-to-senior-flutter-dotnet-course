Root navigator: scannerเป็น child URLของ taskแต่ใช้ parentNavigatorKey: root จึงคลุม app bar/navigation barและ pop resultกลับ branch detailได้

1. Visual requirement

กล้อง/scannerต้องใช้พื้นที่เต็มและไม่ให้ผู้ใช้สลับแท็บกลาง scan Root navigatorเหมาะกว่า branch navigator

2. Route config

GoRoute(path: 'scan',
  parentNavigatorKey: rootKey,
  name: 'taskScan', ...)

3. Push result

Detail await pushNamed<String> Scanner pop(result) แล้ว callerตรวจ mountedก่อน SnackBar/เปลี่ยน state

4. Deep link scanner

ต้องตัดสินว่า URL scannerเปิดตรงได้หรือควร redirect detailก่อน permission/context หากเปิดตรงต้องโหลด taskและจัด permissionเอง

5. Hardware lifecycle

Camera/controllerเริ่มเมื่อ route activeและ disposeเมื่อ pop App lifecycle pause/resumeต้องหยุด resource Route packageไม่จัดการ hardwareให้

6. Cancel

system backคืน null Callerต้องไม่ตีความเป็น scanว่างหรือส่ง API ควรแยก cancel, valid resultและerrorชัด

7. Test

testตรวจ scannerเปิดแล้ว shell labelsหาย จากนั้นจำลอง scanและเห็น resultบน detail เป็นหลักฐาน navigator placement/result contract

8. Rule

ใช้ root navigatorตาม visual/lifecycle requirement ไม่ใช่เพื่อแก้ contextผิดแบบสุ่ม และเก็บ route hierarchyที่สื่อ domainเดิม
