Failure/operations: 404 route, resource 404, redirect denialและparse errorต้องแยก UX/telemetry พร้อม recoveryที่ไม่สร้าง loopหรือรั่วข้อมูล

1. errorBuilder

GoRouterส่ง state.uri/errorให้ RoutingNotFoundPageและมีปุ่ม Home Routeไม่ matchต่างจาก APIหา taskไม่พบ

2. Unknown query

กำหนด policy ignore/default/invalid linkและ log aggregate metric ไม่ crashด้วย enum firstWhereแบบไม่มี fallback

3. Restoration

Navigator restorationช่วย process recreationแต่ domain draft/sessionต้อง persistแยก URLควรเพียงพอโหลด resourceกลับ ไม่พึ่ง widget memory

4. Diagnostics

บันทึก route name/template, navigation typeและcorrelationโดย redact raw query/IDsตาม policy ห้าม log token/from URLที่มี PII

5. Observers

NavigatorObserverวัด screen transitionsได้หลาย navigatorต้องติด observerตาม root/branchesและหลีกเลี่ยงนับซ้ำจาก shell pages

6. Security review

ตรวจ open redirect, path traversal assumptions, IDORฝั่ง API, secretใน URLและ maliciously long parameters จำกัด inputก่อนสร้าง expensive query/UI

7. Upgrade review

go_router major versionsเปลี่ยน history/type-safe APIs อ่าน changelog/migrationและรัน deep-link/back testsก่อนอัปเดต lockfile

8. Checklist

ทุก routeมี owner, auth policy, direct-link behavior, not-found state, back expectation, analytics/privacyและtestอย่างน้อยหนึ่ง critical path
