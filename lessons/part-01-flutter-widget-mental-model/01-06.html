Lifecycle คือสัญญาว่าเมื่อไร State มี context/widget พร้อม, เมื่อไร dependency เปลี่ยน และเมื่อไรต้องคืน resource การจำชื่อ method โดยไม่รู้ owner ทำให้ listener ซ้ำและใช้ object หลัง dispose

1. ลำดับหลัก

createState
→ initState
→ didChangeDependencies
→ build (เกิดซ้ำได้)
→ didUpdateWidget (เมื่อ config ใหม่ type/key เดิม)
→ build ...
→ deactivate (อาจย้าย/reinsert)
→ dispose (จบถาวร)

2. initState

รันครั้งเดียวต่อ State ใช้สร้าง controller, subscribe resource ที่ไม่ต้อง depend on inherited context และเริ่มงานจาก initial config เรียก super.initState() ตาม convention/framework contract

@override
void initState() {
  super.initState();
  controller = TextEditingController();
  service.addListener(_onChanged);
}

3. didChangeDependencies

รันหลัง initState และเมื่อ inherited dependency ที่ State depend เปลี่ยน เหมาะงานที่ต้องใช้ Localizations/Theme/MediaQuery แล้วต้อง cache/subscribeตาม dependency แต่ต้อง guard ไม่ทำ side effect ซ้ำทุกครั้งโดยไม่ยกเลิกของเดิม

4. didUpdateWidget

เมื่อ parent ส่ง widget config ใหม่แต่ State เดิมอยู่ต่อ ถ้า subscriptionขึ้นกับ widget.source ต้องถอด oldWidget.source แล้วต่อ widget.source ใหม่:

@override
void didUpdateWidget(covariant ScanPanel oldWidget) {
  super.didUpdateWidget(oldWidget);
  if (oldWidget.source != widget.source) {
    oldWidget.source.removeListener(_sync);
    widget.source.addListener(_sync);
  }
}

5. dispose แบบสมมาตร

ทุก add/listen/create ต้องมี remove/cancel/dispose โดย owner เดียวกัน Absolute WarehouseShell add WidgetsBindingObserver, สร้าง timers/store แล้ว remove/cancel/dispose ก่อน super.dispose; Login/packing/scan screens dispose controller/focus ของตน

6. Resource ที่ส่งเข้ามาไม่ใช่เจ้าของเสมอ

pda_widgets.dart มีแนวคิดชัด: controller ภายนอกเป็นของ caller จึง dispose เฉพาะ controller ที่ widget สร้างเอง กฎคือผู้สร้าง/รับ ownership ตาม contract เป็นคนคืน ไม่ dispose dependency ที่ยืมมา

7. แบบฝึกหัด

Widget รับ optional external controller ถ้าไม่ส่งให้สร้างเอง เขียน ownership lifecycle

เฉลย
TextEditingController? _owned;
TextEditingController get controller => widget.controller ?? _owned!;
@override void initState() {
  super.initState();
  if (widget.controller == null) _owned = TextEditingController();
}
@override void dispose() {
  _owned?.dispose();
  super.dispose();
}

ถ้า external controller เปลี่ยนต้องพิจารณา didUpdateWidget ด้วย
