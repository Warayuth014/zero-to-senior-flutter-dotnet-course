หลัง jsonDecode ข้อมูลยังไม่ปลอดภัย: JSON ไม่มี class/enum/DateTime และ server อาจส่ง shape, casing หรือ null ต่างจากที่คิด Parser คือ firewall ระหว่าง dynamic world กับ typed app

1. Decode แล้วแปลงทันที

Object? decoded = jsonDecode(response.body);
if (decoded is! Map) {
  throw const FormatException('Expected JSON object');
}
final map = Map<String, dynamic>.from(decoded);
final task = Task.fromJson(map);

อย่า cast as Map<String,dynamic> ก่อนตรวจ shape เพราะ cast error จะให้ข้อความระดับภาษาแทน contract error ที่ควบคุมได้

2. Parser ที่ทน type เล็กน้อยแต่ไม่กลืนข้อมูลเสีย

int requiredInt(Map<String, dynamic> json, String key) {
  final raw = json[key];
  final value = raw is int ? raw : int.tryParse(raw?.toString() ?? '');
  if (value == null) throw FormatException('$key must be an integer');
  return value;
}

List<Map<String, dynamic>> objectRows(Object? raw) => switch (raw) {
  final List rows => rows.whereType<Map>()
      .map((row) => Map<String, dynamic>.from(row)).toList(),
  _ => const [],
};

ต้องตัดสินใจว่า field/list ขาดคือ empty ที่ถูกต้องหรือ contract error อย่า default ทุกอย่างเป็น empty โดยไม่ดู domain

3. Casing และ .NET contract

บาง endpoint อาจส่ง totalCount หรือ TotalCount ช่วง migration ให้ parser boundary รองรับทั้งคู่ชั่วคราวและมี contract test แต่ควรกำหนด canonical JSON policy ฝั่ง .NET แล้วลบ fallback เมื่อพร้อม ไม่กระจาย json['x'] ?? json['X'] ใน widget

4. DateTime, number และ enum

  • ใช้ ISO-8601 พร้อม timezone contract; parse แล้วตัดสินใจ UTC/local ที่ boundary
  • JSON number อาจ decode เป็น int/double ตามรูป ต้อง normalize ตาม domain
  • status parse เป็น enum/unknown strategy ก่อนเข้า UI
  • ไม่ใช้ toString() กลบ object/list ที่ผิด shape

5. ตัวอย่างจริงที่ควรเทียบ

  • ConnectionProfile.fromJson(Object? raw) ตรวจ Map, id, host, port range และคืน null สำหรับ saved row ที่เสีย
  • cycle_count_api.dart มี helper รองรับ camel/Pascal และ whereType
  • wmsapp/api_service.dart มีจุด decoded as Map<String,dynamic> หลังแยก List ซึ่งอาจ throw หาก body เป็น scalar—เป็นจุดที่ควร harden

6. Contract test

test('parses production task fixture', () {
  final json = jsonDecode(fixture) as Map<String, dynamic>;
  final task = Task.fromJson(json);
  expect(task.id, 'TASK-001');
  expect(task.status, TaskStatus.pending);
});

เก็บ fixture ที่ sanitize จาก response จริง และเพิ่มเคส missing/null/wrong type/legacy casing

7. แบบฝึกหัด

ออกแบบ parser ของ {"items": [...], "totalCount": 12} ที่ items บังคับเป็น object list และ totalCount รับ int/numeric string

แนวคำตอบ

ตรวจ root Map → ตรวจ items เป็น List → แปลงแต่ละ row ผ่าน Task.fromJson โดยระบุนโยบายว่าจะ fail ทั้ง page หรือข้าม bad row → parse count ด้วย helper → คืน typed PagedResult<Task> ไม่คืน Map

8. จุดพลาด
