Function ใน Dart เป็น object: เก็บในตัวแปร ส่งเป็น argument คืนจาก function และมี type ได้ นี่คือฐานของ callback ทุกปุ่ม, builder, listener และ repository fake ใน Flutter

1. รูปแบบ parameter

String normalize(String raw) => raw.trim().toUpperCase();

Future<void> submitScan({
  required String barcode,
  int quantity = 1,
  String? serial,
}) async { /* ... */ }

submitScan(barcode: 'PAL-001', quantity: 2);

Positional เหมาะกับค่าจำนวนน้อยที่ลำดับชัด Named parameter ทำ call site อ่านรู้เรื่องและลดการสลับค่า ใช้ required เมื่อไม่มี default ที่ถูกต้อง อย่าทำ required parameter เป็น nullable โดยไม่มีเหตุผล

2. Function type และ callback

typedef ScanHandler = Future<void> Function(String barcode);

class ScanButton extends StatelessWidget {
  const ScanButton({super.key, required this.onScan});
  final ScanHandler onScan;
  // onPressed: () => onScan(controller.text)
}

VoidCallback คือ void Function(), ValueChanged<T> คือ void Function(T) การระบุ signature ทำให้ parent/child ตกลง input-output กันโดยไม่รู้ implementation ของกันและกัน

3. ส่ง function ไม่ใช่เรียก function

onPressed: submit,        // ส่ง tear-off ให้ Flutter เรียกภายหลัง
onPressed: () => submit(code), // wrapper เมื่อมี argument
// onPressed: submit(code),    // เรียกเดี๋ยวนี้และเอาผลลัพธ์ไปใส่: ผิด

ถ้า callback คืน Future<void> แต่ API รับ void Function() Flutter จะไม่ await ให้อัตโนมัติ เจ้าของ action ต้องจัด loading, error และ duplicate tap เอง

4. Closure และค่าที่ capture

for (final task in tasks) {
  buttons.add(TaskButton(onTap: () => openTask(task.id)));
}

closure จำตัวแปรรอบข้างได้ สะดวกแต่ทำ dependency ซ่อนอยู่ ถ้า callback ใหญ่หรือจับ state หลายตัวให้ย้ายเป็น named method เพื่ออ่าน stack trace/test ง่ายขึ้น

5. ตัวอย่างจริง

wmsapp/lib/services/signalr_service.dart ประกาศ typedef SignalRCallback = void Function(Map<String, dynamic> data) แล้วเก็บ listener เป็น list ส่วน widget ในทั้งสองโปรเจกต์รับ onTap, onChanged, onSubmitted เพื่อส่ง event จาก child กลับ owner โดยไม่ให้ child รู้ business logic

6. แบบฝึกหัด

เขียน function validateQuantity ที่รับ String และ optional max แล้วคืน String? สำหรับ Form validator จากนั้นส่งมันเป็น callback

เฉลยตัวอย่าง
String? validateQuantity(String? raw, {int? max}) {
  final value = int.tryParse(raw?.trim() ?? '');
  if (value == null || value <= 0) return 'จำนวนไม่ถูกต้อง';
  if (max != null && value > max) return 'เกินจำนวนคงเหลือ';
  return null;
}

TextFormField(validator: (value) => validateQuantity(value, max: 10));

7. จุดพลาด

callback async ที่ throw อาจกลายเป็น unhandled error ถ้าผู้เรียกไม่ await/catch และอย่าประกาศ callback เป็น Function กว้าง ๆ เพราะเสียการตรวจจำนวน/type ของ argument

8. เช็กความเข้าใจ
