1. Enum พื้นฐานและ enhanced enum

enum ScanPhase {
  idle('รอสแกน'),
  validating('กำลังตรวจสอบ'),
  confirmed('สำเร็จ'),
  failed('ผิดพลาด');

  const ScanPhase(this.thaiLabel);
  final String thaiLabel;

  bool get canSubmit => this == idle || this == failed;
}

Enhanced enum มี field, constructor, getter/method ได้ แต่ instance เป็นค่าคงที่ตามรายการที่ประกาศ

2. Enum ทำให้ switch ตรวจครบ

Color phaseColor(ScanPhase phase) => switch (phase) {
  ScanPhase.idle => Colors.grey,
  ScanPhase.validating => Colors.blue,
  ScanPhase.confirmed => Colors.green,
  ScanPhase.failed => Colors.red,
};

เมื่อเพิ่ม phase ใหม่ analyzer ชี้ตำแหน่ง switch ที่ยังไม่รองรับ ถ้าใส่ wildcard _ ทั้งที่ทุก case ควรชัด คุณจะเสียประโยชน์นี้

3. แยก wire value จาก enum

.NET อาจส่ง "PENDING", เลข 0 หรือ legacy value อย่ากระจายการเปรียบเทียบใน UI ให้ parse ที่ boundary:

enum TaskStatus { pending, inProgress, completed, unknown }

TaskStatus parseTaskStatus(Object? raw) => switch (raw?.toString().toUpperCase()) {
  'PENDING' || '0' => TaskStatus.pending,
  'RUNNING' || '1' => TaskStatus.inProgress,
  'COMPLETE' || '4' => TaskStatus.completed,
  _ => TaskStatus.unknown,
};

4. ตัวอย่างจริง

  • workflow_definitions.dart มี TaskType, TaskStatus, DispatchMode และ map step ตาม TaskType
  • connection_profile.dart มี protocol/environment/status พร้อม parse และ label
  • wmsapp/packing_screen.dart ใช้ private _PackState เป็น state machine ของหน้าจอ

5. เมื่อไม่ควรใช้ enum

ถ้าค่าถูกเพิ่มจาก server ได้โดยไม่ release แอป หรือเป็นข้อมูลอิสระจำนวนมาก enum จะทำให้ client เก่าไม่รู้จัก ต้องมี unknown/raw fallback หรือใช้ model/config ที่ server ขับเคลื่อนแทน

6. แบบฝึกหัด

เปลี่ยน bool isLoading + hasError + isDone เป็น enum และอธิบายว่าป้องกัน state ใด

เฉลย

LoadState { initial, loading, success, empty, failure } ป้องกันค่าขัดกันเช่น loading=true พร้อม done=true และบังคับ UI render หนึ่งสถานะต่อครั้ง อาจเก็บ data/error แยกหรือใช้ sealed state ในบท architecture

7. จุดพลาด

enum.name เป็น contract ได้เฉพาะเมื่อ client/server ตกลงและรับผลกระทบจากการ rename แล้ว ถ้าเป็น external contract ให้ mapping ชัดเจนและมี test fixture

8. สรุป

ใช้ enum เมื่อ domain มี finite states, parse ที่ boundary, switch แบบ exhaustive และตัดสินใจ unknown strategy ก่อน deploy กับ server ที่เปลี่ยนได้
